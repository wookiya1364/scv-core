# 회귀 러너 — 같은 스위트 호출은 한 번만 (suite-gate memoization)

## 사용자 (2026-08-24)
"이거 너무 심하게 느린데??? 앞으로도 계속 이렇게 느린게 확정이야?" → 추천안(러너가 같은 명령을 한 번만) 채택.

## 실측
보관 계약 28개 중 22개가 마지막 줄에 스위트 전량(run-dry · tests/run.sh · core/tests/test-*.sh 루프)을
부른다 → 같은 2~3분짜리 일을 20번 넘게 반복, 회귀 한 번에 15분+. 계약이 늘수록 더 느려진다.

## 원하는 동작
러너가 그 세 호출을 정확히 알아보고 한 번만 실행, 나머지 계약은 종료 코드를 재사용. 계약 자체의 단언은
매번 그대로 실행. --no-memo / SCV_REGRESSION_MEMO=off 로 옛 동작.
