# 증적 영상이 사람보다 빠르다

2026-08-25, 사용자 보고.

slug 증적 영상이 기능 흐름을 다 보여주기도 전에 지나가 버려, 사람이 인지하기
힘든 경우가 반복된다. 사람은 화면이 바뀌면(클릭 등) 최소 2초 정도가 있어야
인지한다 — 홈 → 메뉴 → 결과처럼 전환이 2번이면 영상은 최소 4초여야 한다.

원인: e2e 스펙이 기계 속도로 달린다. Playwright 는 상호작용을 최고 속도로
수행하므로, 스펙에 의도적 유지 시간이 없으면 영상은 사람이 못 따라가는
속도가 된다.

원하는 것: (1) 스펙 작성 규칙 — 의미 있는 화면 전환 뒤 ≥2초 유지, 전환 N번
이면 영상 ≥2N초. (2) 기계 검사 — 증적 영상이 임계(기본 4초)보다 짧으면
경고해 사람이 알아채게. 임계는 설정 키로 조절.
