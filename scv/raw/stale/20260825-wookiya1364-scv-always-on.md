# 일반 대화는 SCV 를 모른다 — 항상 끼어드는 스위치

2026-08-25, 사용자 관찰.

`scv:help` 를 치면 Mode A/B 진행이 되는데, 명령 없이 일반 대화를 하면 SCV 처럼
행동하지 않는다. 스킬 설명의 "명령 없이도 이런 상황이면 써라" 는 권고일 뿐이라
호스트 모델이 대부분 무시한다.

확인된 구조:

- 훅(on-user-prompt.sh)의 stdout 은 매 턴 모델 컨텍스트에 실린다 — 쉬운말
  알림이 이미 이 길로 들어간다. 같은 길로 라우팅 지시를 실을 수 있다.
- 그 외에는 강제 수단이 없다 (스킬 자동 호출은 모델 재량).

원하는 것 (사용자 확인, 2026-08-25):

- 설정 파일에 SCV_ 로 시작하는 on/off 스위치. ON 이면 일반 대화도 **무조건**
  SCV(help 프로토콜)로 라우팅, OFF 면 일반 대화 그대로.
- 기본값 ON (쉬운말 스위치와 같은 규칙: 값이 없거나 다른 값 = ON, off 만 OFF).
- 한계 공유됨: 매 턴 강한 지시를 싣는 방식이라 사실상 항상 따르지만 코드
  레벨 차단은 아니다 — 호스트 구조상 가능한 최대치.
