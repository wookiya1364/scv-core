# 설정 파일은 항상 있고, 모든 키가 보인다 (0.34.0 후보)

## 사용자 요청 (2026-08-24, wookiya1364 — 팀 업데이트 결과 피드백)

1. .env 에서 자동으로 json 을 안 만드는 상황이 있다 → json 을 무조건 만들도록 강제.
2. json 에 SCV 환경 설정값을 모두 세팅 → .env 에 아무것도 없던 사람은 json 이 비어
   어떤 값을 세팅할 수 있는지 아예 모른다.

## 실측 (0.33.0)

- 설정 파일 생성 경로가 셋뿐이고 전부 수동/조건부: hydrate(새 프로젝트, 예시 파일만
  복사), settings-migrate.sh(.env 있을 때만 + 값 있는 키만 → 비면 `{}`), settings-set.sh
  (첫 쓰기). autosync/sync 는 파일이 없으면 만들지 않는다(merge 는 "없으면 아무것도
  안 함" 이 설계였음 — 빈 파일이 "이사했다"로 오인될까 봐).
- DMN-prototype: 0.33.0 으로 갱신됐는데 파일 없음, .env 에 키 3개 잔존 → 수동 이사로 해결.

## 원하는 동작

- 액션 시작 때(autosync 지점) `scv/scv_settings.json` 이 없으면 **만든다**: 공개 키 전부 =
  기본값, .env 에 값이 있으면 그 값. 있으면 없는 키만 더한다(merge).
- 파일은 항상 **전체 키**를 담는다(값이 기본값이어도) — 무엇을 설정할 수 있는지가 파일
  자체에 보이도록. `_doc` 같은 설명 키를 같이 두는 방안.
- 비밀 파일: 자동 생성 시 git 무시가 보장될 때만(무시 줄을 .gitignore 에 더하고 확인) —
  안 되면 만들지 않고 한 줄 알림.
- .env 잔존 경고: 값이 이미 옮겨졌으면 매번 나무라지 않는다.
