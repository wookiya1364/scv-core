# 분류를 없애고 무조건 부르게 — 세 갈래를 걷어낸다

## Turn 1 — 2026-09-01T15:58:01+09:00

**User**: 아직도 scv:help 가 잘 안 불린다. 처음에 선택지를 3개(A 앞으로 할 일 / B 지난 일 찾기 / C 둘 다 아님) 준 것이 잘못인 것 같다. 무조건 scv:help 로 불리게 해라. 즉 세 갈래 분류를 없애고 조건 없이 매 턴 help 액션을 호출하게 만들라는 요구다.

**Claude Code**: 진단에 동의한다. 지금 블록은 **행동을 시키기 전에 판단을 시킨다.** 판단이 하나라도 앞에 있으면 그 판단이 빠져나갈 구멍이 된다 — 0.41.0 이 "조건문을 명령으로" 바꾸긴 했지만, 세 갈래 자체가 여전히 조건문이다. C 라는 정당한 출구가 있는 한, 애매한 턴은 전부 C 로 새는 쪽이 더 쉽다.

설계 방향: **분류를 지침에서 걷어내고, help 안으로 옮긴다.**
- 지침은 한 문장이 된다 — "답을 쓰기 전에 help 액션을 이 메시지 전문을 인자로 하여 지금 호출하라."
- 부를 필요가 있었는지 없었는지는 **help 가 판단**한다. 모델이 미리 거를 일이 없다.
- 지금도 help 는 인자를 보고 세 모드를 고른다(진단/대화/기록 검색). 여기에 "이 턴은 남길 논의가 없다 — 아무것도 쓰지 않고 끝낸다" 를 한 갈래 더하면 C 의 자리가 그대로 옮겨간다. 사라지는 것이 아니라 **판단하는 주체가 바뀐다.**

이렇게 하면 사용자가 지적한 원인이 정확히 제거된다. 모델에게 남는 일은 "부른다" 하나뿐이다.

다만 무조건에서 **빼야만 하는 경우가 둘** 있다. 안 빼면 동작이 깨진다.
1. **이미 SCV 액션이 실린 턴** — help/promote/work 프로토콜을 수행 중인 턴에서 또 help 를 부르면 자기 자신을 다시 부른다. 지금 이 턴이 그 예다.
2. **사람이 쓰지 않은 턴** — 배경 작업 완료 알림 같은 자동 메시지. 사람의 요구가 없으므로 남길 논의도 없다.

**질문**: 이 둘만 예외로 두고 나머지는 전부 무조건 호출 — 이 모양으로 갈까?

**Claude Code**: 맞지 않았다. 정확히 잡았다 — 내가 쓴 계획은 **완전 무조건이 아니었다.** 모델 쪽 분류는 없앴지만, help 안에 "남길 논의 없음 → 아무것도 쓰지 않고 끝" 이라는 돌려보내는 갈래를 새로 만들어 뒀다. 출구를 지침에서 액션으로 옮겼을 뿐, 출구 자체는 살아 있었다. 같은 구멍이 자리만 바꾼 것이다.

그 갈래를 뺀다. 계획의 받아들임 기준 4번(“help 에 남길 논의 없음 갈래가 있고 그 경우 파일을 쓰지 않는다”)이 정확히 반대로 바뀐다 — **help 는 항상 자기 일을 한다.**

그러면 남는 질문은 하나다. "고마워" 같은 턴에서 help 가 **무엇을** 하느냐다. 돌려보내지 않으므로 반드시 기록이 남는다. 남기는 방식이 둘이다.

- **세션의 대화 파일에 이어 붙인다** — 턴마다 새 파일을 만들지 않고, 이 세션이 이미 쓰고 있는 파일에 한 줄 더한다. 돌려보내는 일이 없고, 파일도 폭증하지 않는다.
- **턴마다 새 대화 파일을 만든다** — 가장 문자 그대로지만, 짧은 맞장구 하나에 파일 하나가 생긴다. 하루면 폴더가 잡음으로 찬다.

앞쪽을 권한다. "무조건 help 를 거치고, help 는 반드시 기록한다" 는 요구를 둘 다 만족하면서, 기록이 쓸모없어지지 않는다.

**질문**: 짧은 턴은 세션 대화 파일에 이어 붙이는 쪽으로 갈까?
