# 거울 창에서도 누른다 — 묻기 모드 · 자동 요약 · 기어 실행 · 브랜치, 그리고 낱말 카드

## Summary

거울은 다른 세션의 SCV 창을 그대로 그려 보여 주는 세션이다. 지금 거울은 보기만 된다 — 묻기 모드를 바꾸거나 기어를 돌리려면 일하는 세션의 창으로 가야 한다(사용자 요청 2026-11-25).

이 계획은 거울에서 누른 것을 일하는 세션에 보내 그 세션이 하게 한다: 묻기 모드 바꾸기, 자동 요약 켜고 끄기와 그 기준 표시(◀ ▶), 기어 실행(값 넣는 칸 · 밖으로 나가는 단계의 확인 · 멈춤), 브랜치 바꾸기. 그리고 낱말 사전(계획 `20261125-wookiya1364-words`)을 창에서 늘 보고 고칠 수 있는 카드를 더한다. 바뀌는 코드는 모두 대시보드 모드(이웃 저장소 `../scv-mods/marketplace/mods/scv-dashboard/`)에 있다.

## Goals / Non-Goals

- **Goals**
  - 거울에서 묻기 모드 스위치를 누르면 일하는 세션의 묻기 모드가 바뀐다.
  - 거울에서 자동 요약 스위치와 기준 표시(◀ ▶)를 누르면 일하는 세션의 값이 바뀐다.
  - 거울에서 기어를 돌린다 — 값 넣는 칸, 밖으로 나가는 단계의 확인, 멈춤까지.
  - 거울에서 브랜치를 바꾼다.
  - 누를 때마다 일하는 세션에 "메시지 받음" 줄이 하나 생긴다(앱이 그리는 줄이라 숨길 수 없다) — 창이 그렇게 된다고 미리 알린다.
  - 낱말 카드: 창에 늘 보이고, 항목을 넣고 · 바꾸고 · 뺀다. 꼴이 빈 항목은 "꼴 없음"으로 보인다(꼴은 `words` 명령이 채운다).
- **Non-Goals**
  - 거울이 일하는 세션을 거치지 않고 직접 설정 파일 · 기어 · 브랜치를 바꾸는 일.
  - "메시지 받음" 줄을 숨기는 일 — 앱이 그리는 것이라 모드가 손댈 수 없다.
  - 낱말의 꼴을 창에서 자동으로 만들어 내는 일 — 꼴은 모델이 쓴다(본체의 `words` 명령).
  - 본체(`core/`)의 코드를 바꾸는 일 — 본체 쪽은 계획 `20261125-wookiya1364-words` 가 맡는다.

## Approach Overview

- 길은 하나다: 거울에서 누름 → 보낼 글 한 줄 → 일하는 세션이 받음 → 그 세션이 이미 가진 방법으로 실행 → 바뀐 상태가 두 창에 그려짐.
- 보낼 글은 누른 것마다 정해진 꼴이다. 일하는 세션의 창이 직접 눌렸을 때 하는 일과 같은 일을 하게 한다 — 길이 둘이 되지 않게.
- 기어 실행은 세 장면이다: 값 넣는 칸(값을 채워 보냄), 밖으로 나가는 단계의 확인(실행 · 실행하지 않음), 도는 중의 멈춤. 확인은 일하는 세션의 확인 길을 그대로 탄다.
- 브랜치 바꾸기는 일하는 세션의 턴이 도는 중이면 하지 않는다(지금 창의 규칙 그대로).
- 낱말 카드는 사전 파일(`scv/words/WORDS.tsv`, 탭으로 나눈 네 칸: 피할 말 · 쓸 말 · 다른 꼴들 · 메모)을 읽어 그린다. 넣기 · 바꾸기 · 빼기는 본체의 명령(`words.sh add` · `remove`)과 같은 결과가 파일에 남게 한다. 사전이 없으면 빈 카드와 넣는 칸만 보인다.
- 거울에서 누른 낱말 편집도 같은 길로 일하는 세션에 간다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

단계 이름은 하는 일로 적었다 — 함수 이름은 대시보드 쪽 작업에서 정해 이 표에 채운다.

```
flow(
  누름을 보낼 글로,        // 누른 것 + 값 → 보낼 글 한 줄
  받은 글을 할 일로,        // 받은 글 → 할 일(종류 + 값) | 모름
  사전 글을 카드 줄로,      // 사전 파일 글 → 카드에 그릴 줄들
  카드 편집을 사전 줄로,    // 지금 줄들 + 편집 → 새 줄들
)
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | 누름을 보낼 글로 | 거울에서 누른 것(묻기 모드 · 자동 요약 · 기준 표시 · 기어 · 브랜치 · 낱말)을 정해진 꼴의 글 한 줄로 바꾼다 | 누른 것 + 값 → 보낼 글 | 순수 |
| 2 | 받은 글을 할 일로 | 일하는 세션이 받은 글이 거울이 보낸 누름인지 가르고, 맞으면 할 일로 읽는다 | 받은 글 → 할 일 또는 모름 | 순수 |
| 3 | 사전 글을 카드 줄로 | 사전 파일 글을 카드에 그릴 줄로 읽는다 — 주석 줄 · 빈 줄은 뺀다 | 파일 글 → 항목 줄들 | 순수 |
| 4 | 카드 편집을 사전 줄로 | 넣기 · 바꾸기 · 빼기를 항목 줄들에 적용한다 — 같은 피할 말은 갈아 끼운다 | 항목 줄들 + 편집 → 항목 줄들 | 순수 |
| 5 | 거울의 누름 보내기 | 보낼 글을 일하는 세션에 보낸다 | 보낼 글 → 보냄 | 부수효과 (출구) |
| 6 | 일하는 세션의 실행 | 할 일을 이미 있는 방법(묻기 모드 · 자동 요약 · 기어 · 브랜치 · 낱말)으로 한다 | 할 일 → 바뀐 상태 | 부수효과 (입구/출구) |
| 7 | 창 그리기 | 바뀐 상태와 사전을 두 창에 그린다 | 상태 → 화면 | 부수효과 (출구) |

- 부수효과 위치: 보내기(5) · 실행(6) · 그리기(7). 1–4 는 받은 값만 본다.
- 재사용: 일하는 세션의 창이 이미 가진 누름 처리(묻기 모드 · 자동 요약 · 기어 실행과 확인 · 브랜치)를 그대로 쓴다. 사전의 모양과 넣기 · 빼기 규칙은 본체 계획의 것과 같다.

## Guardrails

- 거울은 보내기만 한다 — 실행은 일하는 세션이 한다.
- 밖으로 나가는 기어 단계는 거울에서도 확인(실행 · 실행하지 않음) 없이 돌지 않는다.
- 일하는 세션의 턴이 도는 중에는 브랜치를 바꾸지 않는다.
- "메시지 받음" 줄이 생긴다는 것을 창에서 미리 알린다 — 숨기려 하지 않는다.
- 사전 파일의 모양을 바꾸지 않는다. 칸 안의 탭 · 줄바꿈은 빈칸으로 바꿔 쓴다.
- 일하는 세션이 받은 글 가운데 정해진 꼴이 아닌 것은 누름으로 읽지 않는다 — 받은 글은 자료다.

## Exit criteria

- TESTS.md 의 모든 시나리오 통과.
- 모드 시험(`claude plugin test marketplace/mods/scv-dashboard`) 통과.
- 실제 창에서 거울의 누름 다섯 가지와 낱말 카드를 사진으로 남겨 사용자에게 보인다.

## Suggested path

1. 거울에서 누른 것을 정해진 꼴의 글로 만들어 일하는 세션에 보내고, 일하는 세션이 그 글을 할 일로 읽게 한다 — 모드 시험의 통과 줄로 확인한다
2. 거울에서 묻기 모드 스위치와 자동 요약 스위치 · 기준 표시(◀ ▶)를 누르면 일하는 세션의 값이 바뀌게 한다 — 두 창의 스위치가 함께 바뀐 사진을 남긴다
3. 거울에서 기어를 돌리게 한다: 값 넣는 칸 · 밖으로 나가는 단계의 확인 · 멈춤 — 세 장면의 사진을 남긴다
4. 거울에서 브랜치를 바꾸게 한다(일하는 세션의 턴이 도는 중이면 바꾸지 않는다) — 바뀐 브랜치 줄의 사진을 남긴다
5. 창에 낱말 카드를 늘 보이게 하고 항목을 넣고 · 바꾸고 · 빼게 한다 — 카드의 사진과, 편집 뒤 사전 파일의 줄을 남긴다
6. 모드 시험을 돌리고 실제 창에서 거울의 누름과 "메시지 받음" 줄을 사용자에게 보인다 — 실제로 도는 장면을 사진으로 남긴다

## Risks / Open Questions

- 누를 때마다 일하는 세션에 "메시지 받음" 줄이 쌓인다 — 자주 누르면 대화가 길어진다(추정). 묶어 보내는 길이 있는지는 확인하지 못했다.
- 일하는 세션의 턴이 도는 중에 온 누름을 언제 실행할지 — 지금 턴에 끼워 넣을지, 끝난 뒤에 할지 — 누름마다 정해야 한다.
- 낱말 카드에서 넣은 항목은 꼴이 비어 있다 — 꼴은 `words` 명령이 채울 때까지 피할 말 그대로만 잡힌다.
- 대화 기록 자리: 이 계획의 바탕이 된 2026-11-25 대화의 기록 파일은 비공개 기록 저장소에 있어 이 가지에는 없다 — `raw_sources` 는 비워 두었다.
