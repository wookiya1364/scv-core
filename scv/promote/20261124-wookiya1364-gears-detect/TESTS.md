# Test Plan — 반복 알아채기

## Overview

비슷한 요청이 2번째로 올 때 알림이 뜨는지, 맞는 기어가 있을 때 그 기어를 알려 주는지, 그리고 겹치는 것이 없을 때는 아무것도 더 실리지 않는지를 본다. 요청 기록이 비밀 가림을 거쳐 기록 폴더에만 쌓이는지도 본다. 끝으로 실제 대화 기록으로 엉뚱한 알림이 얼마나 뜨는지 잰다.

T1–T10 은 임시 폴더의 시험용 프로젝트에서 매 턴 훅을 직접 불러 본다.

## 측정 기준 (재기 전에 고정)

- 엉뚱한 알림: 알림이 뜬 턴 가운데 사람이 "같은 일이 아님"으로 표시한 턴의 비율 — **10% 이하** (제안값. 구현 1단계에서 선택 창으로 확정하고, 확정한 날짜를 이 줄에 적는다).
- 놓침: 사람이 "같은 일의 반복"으로 표시한 요청 쌍 가운데 알림이 뜨지 않은 비율 — 기준 없음, 재서 보고만 한다.
- 매 턴 시간: 기어 · 기록이 있는 프로젝트에서 훅 한 번의 시간이 전의 **1.5배 이내**.

## Test scenarios

### T1. 같은 요청 1번째에는 알림이 없고, 2번째에는 한 줄이 뜬다

- **Setup**: 기어 없음, 요청 기록 없음.
- **Run**: 같은 요청 글로 훅을 두 번 부른다.
- **Expected**: 첫 출력에는 기어 알림이 없다. 둘째 출력에는 지난 요청 한 줄과 "같은 일이면 선택 창으로 기어로 만들지 물어라"는 알림이 정확히 한 줄 있다.
- **Pass criterion**: 알림 표식 줄 수가 1번째 0, 2번째 1.

### T2. 조사만 다른 비슷한 요청도 2번째로 본다

- **Setup**: 기록에 "릴리스 노트 써줘" 한 줄.
- **Run**: "릴리스 노트를 써 줘" 로 훅을 부른다.
- **Expected**: 알림 한 줄.
- **Pass criterion**: 알림 표식 줄 수 1.

### T3. 겹치는 것이 없는 턴에는 한 글자도 더 실리지 않는다

- **Setup**: 기록에 서로 다른 요청 다섯 줄, 사전에 기어 둘.
- **Run**: 어느 것과도 겹치지 않는 요청으로 훅을 부른다. 기어 기능을 뺀 훅의 출력과 견준다.
- **Expected**: 두 출력이 같다.
- **Pass criterion**: `cmp` 종료 코드 0.

### T4. 기어도 기록도 없는 프로젝트의 훅 출력은 지금과 같다

- **Setup**: `scv/gears/` 와 요청 기록이 없는 프로젝트. 변경 전 훅으로 받은 출력을 보관해 둔다.
- **Run**: 변경 뒤 훅을 같은 입력으로 부른다(쌓기가 꺼진 조건과, 켜진 조건의 첫 턴).
- **Expected**: 출력이 변경 전과 바이트까지 같다.
- **Pass criterion**: `cmp` 종료 코드 0. 매 턴 글 크기 시험(`core/tests/test-instruction-diet.sh`) 통과.

### T5. 겹치는 기어가 있으면 그 기어를 알려 준다 — 지난 요청보다 먼저

- **Setup**: 사전에 낱말이 요청과 겹치는 기어 하나, 기록에 비슷한 지난 요청 하나.
- **Run**: 그 요청으로 훅을 부른다.
- **Expected**: 알림은 한 줄이고, 기어 이름 · 하는 일 · 돌리는 명령이 들어 있다. "기어로 만들지 물어라"는 줄은 없다.
- **Pass criterion**: 알림 표식 줄 수 1, 그 줄에 기어 이름과 실행 명령, 만들기 권유 표식 0건.

### T6. 후보가 여럿이어도 알림은 한 줄이다

- **Setup**: 사전에 겹치는 기어 셋(점수가 서로 다름).
- **Run**: 훅을 부른다.
- **Expected**: 점수가 가장 높은 기어 하나만 알린다.
- **Pass criterion**: 알림 표식 줄 수 1, 그 줄의 기어 이름이 최고 점수 기어.

### T7. 만들지 않음을 고른 요청은 다시 묻지 않는다

- **Setup**: T1 의 2번째 상태에서 거절 표시를 남긴다.
- **Run**: 같은 요청으로 훅을 세 번째로 부른다.
- **Expected**: 알림이 없다. 다른 요청의 2번째에는 여전히 알림이 뜬다.
- **Pass criterion**: 거절한 요청의 알림 표식 0, 다른 요청의 알림 표식 1.

### T8. 쌓지 않는 턴: 자동 알림 · 명령 · 짧은 맞장구

- **Setup**: 빈 기록.
- **Run**: 자동 알림 턴, 명령으로 시작하는 메시지, "응" 같은 짧은 맞장구로 훅을 각각 두 번씩 부른다.
- **Expected**: 기록에 한 줄도 쌓이지 않고 알림도 없다.
- **Pass criterion**: 기록 줄 수 0, 알림 표식 0.

### T9. 요청 기록은 가린 글만, 기록 폴더에만 쌓인다

- **Setup**: 비밀처럼 생긴 문자열(토큰 모양)이 든 요청.
- **Run**: 훅을 부른 뒤 프로젝트 전체에서 새로 생기거나 바뀐 파일을 찾는다.
- **Expected**: 바뀐 파일은 기록 폴더 안의 요청 기록뿐이다. 그 안에 비밀 문자열 원문은 없고 가림 표시가 있다. `.claude` 아래는 그대로다.
- **Pass criterion**: 바뀐 파일 경로가 모두 기록 폴더 아래, 원문 문자열 검색 0건, `.claude` 전후 비교 같음.

### T10. 보는 범위에 한도가 있다

- **Setup**: 요청 기록을 한도 줄 수의 열 배로 채운다. 한도 밖(오래된) 줄에만 겹치는 요청을 둔다.
- **Run**: 훅을 부르고 시간을 잰다. 한도 줄 수만 있는 기록에서도 잰다.
- **Expected**: 한도 밖 줄은 알림을 만들지 않는다. 두 경우의 시간이 비슷하다.
- **Pass criterion**: 알림 표식 0, 큰 기록의 시간이 작은 기록의 1.5배 이내(5회 중앙값).

### T11. 매 턴 시간

- **Setup**: 기어 스무 개와 한도만큼의 요청 기록이 있는 프로젝트.
- **Run**: 변경 전 훅과 변경 뒤 훅을 같은 입력으로 번갈아 재서 중앙값을 낸다.
- **Expected**: 변경 뒤가 전의 1.5배 이내. 기존 속도 시험이 통과한다.
- **Pass criterion**: 비율 ≤ 1.5, 속도 시험 종료 코드 0. 넘으면 멈추고 사용자에게 묻는다.

### T12. 실제 대화 기록으로 재기

- **Setup**: 실제 대화 기록에서 뽑은 사람 요청 목록과, 재기 전에 사람이 표시해 둔 "같은 일의 반복" 쌍. 위 '측정 기준'이 확정돼 있다.
- **Run**: 요청을 시간 순으로 훅에 흘려 알림이 뜬 턴을 모은다. 알림이 뜬 턴마다 사람이 같은 일인지 표시한다(어느 설정으로 돌렸는지 가리고).
- **Expected**: 엉뚱한 알림 비율이 기준 이하. 놓친 비율은 숫자로 보고한다.
- **Pass criterion**: 엉뚱한 알림 ≤ 확정한 기준. 결과 파일에 알림 수 · 엉뚱한 알림 수 · 놓친 쌍 수가 있다.

### T13. 실제 세션에서 선택 창이 뜬다

- **Setup**: 변경을 얹은 실제 세션.
- **Run**: 같은 요청을 두 번 한다. 그 뒤 기어로 만들어 두고 비슷한 요청을 한 번 더 한다.
- **Expected**: 2번째 요청에서 모델이 선택 창으로 "이것을 별도의 기어로 만들어 재사용할 수 있게 할까요?"를 묻는다. 기어를 만든 뒤의 요청에서는 모델이 그 기어를 돌린다.
- **Pass criterion**: 두 장면의 실제 화면 또는 세션 기록을 사용자에게 보여 주고 확인받았다는 기록이 변경 이력에 있다.

### T14. 맥과 리눅스에서 같은 결과, 순수 함수 사전

- **Setup**: 맥(BSD 도구 · bash 3.2)과 리눅스(GNU 도구).
- **Run**: 이 시험 파일, 순수 함수 사전 검사, 호스트 이름 시험, 템플릿 지문 검사를 두 곳에서 돈다.
- **Expected**: 모두 통과하고, 같은 요청 쌍의 점수가 두 환경에서 같다.
- **Pass criterion**: 두 환경 종료 코드 0, 점수 출력 비교 같음.

## How to run

```bash
bash core/tests/test-gear-detect.sh
```

## Pass criteria

- T1–T11 · T14 가 맥과 리눅스에서 통과한다.
- T12 의 엉뚱한 알림 비율이 확정한 기준 이하이고, 결과 숫자가 기록돼 있다.
- T13 의 사용자 확인이 변경 이력에 있다.
