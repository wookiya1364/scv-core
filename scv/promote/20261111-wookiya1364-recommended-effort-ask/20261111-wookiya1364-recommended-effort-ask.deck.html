# 권장 effort 요청 — 모델의 권장 값과 다르면 한 번 묻는다

## Summary

모델마다 공식 문서가 권하는 effort 값이 있다. 세션의 effort 가 그 값과 다르면, SCV 가 선택 창으로 한 번 "바꾸시겠습니까"를 묻게 한다.
바꾸는 것은 사용자이고, 같은 조건에서는 다시 묻지 않는다. 클로드 코드 래퍼에 먼저 넣는다.
방향과 값은 2026-11-10 리눅스 세션에서 사용자가 정했다.

## Goals / Non-Goals

- **Goals**
  - 래퍼 가이드 폴더에 모델별 권장 effort 표를 둔다(모델 9개, 값 · 조건 · 근거 문장 · 출처).
  - 지금 effort 가 권장과 다르면 매 턴 안내에 "선택 창으로 한 번 물어라"는 줄이 한 번 실린다. 근거 문장이 함께 보인다.
  - 같은 조건(모델 · 지금 값 · 권장 값)에서는 다시 묻지 않는다. 조건이 달라지면 한 번 더 묻는다.
  - 끄는 설정 하나(기본 켬).
  - 지금 값은 호스트가 주는 값을 먼저 쓰고, 도움말도 모델과 함께 effort 를 받을 수 있다.
- **Non-Goals**
  - effort 를 SCV 나 모델이 직접 바꾸는 일
  - 코덱스 래퍼의 effort 요청
  - 일의 무게로 실행 방식을 정하는 기존 장치(`SCV_EFFORT_MODE`) 손보기
  - 다시 쓰기 규칙 · 답 모양 규칙

## Approach Overview

- **권장 표** — 래퍼의 `prompting/EFFORT.tsv`. 한 줄 = 모델 id · 권장 값 · 조건(없으면 `-`) · 근거 문장 · 출처 주소. 리눅스 세션에서 정한 값:
  Fable 5 · 5.1 · 5.2 = high / Opus 4.8 = xhigh / Opus 5 = high / Opus 5.5 = medium / Sonnet 5 = high / Sonnet 5.5 = high / Haiku 5.5 = medium.
  조건이 달린 모델: Opus 4.8(코딩 · 에이전트 일은 xhigh, 그 밖은 high 이상), Sonnet 5.5(high 에서 시작, 잘 정의된 에이전트 코딩은 medium).
  1단계에서 값과 근거 문장을 지금의 공식 문서와 다시 맞춘다. 문서에서 근거 문장을 찾지 못한 모델은 표에 넣지 않는다(그 모델은 묻지 않음).
- **지금 값 읽기** — 코어는 "값을 담은 환경 변수 이름"을 호스트 프로필에서 받는다(코어에 호스트 이름 없음). 래퍼가 그 이름을 알려 준다.
  확인한 것: 클로드 코드의 도구 실행 환경에 effort 값을 담은 환경 변수가 있다(2026-11-11, 값 `high`). 확인 못 한 것: 매 턴 훅의 환경에도 같은 변수가 있는지, 세션 중에 값을 바꾸면 따라 바뀌는지 — 1단계에서 실제 세션으로 확인한다.
  훅에서 못 읽으면 도움말이 받는 값(`--effort`)을 쓴다. 둘 다 없으면 '모름' → 묻지 않는다.
- **판정과 안내** — 순수 함수가 지금 값 · 권장 줄 · 지난번 물은 조건을 받아 `ask | same | asked | unknown | off` 중 하나를 낸다. `ask` 일 때만 매 턴 안내에 줄이 실린다. 물은 조건은 세션 상태 파일에 적는다.
- **분량** — 묻지 않는 턴은 안내가 0바이트 늘어난다. 묻는 턴의 줄은 분량 한도 시험 안에 든다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  effort_now,              // 호스트 프로필 · 환경 · 도움말 인자 → 지금 값 또는 빈 값   (부수효과: 환경 읽기)
  scv_mp_effort_row,       // 권장 표 글 · 모델 id → "권장<TAB>조건<TAB>근거<TAB>출처" 또는 빈 값
  scv_mp_effort_verdict,   // 스위치 · 지금 값 · 권장 줄 · 지난번 조건 → ask|same|asked|unknown|off
  scv_mp_effort_block,     // 판정 · 지금 값 · 권장 줄 → 안내에 실을 줄(ask 가 아니면 빈 값)
  effort_mark,             // 조건 → 세션 상태 파일                                    (부수효과: 쓰기)
)
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | `effort_now` | 지금 세션의 effort 값을 얻는다 | 호스트 프로필 · 환경 · 인자 → 값 또는 빈 값 | 부수효과 (입구) |
| 2 | `scv_mp_effort_row` | 권장 표에서 이 모델의 줄을 고른다 | 표 글 · 모델 id → 권장 줄 또는 빈 값 | 순수 |
| 3 | `scv_mp_effort_verdict` | 물을지 말지 정한다 | 스위치 · 지금 값 · 권장 줄 · 지난번 조건 → 판정 | 순수 |
| 4 | `scv_mp_effort_block` | 물으라는 안내 줄을 만든다 | 판정 · 지금 값 · 권장 줄 → 안내 줄 | 순수 |
| 5 | `effort_mark` | 물은 조건을 적어 둔다 | 조건 → 세션 상태 파일 | 부수효과 (출구) |

- 부수효과 위치: 1(환경 읽기) · 5(상태 파일 쓰기).
- 재사용: 매 턴 안내를 싣는 자리(`prompt` 명령)와 세션 상태 폴더, 선택 창 규칙(`contracts/choices.md`)을 그대로 쓴다.

## Guardrails

- 안내 줄은 "사용자에게 물어라"까지다. "값을 바꿔라"는 말을 넣지 않는다.
- 근거 문장은 공식 문서의 문장 그대로다. 요약하거나 지어내지 않는다.
- 코어에는 호스트 이름 · 호스트의 환경 변수 이름을 적지 않는다(호스트 프로필에서 받는다).
- 지금 값이 표의 값 낱말(low · medium · high · xhigh · max)이 아니면 '모름'으로 본다.
- 실제 세션에서 지금 값이 맞게 읽히는 것을 확인하지 못하면 내보내지 않는다 — 멈추고 보고한다.

## Exit criteria

- TESTS.md 의 시나리오 17개 통과
- 실제 클로드 코드 세션에서: effort 를 권장과 다르게 두면 요청이 1번, 권장대로 두면 0번(T15)
- 묻지 않는 턴의 매 턴 안내 크기가 0.88.x 와 바이트 단위로 같음
- 전체 시험 bash 3.2 · bash 5, CI 맥 · 리눅스 통과

## Suggested path

1. 지금 값을 읽는 길을 실제 세션으로 확인하고, 표의 값 · 근거 문장을 공식 문서와 맞춤 — 읽는 길이 없으면 여기서 멈추고 보고한다
2. 권장 표와 표 검사를 래퍼에 넣음 — `scv_mp_effort_row`
3. 판정과 안내 줄 — `scv_mp_effort_verdict`, `scv_mp_effort_block`
4. 지금 값 읽기와 물은 조건 적기를 매 턴 안내에 이음 — `effort_now`, `effort_mark`
5. 도움말이 effort 를 받고, 끄는 설정을 넣음 — `effort_now`
6. 문서 · CHANGELOG · VERSION 0.89.0 · 순수 함수 목록 — 문서와 버전을 맞춘다
7. 실제 세션으로 요청 1번 · 0번을 확인 — 화면에 보이는 대로 적는다

## Risks / Open Questions

- 훅 환경에서 지금 값을 읽을 수 있는지는 확인 전이다. 못 읽으면 도움말 인자 길만 남고, 그 값은 모델이 아는 범위에서만 온다.
- 세션 중에 effort 를 바꿨을 때 환경 값이 따라 바뀌는지 모른다. 안 바뀌면 "달라진 때 한 번"이 새 세션에서만 맞는다 — 확인한 대로 문서에 적는다.
- 표의 값은 리눅스 세션에서 정한 것이다. 지금 공식 문서와 다르면 문서를 따르고, 달라진 값은 보고한다.
- 코덱스 래퍼에는 표가 없어 동작이 그대로다(뒤 계획).

# 권장 effort 요청 — 모델의 권장 값과 다르면 한 번 묻는다

## Summary

모델마다 공식 문서가 권하는 effort 값이 있다. 세션의 effort 가 그 값과 다르면, SCV 가 선택 창으로 한 번 "바꾸시겠습니까"를 묻게 한다.
바꾸는 것은 사용자이고, 같은 조건에서는 다시 묻지 않는다. 클로드 코드 래퍼에 먼저 넣는다.
방향과 값은 2026-11-10 리눅스 세션에서 사용자가 정했다.

## Goals / Non-Goals

- **Goals**
  - 래퍼 가이드 폴더에 모델별 권장 effort 표를 둔다(모델 9개, 값 · 조건 · 근거 문장 · 출처).
  - 지금 effort 가 권장과 다르면 매 턴 안내에 "선택 창으로 한 번 물어라"는 줄이 한 번 실린다. 근거 문장이 함께 보인다.
  - 같은 조건(모델 · 지금 값 · 권장 값)에서는 다시 묻지 않는다. 조건이 달라지면 한 번 더 묻는다.
  - 끄는 설정 하나(기본 켬).
  - 지금 값은 호스트가 주는 값을 먼저 쓰고, 도움말도 모델과 함께 effort 를 받을 수 있다.
- **Non-Goals**
  - effort 를 SCV 나 모델이 직접 바꾸는 일
  - 코덱스 래퍼의 effort 요청
  - 일의 무게로 실행 방식을 정하는 기존 장치(`SCV_EFFORT_MODE`) 손보기
  - 다시 쓰기 규칙 · 답 모양 규칙

## Approach Overview

- **권장 표** — 래퍼의 `prompting/EFFORT.tsv`. 한 줄 = 모델 id · 권장 값 · 조건(없으면 `-`) · 근거 문장 · 출처 주소. 리눅스 세션에서 정한 값:
  Fable 5 · 5.1 · 5.2 = high / Opus 4.8 = xhigh / Opus 5 = high / Opus 5.5 = medium / Sonnet 5 = high / Sonnet 5.5 = high / Haiku 5.5 = medium.
  조건이 달린 모델: Opus 4.8(코딩 · 에이전트 일은 xhigh, 그 밖은 high 이상), Sonnet 5.5(high 에서 시작, 잘 정의된 에이전트 코딩은 medium).
  1단계에서 값과 근거 문장을 지금의 공식 문서와 다시 맞춘다. 문서에서 근거 문장을 찾지 못한 모델은 표에 넣지 않는다(그 모델은 묻지 않음).
- **지금 값 읽기** — 코어는 "값을 담은 환경 변수 이름"을 호스트 프로필에서 받는다(코어에 호스트 이름 없음). 래퍼가 그 이름을 알려 준다.
  확인한 것: 클로드 코드의 도구 실행 환경에 effort 값을 담은 환경 변수가 있다(2026-11-11, 값 `high`). 확인 못 한 것: 매 턴 훅의 환경에도 같은 변수가 있는지, 세션 중에 값을 바꾸면 따라 바뀌는지 — 1단계에서 실제 세션으로 확인한다.
  훅에서 못 읽으면 도움말이 받는 값(`--effort`)을 쓴다. 둘 다 없으면 '모름' → 묻지 않는다.
- **판정과 안내** — 순수 함수가 지금 값 · 권장 줄 · 지난번 물은 조건을 받아 `ask | same | asked | unknown | off` 중 하나를 낸다. `ask` 일 때만 매 턴 안내에 줄이 실린다. 물은 조건은 세션 상태 파일에 적는다.
- **분량** — 묻지 않는 턴은 안내가 0바이트 늘어난다. 묻는 턴의 줄은 분량 한도 시험 안에 든다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  effort_now,              // 호스트 프로필 · 환경 · 도움말 인자 → 지금 값 또는 빈 값   (부수효과: 환경 읽기)
  scv_mp_effort_row,       // 권장 표 글 · 모델 id → "권장<TAB>조건<TAB>근거<TAB>출처" 또는 빈 값
  scv_mp_effort_verdict,   // 스위치 · 지금 값 · 권장 줄 · 지난번 조건 → ask|same|asked|unknown|off
  scv_mp_effort_block,     // 판정 · 지금 값 · 권장 줄 → 안내에 실을 줄(ask 가 아니면 빈 값)
  effort_mark,             // 조건 → 세션 상태 파일                                    (부수효과: 쓰기)
)
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | `effort_now` | 지금 세션의 effort 값을 얻는다 | 호스트 프로필 · 환경 · 인자 → 값 또는 빈 값 | 부수효과 (입구) |
| 2 | `scv_mp_effort_row` | 권장 표에서 이 모델의 줄을 고른다 | 표 글 · 모델 id → 권장 줄 또는 빈 값 | 순수 |
| 3 | `scv_mp_effort_verdict` | 물을지 말지 정한다 | 스위치 · 지금 값 · 권장 줄 · 지난번 조건 → 판정 | 순수 |
| 4 | `scv_mp_effort_block` | 물으라는 안내 줄을 만든다 | 판정 · 지금 값 · 권장 줄 → 안내 줄 | 순수 |
| 5 | `effort_mark` | 물은 조건을 적어 둔다 | 조건 → 세션 상태 파일 | 부수효과 (출구) |

- 부수효과 위치: 1(환경 읽기) · 5(상태 파일 쓰기).
- 재사용: 매 턴 안내를 싣는 자리(`prompt` 명령)와 세션 상태 폴더, 선택 창 규칙(`contracts/choices.md`)을 그대로 쓴다.

## Guardrails

- 안내 줄은 "사용자에게 물어라"까지다. "값을 바꿔라"는 말을 넣지 않는다.
- 근거 문장은 공식 문서의 문장 그대로다. 요약하거나 지어내지 않는다.
- 코어에는 호스트 이름 · 호스트의 환경 변수 이름을 적지 않는다(호스트 프로필에서 받는다).
- 지금 값이 표의 값 낱말(low · medium · high · xhigh · max)이 아니면 '모름'으로 본다.
- 실제 세션에서 지금 값이 맞게 읽히는 것을 확인하지 못하면 내보내지 않는다 — 멈추고 보고한다.

## Exit criteria

- TESTS.md 의 시나리오 17개 통과
- 실제 클로드 코드 세션에서: effort 를 권장과 다르게 두면 요청이 1번, 권장대로 두면 0번(T15)
- 묻지 않는 턴의 매 턴 안내 크기가 0.88.x 와 바이트 단위로 같음
- 전체 시험 bash 3.2 · bash 5, CI 맥 · 리눅스 통과

## Suggested path

1. 지금 값을 읽는 길을 실제 세션으로 확인하고, 표의 값 · 근거 문장을 공식 문서와 맞춤 — 읽는 길이 없으면 여기서 멈추고 보고한다
2. 권장 표와 표 검사를 래퍼에 넣음 — `scv_mp_effort_row`
3. 판정과 안내 줄 — `scv_mp_effort_verdict`, `scv_mp_effort_block`
4. 지금 값 읽기와 물은 조건 적기를 매 턴 안내에 이음 — `effort_now`, `effort_mark`
5. 도움말이 effort 를 받고, 끄는 설정을 넣음 — `effort_now`
6. 문서 · CHANGELOG · VERSION 0.89.0 · 순수 함수 목록 — 문서와 버전을 맞춘다
7. 실제 세션으로 요청 1번 · 0번을 확인 — 화면에 보이는 대로 적는다

## Risks / Open Questions

- 훅 환경에서 지금 값을 읽을 수 있는지는 확인 전이다. 못 읽으면 도움말 인자 길만 남고, 그 값은 모델이 아는 범위에서만 온다.
- 세션 중에 effort 를 바꿨을 때 환경 값이 따라 바뀌는지 모른다. 안 바뀌면 "달라진 때 한 번"이 새 세션에서만 맞는다 — 확인한 대로 문서에 적는다.
- 표의 값은 리눅스 세션에서 정한 것이다. 지금 공식 문서와 다르면 문서를 따르고, 달라진 값은 보고한다.
- 코덱스 래퍼에는 표가 없어 동작이 그대로다(뒤 계획).

# Test Plan — 권장 effort 요청

## Overview

effort 가 권장과 다를 때만, 한 번만 묻는지 본다. 값을 모르거나 표가 없으면 아무 일도 없어야 한다.
T1–T14 · T16 · T17 은 임시 폴더의 자동 시험, T15 는 실제 세션 확인이다.

## Test scenarios

### T1. 권장 표 검사

- **Setup**: 래퍼의 `prompting/EFFORT.tsv`.
- **Run**: `bash ../scv-claude-code/prompting/check.sh`.
- **Expected**: 모델 줄마다 값이 low · medium · high · xhigh · max 중 하나, 근거 문장과 출처가 비어 있지 않음, 모델 id 가 가이드 색인에 있음.
- **Pass criterion**: 종료 코드 0. 값 낱말을 틀리게 바꾼 사본에서는 종료 코드 1.

### T2. 근거 문장은 공식 문서의 문장 그대로

- **Setup**: 표의 줄마다 출처로 적힌 문서(저장된 가이드 사본 또는 받아 온 공식 문서).
- **Run**: 근거 문장을 그 문서에서 글자 그대로 찾음.
- **Expected**: 모든 줄에서 찾음.
- **Pass criterion**: 못 찾은 줄 0개.

### T3. 다르면 요청 1번

- **Setup**: 모델 `claude-opus-5-5`(권장 medium), 지금 값 high, 새 세션.
- **Run**: 매 턴 안내 명령(`prompt`).
- **Expected**: 안내에 effort 요청 줄 1개 — 지금 값 high · 권장 medium · 근거 문장 · "선택 창으로 한 번 물어라".
- **Pass criterion**: 요청 줄 수 1.

### T4. 같은 조건에서 다시 0번

- **Setup**: T3 바로 뒤, 같은 세션.
- **Run**: `prompt` 를 두 번 더.
- **Expected**: 요청 줄 없음.
- **Pass criterion**: 두 번 모두 요청 줄 수 0.

### T5. 같으면 0번

- **Setup**: 모델 `claude-opus-5-5`, 지금 값 medium, 새 세션.
- **Run**: `prompt`.
- **Expected**: 요청 줄 없음.
- **Pass criterion**: 요청 줄 수 0, 안내 크기가 스위치를 끈 때와 바이트 단위로 같음.

### T6. 표에 없는 모델 0번

- **Setup**: 모델 `some-unknown-model`, 지금 값 low.
- **Run**: `prompt`.
- **Expected**: 요청 줄 없음.
- **Pass criterion**: 요청 줄 수 0.

### T7. 지금 값을 모르면 0번

- **Setup**: 값을 담은 환경 변수 없음, 도움말 인자도 없음. 또 하나: 값이 `banana`.
- **Run**: `prompt`.
- **Expected**: 두 경우 모두 요청 줄 없음.
- **Pass criterion**: 요청 줄 수 0.

### T8. 조건이 달라지면 다시 1번

- **Setup**: T3 → T4 뒤, 지금 값을 low 로 바꿈. 또 하나: 모델을 `claude-fable-5-2`(권장 high)로 바꾸고 지금 값 medium.
- **Run**: `prompt` 를 각각 두 번.
- **Expected**: 첫 번째에 1번, 두 번째에 0번.
- **Pass criterion**: 요청 줄 수가 1 · 0.

### T9. 끄는 설정

- **Setup**: 설정에서 effort 요청을 끔. 조건은 T3.
- **Run**: `prompt`.
- **Expected**: 요청 줄 없음, 상태 파일도 안 생김.
- **Pass criterion**: 요청 줄 수 0, 안내가 0.88.x 와 바이트 단위로 같음.

### T10. 조건이 달린 모델

- **Setup**: 모델 `claude-opus-4-8`(지금 값 high) · `claude-sonnet-5-5`(지금 값 medium).
- **Run**: `prompt`.
- **Expected**: 요청 줄에 표의 조건 글이 함께 실림.
- **Pass criterion**: 요청 줄에 조건 글이 글자 그대로 있음.

### T11. 바꾸는 것은 사용자

- **Setup**: T3 의 요청 줄.
- **Run**: 줄의 글을 봄.
- **Expected**: "사용자가 바꾼다"는 뜻의 말이 있고, 모델에게 값을 바꾸라는 말이 없음.
- **Pass criterion**: 정해 둔 문구가 있음, 금지 문구 0건.

### T12. 분량 한도

- **Setup**: 없음.
- **Run**: 매 턴 안내 분량 시험(`core/tests/test-instruction-diet.sh`)과 도움말 분량 시험.
- **Expected**: 통과.
- **Pass criterion**: 종료 코드 0.

### T13. 도움말이 effort 를 받음

- **Setup**: 없음.
- **Run**: 도움말을 `--model <id> --effort high` 로, 그리고 `--effort` 없이.
- **Expected**: 받은 값이 지금 값으로 쓰임(호스트 값이 없을 때). 없이 부르면 출력이 0.88.x 와 같음.
- **Pass criterion**: 두 출력이 기대와 같음.

### T14. 표가 없는 호스트 — 그대로

- **Setup**: 가이드 폴더에 `EFFORT.tsv` 가 없음(코덱스 래퍼 모양).
- **Run**: `prompt`, 호스트 이름 검사(`tests/test-host-neutral.sh`).
- **Expected**: 요청 줄 없음, 코어에 호스트 이름 0건.
- **Pass criterion**: 요청 줄 수 0, 검사 종료 코드 0.

### T15. 실제 세션

- **Setup**: 새 버전을 설치한 클로드 코드. 모델의 권장 값과 다른 effort 로 세션을 엶.
- **Run**: 요청 한 번. 그다음 effort 를 권장대로 두고 새 세션에서 요청 한 번.
- **Expected**: 첫 세션에서 선택 창(또는 요청 문장)이 1번, 둘째 세션에서 0번. SCV 가 읽은 지금 값이 호스트가 보여 주는 값과 같음(설정 2가지).
- **Pass criterion**: 세션 기록에서 요청 횟수가 1 · 0, 읽은 값이 두 설정 모두 일치.

### T16. 순수 함수 목록
