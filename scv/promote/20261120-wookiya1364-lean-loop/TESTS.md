# Test Plan — 가벼운 에이전트 루프

## Overview

장부를 훅이 대신 하는지, 막힘이 줄었는지, 처음과 끝만 묻기 모드가 자리마다 맞게 묻는지, 기본값은 그대로인지 본다.

## Test scenarios

### T1. help 를 부르지 않아도 진단 · 안내가 실린다
- **Run**: 사람 턴 훅 실행.
- **Pass criterion**: 훅 출력에 진단 · 규약 안내가 있고, help 를 부르라는 지시는 없음(ends · all 공통).

### T2. 답 첫 줄 인용으로 등록된다
- **Run**: 인용이 있는 답 · 없는 답으로 종료 훅.
- **Pass criterion**: 있는 답은 등록 파일이 생기고 통과, 없는 답은 막힘(바로 고칠 수 있는 어김).

### T3. 대화 기록 · 표시를 종료 훅이 쓴다
- **Pass criterion**: 모델 도구 호출 없이 대화 기록에 그 턴이 남고 규약 표시가 갱신됨.

### T4. 막힘은 바로 고칠 수 있는 것만
- **Run**: 답 모양 어김 · 확인 범위 누락 · 인용 누락 · 언어 어김.
- **Pass criterion**: 인용 · 언어만 막고 나머지는 다음 턴 경고.

### T5. 처음과 끝만 묻기
- **Run**: SCV_ASK_MODE=ends(설정 파일 · 환경 변수 각각)로 계획 개요 · 중간 결정 · 첫 실행 확인 · 보관 · 끝 검증 · 배포 자리 판정.
- **Pass criterion**: 개요 · 끝 검증 · 배포는 묻기, 중간 결정 · 첫 실행 확인은 추천대로.

### T6. 기본값은 그대로
- **Run**: 설정 없음 · all.
- **Pass criterion**: 지금과 같은 출력(바이트 비교).

## How to run

```bash
bash core/tests/test-lean-loop.sh
```

## Pass criteria

- T1–T6 통과(맥 · 리눅스 · 코덱스 사본), 전체 실행 통과, 기존 기록 재계산 · 헤드리스 비교 수치가 마무리 보고에.
