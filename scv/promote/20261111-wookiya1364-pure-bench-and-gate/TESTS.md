# Test Plan — 재는 명령과 느려지면 막기

## Overview

재는 값이 믿을 만한지(흔들림 · GPU · 메모리 · 외부 명령 수), 판정 잣대가 실제로 쓴 것으로 골라지는지, 느려진 것은 막고 잴 수 없는 것은 숨기지 않는지를 본다.
T1–T7 · T16 은 실제 실행이 있는 시험, T8–T15 는 임시 폴더의 자동 시험, T17 은 전체 시험이다.

## Test scenarios

### T1. 반복 측정의 흔들림

- **Setup**: 사전의 순수함수 10개와 그 예시 입력.
- **Run**: 재는 명령을 같은 함수에 세 번.
- **Expected**: 판정 값(CPU 시간)이 세 번 사이에 거의 같다.
- **Pass criterion**: 함수 10개 모두 (가장 큰 값 − 가장 작은 값) ÷ 가장 작은 값 ≤ 0.05.

### T2. 붐비는 컴퓨터에서의 판정 값

- **Setup**: 코어 수만큼 바쁜 작업을 띄운 상태.
- **Run**: T1 과 같은 함수 10개.
- **Expected**: CPU 시간으로 판정한 값은 한가할 때와 거의 같다.
- **Pass criterion**: 붐빌 때 ÷ 한가할 때 ≤ 1.2 (10개 모두).

### T3. GPU 를 쓴 명령은 GPU 로 판정한다

- **Setup**: 셸에서 띄우는 GPU 작업 둘(작은 일 · 약 10배 큰 일). 2026-11-11 측정: 벽시계 1.1 ~ 1.4초 대 8.3초, CPU 시간 0.75 대 0.77초.
- **Run**: 재는 명령을 두 작업에.
- **Expected**: 판정 잣대가 "벽시계 · GPU"로 골라지고, 큰 일의 판정 값이 작은 일보다 크다.
- **Pass criterion**: 잣대 이름이 `wall-gpu`, 큰 일의 벽시계와 GPU 사용 시간이 작은 일의 3배 이상. CPU 시간으로 판정했다면 차이가 1.1배 안이라 통과했을 경우다.

### T4. GPU 를 읽을 도구가 없을 때

- **Setup**: GPU 읽는 도구를 찾지 못하게 한 환경에서 T3 의 GPU 작업.
- **Run**: 재는 명령.
- **Expected**: GPU 칸이 "재지 못함", 그 줄은 통과로 세지 않는다.
- **Pass criterion**: 표에 `재지 못함` 1번, 요약의 통과 수에 그 줄이 없음.

### T5. 띄운 외부 명령 수

- **Setup**: 시험용 함수 둘 — 줄마다 외부 명령을 띄우는 것, 전체에 한 번만 띄우는 것.
- **Run**: 입력 1배와 4배로.
- **Expected**: 앞의 것은 수가 4배로 늘고, 뒤의 것은 그대로다.
- **Pass criterion**: 수의 배수가 4.0 과 1.0.

### T6. 입력 4배 때의 배수

- **Setup**: 낱말 나누기 함수(`scv_tc_words`)와 줄 비교 함수(`scv_tc_diff`).
- **Run**: 재는 명령.
- **Expected**: 낱말 나누기는 약 12배(2026-11-11 측정 12.6배), 줄 비교는 약 4배(4.4배).
- **Pass criterion**: 낱말 나누기의 배수 ≥ 8 이고 "지금 넘는 곳" 목록에 오른다. 줄 비교의 배수 ≤ 6.

### T7. 메모리 최고치

- **Setup**: 시험용 함수 둘 — 큰 입력을 변수에 통째로 모으는 것, 한 줄씩 흘려보내는 것.
- **Run**: 재는 명령을 큰 입력으로.
- **Expected**: 모으는 쪽의 메모리 최고치가 뚜렷이 크다.
- **Pass criterion**: 모으는 쪽 ≥ 흘려보내는 쪽의 2배. 차이가 안 보이면 이 시험은 실패로 두고, 계획의 위험 절에 적은 대로 보고한다.

### T8. 판정 잣대 고르기 — 전수

- **Setup**: 없음(순수 함수).
- **Run**: `pb_pick_measure` 에 네 경우: CPU 에서만 일함 / GPU 를 씀 / 벽시계가 CPU 시간의 여러 배인데 GPU 도구 없음 / 너무 짧아 잴 수 없음.
- **Expected**: `cpu` · `wall-gpu` · `unmeasured` · `unmeasured`.
- **Pass criterion**: 네 출력이 그대로.

### T9. 앞뒤 비교 — 한도

- **Setup**: 없음(순수 함수).
- **Run**: `pb_compare` 에 뒤 값이 앞 값의 1.15배 / 1.25배 / 메모리만 1.25배이면서 +2MB / 메모리만 1.25배이면서 +0.3MB / 부른 횟수만 1 → 2 / 예시의 답이 달라진 경우.
- **Expected**: 통과 / 실패 / 실패 / 통과 / 실패 / 비교에서 뺌.
- **Pass criterion**: 판정 줄 여섯 개가 `pass` · `fail` · `fail` · `pass` · `fail` · `skipped-different-answer`. (한도는 1단계에서 사용자가 정한 값: 시간 1.2배 · 부른 횟수는 1번이라도 늘면 · 메모리는 1.2배를 넘고 1MB 넘게)

### T10. 같은 코드를 앞뒤로 넣으면 차이 없음

- **Setup**: 같은 함수를 "앞"과 "뒤"로.
- **Run**: 번갈아 재기.
- **Expected**: 배수가 1 에 가깝다.
- **Pass criterion**: 0.9 ≤ 배수 ≤ 1.1 (함수 5개 모두).

### T11. 일부러 느리게 만든 판은 막힌다

- **Setup**: 함수 하나를 줄마다 외부 명령을 띄우게 고친 사본.
- **Run**: 앞뒤 비교.
- **Expected**: 실패, 느려진 함수의 이름과 앞뒤 값이 줄에 있다.
- **Pass criterion**: 종료 코드 1, 출력에 그 함수 이름과 배수.

### T12. 기준 목록 — 늘면 실패, 줄면 내림

- **Setup**: 지금 넘는 곳 2개가 적힌 기준 목록.
- **Run**: 넘는 곳이 3개가 된 경우 / 1개로 준 경우 / 그대로.
- **Expected**: 실패 / 목록이 1개로 줄어 쓰임 / 통과.
- **Pass criterion**: 종료 코드 1 · 0 · 0, 둘째 경우 목록 줄 수 1.

### T13. 지나가는 길 — 선택 창 답

- **Setup**: 한도를 넘은 변경. 계획 기록에 그 함수에 대한 선택 창 답이 있는 경우와 없는 경우.
- **Run**: 막는 검사.
- **Expected**: 답이 있으면 통과하고 그 답이 기록에 남아 있다. 없으면 막히고 "선택 창으로 물어라"는 줄이 나온다.
- **Pass criterion**: 종료 코드 0 · 1, 막는 글에 앞뒤 값 · 배수 · 함수 이름.

### T14. 턴 끝 — 바뀐 함수만

- **Setup**: 순수함수 파일을 하나도 안 고친 턴 / 함수 둘을 고친 턴.
- **Run**: 턴 끝 검사.
- **Expected**: 앞의 턴은 재는 명령이 0번 돈다. 뒤의 턴은 그 둘만 잰다.
- **Pass criterion**: 잰 함수 수 0 과 2.

### T15. 합성 함수

- **Setup**: 5단계에서 정한 합성 함수 둘 이상.
- **Run**: 재는 명령.
- **Expected**: 묶음 전체의 값과 단계 값의 합이 표에 나란히 있고, 입력 4배 때 외부 명령 수의 배수가 있다.
- **Pass criterion**: 합성 함수 줄마다 두 값과 배수가 비어 있지 않음.

### T16. 전체 한 번

- **Setup**: 사전에 오른 순수함수 전체.
- **Run**: 재는 명령을 전체에.
- **Expected**: 표 끝에 잰 수 · 못 잰 수와 이유(예시 없음 · 늘릴 수 없음 · 재지 못함)가 있다.
- **Pass criterion**: 잰 수 + 못 잰 수 = 사전의 함수 수. 표를 사용자에게 보인다.

### T17. 순수 함수 목록과 전체 시험

- **Setup**: 없음.
- **Run**: 순수 함수 목록 시험, 전체 시험(4개씩, bash 3.2 · bash 5).
- **Expected**: 새 순수 함수 여섯이 목록에 있고 예가 실제 출력과 같다. 새로 실패한 시험 0개.
- **Pass criterion**: 두 bash 모두 실패 0개.

## How to run

```bash
bash core/tests/test-pure-bench.sh
```

## Pass criteria

- T1–T17 통과. T7 이 통과하지 못하면 메모리는 "큰 입력에서만 뜻이 있음"으로 보고하고 사용자와 다시 정한다.
- 리눅스 GPU 는 돌려 보지 않는다 — 보고에 그렇게 적는다.
