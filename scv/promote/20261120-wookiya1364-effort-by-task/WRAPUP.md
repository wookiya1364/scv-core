## 1. 문제

- 상황: SCV 는 모델별 권장 effort 한 값만 보고 세션당 한 번 묻는다. 공식 문서는 질의 난이도에 맞춰 effort 를 달리하되, 캐시를 쓰는 대화에서는 요청 전체 값을 자주 바꾸지 말라고 한다.
- 기대: 일의 종류가 크게 바뀔 때만 알맞은 effort 를 추천하고, 큰 일은 새 세션으로 나눠 이 세션 캐시를 지킨다.
- 실제: 일의 종류와 상관없이 같은 권장값을 한 번만 물음. 사용자가 effort 를 바꾸면 캐시가 깨지는지 SCV 는 모름.
- 재현 조건: 가벼운 대화로 시작한 세션에서 긴 계획 구현으로 넘어가도 effort 추천이 다시 나오지 않음.

## 2. 관찰

- 관찰한 사실과 측정값: 긴 실제 세션 3,740 응답 중 큰 캐시 미스 13번(대화 요약 8 · 1시간 넘게 쉼 3 · 모델 변경 1 · 그 밖 1), 이 세션 1,180 응답 중 8번(요약 5 · 쉼 2 · 모델 1).
- 정상일 때와 차이: SCV 훅 글은 사용자 메시지 뒤에 붙기만 해 캐시 미스를 만들지 않음 — 미스는 요약 · 오래 쉼 · 모델 변경에서 남.
