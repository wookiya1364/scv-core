# 순수함수 사전 — 차례

> 생성물 — 손으로 고치지 말 것. 다시 만들기: `bash core/scripts/pure-catalog.sh build`
>
> 새 함수를 만들기 전에: 아래에서 종류를 고르고, 그 종류 파일 하나만 연다.

| 종류 | 하는 일 | 개수 | 파일 |
|---|---|---|---|
| 다듬기 | 글자를 정리한다 — 공백 · 대소문자 · 이스케이프 · 자르기 | 13 | [tidy.md](tidy.md) |
| 꺼내기 | 글 · JSON · 표에서 값이나 필드를 뽑는다 | 46 | [extract.md](extract.md) |
| 세기 | 개수 · 길이 · 합계를 센다 | 14 | [count.md](count.md) |
| 비교 | 둘을 비교해 순서나 같음을 낸다 — 버전 · 숫자 · 집합 | 1 | [compare.md](compare.md) |
| 판정/answer | 답 · 메시지 글을 보고 판정한다 — 표가 있나, 묻는 글인가, 확인인가 | 22 | [judge-answer.md](judge-answer.md) |
| 판정/gate | 훅이 막을지 · 넘길지 · 다시 물을지를 정한다 | 19 | [judge-gate.md](judge-gate.md) |
| 판정 | 입력을 보고 예/아니오나 판정 이름 하나를 낸다 | 22 | [judge.md](judge.md) |
| 고르기 | 여럿 중 일부를 골라내거나 순서를 매긴다 | 28 | [select.md](select.md) |
| 조립 | 조각을 받아 정해진 모양의 글을 만든다 — 줄 · 표 · 메시지 | 52 | [build.md](build.md) |
| 변환 | 한 표기를 다른 표기로 바꾼다 — 경로 · 날짜 · 단위 · 인코딩 | 22 | [convert.md](convert.md) |
| 지문 | 내용에서 짧은 식별값을 만든다 — 해시 · 키 · 이름 | 6 | [fingerprint.md](fingerprint.md) |
