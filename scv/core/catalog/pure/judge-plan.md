# 판정/plan — 입력을 보고 예/아니오나 판정 이름 하나를 낸다

> 생성물 — 원본은 각 함수 위 주석(역할 · 종류 · 예). 1개.

### scv_tc_plan_handled
- 역할: 계획 하나가 이번 턴에 다뤄졌는지 가린다 — 턴 시작 때 없었거나, 글 길이가 달라졌거나, 턴 시작보다 새것이면 다룬 것
- 위치: scripts/lib/turn-check.sh · @pure · sh
- 예: `$'p1\t100' "p1" 100 0 → "no"`
- 예: `$'p1\t100' "p1" 130 0 → "yes"`
- 예: `$'p1\t100' "p2" 50 0 → "yes"`
- 예: `$'p1\t100' "p1" 100 1 → "yes"`
- 예: `"@none" "p1" 100 0 → "no"`
