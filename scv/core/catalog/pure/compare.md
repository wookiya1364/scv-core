# 비교 — 둘을 비교해 순서나 같음을 낸다 — 버전 · 숫자 · 집합

> 생성물 — 원본은 각 함수 위 주석(역할 · 종류 · 예). 3개.

### scv_tc_diff
- 역할: 시작 사진과 끝 사진("경로<TAB>지문" 줄들)을 견줘 이번 턴에 바뀐 경로만 낸다 — 새로 생김 · 지문이 바뀜 · 사라짐
- 위치: scripts/lib/turn-check.sh · @pure · sh
- 예: `$'a\t1\nb\t2' $'a\t1\nb\t3\nc\t9' → $'b\nc'`
- 예: `$'a\t1\nb\t2' $'a\t1' → "b"`
- 예: `$'a\t1' $'a\t1' → ""`

### scv_tc_new_lines
- 역할: 정렬된 두 묶음에서 뒤 묶음에만 있는 줄을 낸다 — 같은 줄이 늘어난 것도 센다
- 위치: scripts/lib/turn-check.sh · @pure · sh
- 예: `$'a\nb' $'a\nb\nc' → "c"`
- 예: `$'a' $'a\na' → "a"`
- 예: `$'a\nb' $'a' → ""`

### scv_ver_lt
- 역할: 첫 버전이 둘째 버전보다 낮으면 참(숫자로 비교, 접미사는 무시)
- 위치: scripts/lib/template-digest.sh · @pure · sh
- 예: `0.9.1 0.10.0 → ""`
- 예: `1.2.3 1.2.3 → "" [1]`
- 예: `0.10.0 0.9.1 → "" [1]`
