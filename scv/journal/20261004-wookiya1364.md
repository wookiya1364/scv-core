3. **Minor, but major for automation-heavy projects (performance) — `model-prompting.sh:103-117`, `on-user-prompt.sh:133`.**
   - The newest-session lookup runs on every call without `--session`. That includes the `kind` call the prompt hook makes on every prompt, and `help.sh`. It costs about 4 process forks per session folder.
   - Measured on macOS:

     | Session folders | `kind` call | Prompt hook | Stop hook without session id |

     | 1 | 0.05s | — | — |
     | 301 | 1.2s | 1.7s | — |
     | 1001 | 3.9s | 4.3s | 12.2s |

   - One folder is kept per session for 14 days, so headless or Ralph-loop runs pile them up. This project currently has about 20, which costs about 80ms.
   - Fix:
     - Only resolve the session for subcommands that use per-turn state.
     - Pass `--session` to `kind`.
     - Use one `ls -t` call instead of a `stat` per folder.
