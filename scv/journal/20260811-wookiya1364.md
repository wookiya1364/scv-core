**`scv/journal/<YYYYMMDD>-<author>.md`**

훅이 씁니다. `on-user-prompt.sh`는 **모든** 사용자 프롬프트를, `on-stop.sh`는 어시스턴트 응답 요약을 자동으로 append합니다. `action:*`을 한 번도 부르지 않은 자유대화까지 들어갑니다. 파일명이 날짜+작성자인 건 여러 명이 같은 날 기록해도 git 충돌이 안 나게 하려는 것이고, **수명주기가 없습니다** — archive도 없고 그냥 계속 쌓입니다. 무엇의 입력도 아닌 **주변 기록**입니다.
