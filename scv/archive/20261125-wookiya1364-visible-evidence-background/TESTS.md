# Test Plan — 단계 증거를 눈에 보이게 · 뒤에서 도는 일은 뒤에서

## Overview

단계 끝 증거가 눈에 보이는 것만 받는지, 화면이 없는 단계의 함수 목록이 끝난 뒤에도 남는지, 뒤에서 도는 단계가 따로 표시되는지, 앞에서 오래 기다리는 호출이 거절되는지 본다. T1–T4 는 대시보드 모드의 시험, T5–T9 는 본체 시험이다.

## Test scenarios

### T1. 소스코드 파일은 증거로 받지 않는다

- **Setup**: 진행 중인 계획의 단계.
- **Run**: 단계 보고 도구에 `done` 과 스크립트 파일 경로를 준다. 이어서 이미지 파일 경로를 준다.
- **Expected**: 첫 번째는 거절(눈에 보이는 증거를 붙이라는 안내), 두 번째는 통과.
- **Pass criterion**: 모드 시험에서 두 판정이 그대로다.

### T2. 함수가 적힌 단계는 파일 없이 통과하고, 목록이 끝난 뒤에도 보인다

- **Setup**: 줄 끝에 함수 이름이 적힌 단계.
- **Run**: 파일 없이 `done` 을 보낸 뒤 창의 그 단계를 본다.
- **Expected**: 통과하고, 끝난 단계에 새로 만든 함수 · 다시 쓴 함수 목록이 보인다.
- **Pass criterion**: 모드 시험에서 판정 통과와 목록 줄이 있다.

### T3. 그림도 함수도 없는 단계는 거절한다

- **Setup**: 줄에 함수 이름이 없는 단계.
- **Run**: 파일 없이, 출력 발췌만 주고 `done` 을 보낸다.
- **Expected**: 거절(화면 사진 · 영상 · 차트를 붙이라는 안내).
- **Pass criterion**: 모드 시험에서 거절 이유 글이 있다.

### T4. 뒤에서 도는 단계는 "진행 중(백그라운드)"

- **Setup**: 진행 중인 계획.
- **Run**: `doing` 을 세 가지로 보낸다 — `background: true`, `log` 만, 아무것도 없이.
- **Expected**: 앞의 둘은 "진행 중(백그라운드)", 마지막은 "진행 중".
- **Pass criterion**: 모드 시험에서 세 글이 그대로다.

### T5. 막대 그림을 만든다

- **Setup**: "통과=124", "실패=2" 두 줄.
- **Run**: `evidence.sh card` 로 프로젝트 안 경로에 쓴다.
- **Expected**: SVG 파일이 생기고 제목 · 두 이름 · 두 값이 들어 있다.
- **Pass criterion**: 파일이 `<svg` 로 시작하고 네 글이 모두 있다. 같은 입력이면 바이트까지 같은 파일.

### T6. 그림은 프로젝트 안에만 쓴다

- **Setup**: 프로젝트 밖 경로, 심볼릭 링크 경로.
- **Run**: `evidence.sh card` 에 그 경로를 준다.
- **Expected**: 쓰지 않고 종료 코드 2.
- **Pass criterion**: 파일 없음, 종료 코드 2.

### T7. 앞에서 오래 기다리는 호출을 거절한다

- **Setup**: 가드에 줄 훅 입력 셋 — 대기 값 200초인 도구 호출, 잠자기 120초를 앞에서 도는 셸 명령, 잠자기로 도는 기다림 루프.
- **Run**: 가드를 돌린다.
- **Expected**: 셋 다 거절, 이유 글에 뒤에서 돌리라는 안내.
- **Pass criterion**: 거절 결정과 안내 글.

### T8. 보통 호출은 건드리지 않는다

- **Setup**: 대기 값 5초인 도구 호출, 뒤로 보낸 긴 셸 명령, 잠자기가 없는 보통 셸 명령, 잠자기 2초가 든 명령.
- **Run**: 가드를 돌린다.
- **Expected**: 넷 다 통과.
- **Pass criterion**: 이 규칙의 거절 0건.

### T9. 끄는 설정

- **Setup**: `SCV_BACKGROUND_FIRST=off`.
- **Run**: T7 의 입력으로 가드를 돌린다.
- **Expected**: 이 규칙으로는 거절하지 않는다.
- **Pass criterion**: 거절 0건.

### T10. 실제 창의 세 장면

- **Setup**: 고친 모드를 얹은 실제 앱.
- **Run**: 계획 하나를 진행하며 세 장면을 만든다.
- **Expected**: 그림 증거가 붙은 끝난 단계, 함수 목록이 남은 끝난 단계, "진행 중(백그라운드)".
- **Pass criterion**: 화면 사진 세 장을 사용자에게 보였다는 기록이 변경 이력에 있다.

## How to run

```bash
bash core/tests/test-evidence-card.sh && bash core/tests/test-guard-wait.sh
```

## Pass criteria

- T5–T9 통과(맥 기본 셸 · 새 셸), 모드 시험(T1–T4) 통과, 관련 시험(가드 · 템플릿 지문 · 순수성 · 호스트 이름) 통과, 깃허브 검사 통과.
- T10 의 화면 사진 기록.
