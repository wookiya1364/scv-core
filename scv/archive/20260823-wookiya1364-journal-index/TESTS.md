# Test Plan — 저널 색인

## Overview

확인하는 것: 순수부가 고정 입력에 고정 출력을 내는지, 표시가 알려진 것만
통과하는지, 같은 이름은 최신이 이기는지, 읽을 때 저널을 훑지 않는지, 저널이
편집되면 조용히 엉뚱한 내용을 주지 않는지, 색인이 없거나 깨져도 기록이 계속되는지.

**판정은 전부 문자열 비교다.** 순수성은 `check-purity.sh` 가 본다.

## Test scenarios

### T1. 표시 정규화 — 18가지 전수  ✅ `18/18`
- **Setup**: 알려진 표시 넷 × (그대로 / 대문자 / 앞뒤 공백) + 알 수 없는 값 여섯.
- **Expected**: 알려진 것만 소문자로 통과. 나머지는 빈 값.
- **여기서 잡힌 것**: `"de cision"` 이 `decision` 으로 통과했다 — 가운데 공백까지
  지우고 있었다. 문서는 "앞뒤 공백만" 이라고 적혀 있었으니 코드가 틀렸다.
  오타를 몰래 고치면 무엇이 기록됐는지 부르는 쪽이 모른다.

### T2. 레코드 — 잘못된 입력은 빈 값  ✅
- **Expected**: 알 수 없는 표시 / 숫자 아닌 오프셋 / 길이 0 / 음수 길이 / 키 없음
  / 파일 없음 → 전부 빈 값. 탭·줄바꿈이 섞여도 **한 줄**을 유지한다.
- **왜**: 한 줄 한 레코드가 깨지면 색인 전체를 못 읽는다.

### T3. 조회 — 같은 이름은 최신이 이긴다  ✅
- **Expected**: 같은 키가 여러 번이면 마지막 것. 없는 키·빈 색인·빈 키 → 빈 값.
- **반복 가능성**: 같은 입력 50회 → 같은 출력. 이것이 깨지면 나머지가 무의미하다.

### T4. 걸러내기 — 옛 레코드는 빠진다  ✅
- **Expected**: 전부 조회 시 같은 키는 하나만. 표시로 거르면 그것만. 없는 표시 → 0건.

### T5. 순수성  ✅
- **Expected**: 선언된 다섯 함수 전부 위반 0건.
- **여기서 잡힌 것**: 처음 구현이 소문자 변환에 `tr`, 필드 대입에 `printf -v` 를
  썼다. 둘 다 셸 안에서 되는 일이라 외부 도구를 쓸 이유가 없었다 — 규칙이 옳았다.

### T6. 저널을 훑지 않는가  ✅
- **Setup**: 표시 3건 + 표시 없는 턴 8건.
- **Expected**:
  - 색인에 **표시한 것만** 3건
  - 같은 이름의 **최신** 결정이 읽힌다
  - 표시 안 한 턴은 결과에 **안 섞인다**
  - **읽은 양이 저널의 절반 미만** (실측 126B / 870B)
  - 정상 읽기는 **조용하다**

### T7. 편집 감지  ✅
- **Setup**: 저널에서 한 줄을 지운다.
- **Expected**: 위치가 어긋났다고 알린다. 그래도 **exit 0** — 부르는 쪽을 막지 않는다.
- **두 가지를 본다**: 길이는 **잘림**을, 시작 모양은 **밀림**을 잡는다. 앞줄이
  지워지면 길이는 그대로인데 다른 항목이 읽히므로 길이만으로는 부족하다.

### T8. 없어도 죽지 않는가  ✅
- **Expected**: 색인 없음 / 깨진 색인 → exit 0. 알 수 없는 표시로 기록해도 저널은
  써지고, 그 사실을 알리고, 색인에는 안 들어간다.

### T9. 회귀 — 기존 스위트  ✅
- **Expected**: run-dry 977 PASS / 0 FAIL, tests/run.sh 통과, core/tests 실패 0.

## How to run

```bash
bash core/tests/test-journal-index.sh            # T1–T8
bash core/scripts/check-purity.sh                # T5
bash core/tests/run-dry.sh && bash tests/run.sh  # T9
```

## 아직 안 한 것

- **컨텍스트 자동 비우기는 없다.** 호스트가 그 기능을 주지 않는다(조사 완료:
  훅이 비우기를 걸 수 없고, 훅 출력 제어값에 그런 항목이 없다). 색인은 비운 뒤
  다시 채우는 쪽을 싸게 만든다.
- **무엇이 의미 있는지 자동 판단하지 않는다.** 표시는 쓰는 쪽이 붙인다.
  자유 텍스트 휴리스틱은 한국어·영어가 섞이면 신뢰할 수 없다.
