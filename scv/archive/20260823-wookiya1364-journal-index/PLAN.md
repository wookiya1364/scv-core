# 저널 색인

## Summary

저널은 모든 턴을 그대로 쌓는다. 오늘 하루치가 이미 62KB · 915줄 · 43항목이다.
지난 대화를 찾으려면 파일 전체를 읽어야 하고, 그러면 컨텍스트가 그만큼 찬다.

**의미 있는 것만 표시하고, 그것만 위치로 바로 읽는다.** 저널 본문은 훑지 않는다.

이것이 세 요구가 만나는 지점이다 — 컨텍스트를 줄이고(#1), 순수함수로만 이뤄지고
(#2), 완료기준이 실행 가능한 테스트로 떨어진다(#3).

## Goals / Non-Goals

**Goals**

1. 쓰는 시점에 **표시**를 붙인다 — 결정 / 계획 / 막힘 / 방향전환.
2. 표시된 항목의 **위치**(파일·바이트 오프셋·길이)를 색인에 적는다.
3. 읽을 때 **저널을 훑지 않는다.** 색인에서 위치를 얻어 그 구간만 읽는다.
4. 색인이 없거나 깨져도 기록은 계속된다.

**Non-Goals**

- **무엇이 의미 있는지 자동으로 판단하지 않는다.** 자유 텍스트 휴리스틱은 한국어·
  영어가 섞이면 신뢰할 수 없다. 표시는 부르는 쪽이 붙인다.
- 컨텍스트를 자동으로 비우지 않는다. 호스트가 그 기능을 주지 않는다(조사 완료).
  색인은 비운 뒤 다시 채우는 쪽을 싸게 만든다.
- 기존 저널 형식을 바꾸지 않는다. 색인은 옆에 붙는 별도 파일이다.

## 함수와 층

| 이름 | 층 | 입출력 |
|---|---|---|
| `journal_mark_normalize` | `@pure` | 표시 문자열 → 정규화된 표시 또는 빈 값 |
| `journal_index_record` | `@pure` | 표시·키·파일·오프셋·길이·시각 → 색인 한 줄 |
| `journal_index_lookup` | `@pure` | 색인 텍스트 + 키 → 레코드 한 줄 (없으면 빈 값) |
| `journal_index_filter` | `@pure` | 색인 텍스트 + 표시 → 해당 레코드들 |
| `journal_index_fields` | `@pure` | 레코드 한 줄 → 탭 구분 필드 |
| `journal_append_marked` | 효과 | 저널에 쓰고, 쓰기 전 크기를 재어 위치를 색인에 적는다 |
| `journal_read_at` | 효과 | 파일·오프셋·길이 → 그 구간만 읽는다 |

**순수부는 색인 텍스트만 다룬다.** 파일을 여는 것은 효과층 둘뿐이다.

### 왜 오프셋인가

색인이 위치를 들고 있으면 읽을 때 저널을 훑지 않는다. 파일 크기와 무관하게
`tail -c +N | head -c LEN` 한 번이다.

**정확히 말하면**: 저널 본문 탐색은 상수 시간이고, 읽는 양은 그 항목 크기만큼이다.
색인 자체는 표시된 항목 수만큼이라 저널보다 훨씬 작다 — 오늘치로 치면 43항목 중
표시된 몇 개뿐이다. "저널을 안 훑는다" 가 요점이지 색인 조회까지 상수라는 뜻은
아니다.

### 색인 형식

탭 구분 한 줄에 하나. append-only — 기존 줄을 고치지 않는다.

```
<표시>	<키>	<파일>	<오프셋>	<길이>	<시각>	<한 줄 요약>
```

키는 사람이 부르는 이름이다(`settings-migration` 처럼). 같은 키가 여러 번 나오면
**마지막 것이 이긴다** — 나중 기록이 그 주제의 최신 상태다.

### 표시 종류

| 표시 | 언제 |
|---|---|
| `decision` | 방향을 정한 순간 |
| `plan` | 계획을 만들거나 보관한 순간 |
| `blocker` | 막혔고 그 이유를 알아낸 순간 |
| `pivot` | 하던 것을 접거나 바꾼 순간 |

알 수 없는 표시는 조용히 무시한다 — 저널 기록 자체는 막지 않는다.

## 위험과 대응

| 위험 | 대응 |
|---|---|
| **오프셋이 어긋난다** | 쓰기 직전 크기를 재고, 쓴 뒤 실제 크기와 대조한다. 어긋나면 색인에 적지 않는다 |
| 저널이 손으로 편집된다 | 색인 레코드에 길이를 함께 적어, 읽은 내용이 예상 길이와 다르면 알린다 |
| 색인이 깨진다 | 읽기가 빈 값을 내고 진행은 계속된다. 기록은 색인과 무관하게 돈다 |
| 비밀값이 새어든다 | 위치는 **redaction 이 끝난 뒤**에만 기록된다. 요약도 같은 필터를 거친다 |
