# Test Plan — 갱신은 이미 자동이다

## Overview

바꾸는 것은 **보고 경로**다. 갱신 자체는 이미 돌고 있으므로, 검사는 "갱신이 일어난
턴에 사용자가 그것을 읽을 수 있는가" 와 "그 외의 턴은 여전히 조용한가" 두 축이다.

침묵 쪽 검사가 더 중요하다. 보이게 만드는 변경은 언제나 반대편으로 새기 쉽고, 훅
출력이 시끄러워지면 지금까지 쌓아 온 preflight 블록의 신뢰가 무너진다. T2·T3 이
그 방어선이다.

## Test scenarios

### T1. 갱신이 일어난 턴에 결과가 보인다

이 계획의 핵심이다. 갱신됐는데 화면이 조용하면 사용자는 손으로 sync 를 친다.

- **Setup**: 하이드레이트된 임시 프로젝트. `SCV.md` 의 템플릿 도장을 배포본보다
  낮은 값으로 되돌려 갱신이 필요한 상태를 만든다.
- **Run**: 프롬프트 훅을 한 번 실행한다.
- **Expected**: 훅 출력에 워크플로 문서가 새로고침됐다는 보고 줄이 있다.
- **Pass criterion**: 갱신 보고 줄이 출력에서 확인되고, 그 줄이 지시 블록 뒤·진단
  앞에 있다.

### T2. 갱신할 것이 없으면 아무 줄도 나오지 않는다

침묵이 기본값이다. 매 턴 "최신입니다" 가 찍히면 그것이 곧 소음이다.

- **Setup**: 하이드레이트된 임시 프로젝트, 도장이 배포본과 같은 상태(= 갱신 불필요).
- **Run**: 프롬프트 훅을 한 번 실행한다.
- **Expected**: 갱신에 관한 줄이 하나도 없다.
- **Pass criterion**: 출력에 갱신 보고 문구가 나타나지 않는다. 지시 블록과 진단은
  평소대로 나온다.

### T3. 점검 스크립트의 다른 stderr 는 새지 않는다

`2>/dev/null` 을 걷어내면 나머지 stderr 가 통째로 쏟아질 위험이 생긴다. 고른 줄만
실어야 한다.

- **Setup**: T2 와 같은 프로젝트. 점검 스크립트가 갱신과 무관한 경고를 stderr 로
  내도록 상황을 만든다.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 그 무관한 경고는 훅 출력에 없다.
- **Pass criterion**: 갱신 보고 이외의 stderr 문자열이 출력에 나타나지 않는다.

### T4. 훅은 어떤 경우에도 막지 않는다

- **Setup**: 점검 스크립트가 실패하도록(비정상 종료) 만든 프로젝트.
- **Run**: 프롬프트 훅을 실행하고 종료 코드를 본다.
- **Expected**: 종료 코드 0.
- **Pass criterion**: 종료 코드가 0 이고, 지시 블록은 그대로 나온다.

### T5. 자동 갱신이 꺼져 있으면 기존 안내가 그대로 나온다

껐을 때의 계약은 바뀌지 않는다 — 파일은 안 건드리되 어긋남은 알린다.

- **Setup**: 갱신이 필요한 프로젝트에서 자동 갱신 스위치를 끈다.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: "문서가 낡았고 자동 갱신이 꺼져 있으니 sync 를 돌리라" 는 기존
  안내가 보인다.
- **Pass criterion**: 그 안내 문구가 확인되고, 프로젝트 파일은 바뀌지 않는다.

### T6. scv 폴더가 없으면 아무 출력도 없다

- **Setup**: scv 를 채택하지 않은 빈 임시 디렉터리.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 출력 없음, 종료 코드 0.
- **Pass criterion**: 표준출력이 비어 있다.

### T7. 래퍼 문서에 강요 문구가 남아 있지 않다

이 저장소 밖이라 강제할 수 없다. 옆에 체크아웃이 있을 때만 돌고, 없으면 건너뛴다 —
건너뜀은 실패가 아니다.

- **Setup**: 형제 경로에 두 래퍼 저장소가 있는 경우에만 진행한다.
- **Run**: 세 문서에서 "sync 를 따로 실행하라"는 취지의 문장을 찾는다.
- **Expected**: 세 곳 모두 없고, 대신 "다시 불러온 뒤 첫 액션이 자동으로 닫는다"는
  취지의 문장이 있다.
- **Pass criterion**: 강요 문구 0건, 대체 문구 3건. 체크아웃이 없으면 SKIP.

## How to run

```bash
bash core/tests/test-autosync.sh
```

## Pass criteria

- T1~T6 모두 통과. T7 은 통과 또는 SKIP.
- 갱신이 필요 없는 평상시 턴의 훅 출력이 이전과 한 글자도 다르지 않다.
