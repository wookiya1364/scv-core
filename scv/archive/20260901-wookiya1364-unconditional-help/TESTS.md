# Test Plan — 분류를 걷어내고 무조건 부르게

## Overview

검사는 두 축이다. 하나는 **없어졌는가** — 갈래·분류·조건이 지시 블록에 남아 있지
않은가. 다른 하나는 **이어받았는가** — 대체되는 계획이 지키던 성질이 새 검사에
살아 있는가.

둘째 축이 더 위험하다. supersedes 를 선언하면 그 계획의 검사가 회귀에서 빠지므로,
거기 있던 성질을 여기서 다시 세우지 않으면 조용히 사라진다. T5~T8 이 그 방어선이다.

## Test scenarios

### T1. 지시 블록에 갈래가 없다

이 계획의 핵심이다. 갈래가 하나라도 남으면 원인이 그대로 남는다.

- **Setup**: scv 폴더가 있는 임시 프로젝트, 스위치 기본값.
- **Run**: 프롬프트 훅을 실행하고 지시 블록을 본다.
- **Expected**: A/B/C 같은 갈래 표시가 없고, "셋 중 하나를 고르라" 는 취지의 문장도
  없다.
- **Pass criterion**: 갈래 표지가 0건.

### T2. 명령이 하나이고 조건이 없다

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: "답을 쓰기 전에 이 메시지 전문을 인자로 help 를 지금 호출하라" 는
  취지의 명령이 있고, 그 명령에 조건절이 붙어 있지 않다.
- **Pass criterion**: 호출 명령이 확인되고, "…이면" 형태의 조건이 명령에 붙어 있지
  않다.

### T3. 부르지 않아도 되는 경우가 둘만 명시돼 있다

예외가 없으면 자기 자신을 다시 부르고, 예외가 많으면 다시 분류가 된다.

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: 이미 SCV 액션이 실린 턴, 그리고 사람이 쓰지 않은 자동 알림 —
  이 둘이 예외로 적혀 있다.
- **Pass criterion**: 두 예외가 모두 확인된다.

### T4. 왜 불러야 하는지의 이유가 남아 있다

볼륨 대신 이유를 준다는 것이 이 계열 계획의 설계 선택이다. 문구가 사라지면 선택도
사라진다.

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: 부르지 않으면 논의가 파일로 남지 않는다는 사실이 블록에 있다.
- **Pass criterion**: 그 취지의 문장이 확인된다.

### T5. 스위치를 끄면 아무 것도 주입하지 않는다

대체되는 계획에서 이어받는 성질 (1/4).

- **Setup**: 라우팅 스위치를 끈 프로젝트.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 지시도 진단도 나오지 않는다.
- **Pass criterion**: 지시 표지와 진단 표지가 모두 없다.

### T6. scv 폴더가 없으면 출력이 없다

이어받는 성질 (2/4).

- **Setup**: scv 를 채택하지 않은 빈 임시 디렉터리.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 출력 없음, 종료 코드 0.
- **Pass criterion**: 표준출력이 비어 있다.

### T7. 훅은 어떤 경우에도 막지 않는다

이어받는 성질 (3/4).

- **Setup**: 점검 스크립트가 비정상 종료하도록 만든 상황.
- **Run**: 프롬프트 훅을 실행하고 종료 코드를 본다.
- **Expected**: 종료 코드 0, 지시 블록은 그대로 나온다.
- **Pass criterion**: 종료 코드가 0 이고 지시 표지가 확인된다.

### T8. 같은 요구를 하는 블록이 하나뿐이다

이어받는 성질 (4/4). 무시되는 지시가 둘이면 서로를 약화시킨다.

- **Setup**: T1 과 같다.
- **Run**: 훅 출력 전체를 본다.
- **Expected**: help 호출을 요구하는 블록이 하나다.
- **Pass criterion**: 호출을 요구하는 표지가 1건.

### T9. 쉬운말 블록은 라우팅과 무관하다

- **Setup**: 라우팅 스위치를 끈 프로젝트.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 쉬운말 안내는 그대로 나온다.
- **Pass criterion**: 쉬운말 표지가 확인된다.

### T10. 지시 블록이 전보다 짧다

분류를 걷어낸 만큼 줄어야 한다. 늘어났다면 갈래를 말로 바꿔 남긴 것이다.

- **Setup**: 없음 — 지시 블록을 직접 만들어 본다.
- **Run**: 블록의 줄 수를 센다.
- **Expected**: 21줄보다 적다.
- **Pass criterion**: 줄 수 < 21.

### T11. help 에 돌려보내는 갈래가 없다

초안의 실수를 막는 검사다. 출구를 지침에서 액션으로 옮기기만 하면 같은 구멍이
자리만 바꾼다.

- **Setup**: 없음.
- **Run**: help 프로토콜 문서를 읽는다.
- **Expected**: "남길 논의가 없으니 아무것도 쓰지 않고 끝낸다" 는 취지의 갈래가
  없다.
- **Pass criterion**: 그런 갈래가 0건.

### T12. 짧은 턴은 세션의 대화 파일에 이어 붙는다

돌려보내지 않으므로 반드시 기록이 남되, 파일이 폭증하지 않아야 한다.

- **Setup**: 없음.
- **Run**: help 프로토콜 문서를 읽는다.
- **Expected**: 짧은 턴을 새 파일이 아니라 세션의 대화 파일에 이어 붙인다는 규칙이
  있고, 세션 파일이 아직 없으면 하나를 연다는 것도 적혀 있다.
- **Pass criterion**: 두 문장이 모두 확인된다.

## How to run

```bash
bash core/tests/test-force-help.sh
```

## Pass criteria

- T1~T12 모두 통과.
- 대체되는 계획의 성질 넷(T5~T8)이 새 검사에 살아 있다.
