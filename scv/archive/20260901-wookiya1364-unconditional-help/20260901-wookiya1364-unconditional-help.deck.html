# 분류를 걷어내고 무조건 부르게 — 판단은 help 가 한다

## Summary

0.41.0 이 지시를 맨 앞으로 옮기고 조건문을 명령으로 바꿨는데도 호출이 여전히 안 된다.
남아 있던 원인은 **세 갈래 자체**다. 블록이 행동을 시키기 전에 **판단을 시키고**,
그 판단에 "부르지 않아도 된다" 는 정당한 출구가 있다. 애매한 턴은 전부 그쪽으로 샌다.
분류를 지침에서 걷어내고 help 안으로 옮긴다.

## Goals / Non-Goals

- **Goals**
  - 지시 블록에서 갈래·분류·조건을 없앤다. 남는 것은 명령 하나다.
  - 부르지 않아도 되는 경우를 둘로 못 박는다 — 그 외에는 예외가 없다.
  - help 는 **항상 자기 일을 한다.** 일반 응답으로 돌려보내는 갈래를 두지 않는다.
- **Non-Goals**
  - 스위치를 없애지 않는다. 끄면 여전히 아무 것도 주입하지 않는다.
  - 훅의 비차단 보장을 건드리지 않는다.
  - help 의 기존 세 모드(진단·대화·기록 검색)를 바꾸지 않는다.

## Approach Overview

지금 블록은 이렇게 말한다: "셋 중 하나를 고르고, 고른 것을 실행하라." 고르는 일이
행동보다 앞에 있다. 그리고 셋째 갈래는 "아무 것도 부르지 말라" 다 — 즉 **아무 것도
하지 않는 것이 정답인 경우가 명시돼 있다.** 애매한 입력 앞에서 두 갈래(호출)와 한
갈래(침묵) 중 침묵이 언제나 더 싸다. 볼륨을 아무리 올려도 이 비대칭은 남는다.

그래서 판단을 옮긴다. 지침은 조건 없는 한 문장이 된다 — "답을 쓰기 전에 이 메시지
전문을 인자로 help 를 지금 호출하라. 판단하지 말고 부르라." 모델에게 남는 선택지가
없어지므로 샐 곳도 없다.

여기서 한 번 더 걸러야 할 것이 있다. 처음 안은 help 안에 "남길 논의 없음 → 아무
것도 쓰지 않고 끝" 이라는 갈래를 새로 두는 것이었는데, 그것은 **출구를 지침에서
액션으로 옮겼을 뿐 출구 자체는 살려 둔 것**이다. 같은 구멍이 자리만 바꾼다. 그래서
그 갈래를 두지 않는다 — **help 는 돌려보내지 않고 항상 기록한다.**

대신 기록의 **모양**을 정한다. 짧은 턴마다 새 대화 파일을 만들면 하루면 폴더가
잡음으로 찬다. 그래서 짧은 턴은 이 세션이 이미 쓰고 있는 대화 파일에 **이어
붙인다.** 돌려보내는 일이 없으므로 요구는 그대로 만족되고, 기록은 쓸모를 잃지
않는다.

무조건에서 빼야 하는 경우는 둘뿐이고, 둘 다 빼지 않으면 동작이 깨진다. 이미 SCV
액션이 도는 턴에서 다시 부르면 자기 자신을 부른다. 사람이 쓰지 않은 자동 알림에는
남길 논의가 없다. 이 둘은 분류가 아니라 **정의상 해당 없음**이므로 블록에 짧게
못 박는다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  readSwitches,      // 설정 파일 → 스위치 값                    ← 부수효과 (입구)
  renderDirective,   // 스위치    → 지시 블록 문자열              ← 이번에 짧아진다
  probeProject,      // 프로젝트  → 진단                          ← 부수효과
  emitBlock,         // 조각들    → 훅 출력                       ← 부수효과 (출구)
)

// help 액션 안 — 분류가 옮겨 가는 자리
flow(
  classifyArgument,  // 인자 → 진단 | 대화 | 기록 검색 | 남길 것 없음   ← 순수
)
```

| # | 단계 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|
| 1 | readSwitches | 설정 파일 → 스위치 값 | 부수효과 (입구) |
| 2 | renderDirective | 스위치 → 조건 없는 명령 블록 | 순수 |
| 3 | probeProject | 프로젝트 경로 → 진단 | 부수효과 |
| 4 | emitBlock | 명령 + 진단 → 훅 출력 | 부수효과 (출구) |
| 5 | classifyArgument | 인자 → 네 갈래 중 하나 | 순수 (help 안) |

- 부수효과 위치: 1·3·4. 2 와 5 는 순수하다.
- 재사용: 1·3·4 는 그대로 둔다. 2 는 내용을 줄이고, 5 는 갈래를 하나 더한다.

## Guardrails

- 스위치를 끄면 아무 것도 주입하지 않는다 — 지시도 진단도.
- scv 폴더가 없으면 출력이 없다.
- 훅은 어떤 경우에도 세션을 막지 않는다.
- 같은 요구를 하는 블록을 다시 늘리지 않는다. 지시는 한 곳에서만 한다.
- help 의 기존 세 모드의 동작은 바꾸지 않는다.
- 쉬운말 블록은 라우팅 스위치와 무관하게 그대로 나온다.

## 성공지표 (Metrics)

| 지표 | 지금 (baseline) | 목표 (target) |
|---|---|---|
| 지시 블록의 갈래 수 | 3 | 0 |
| 지시 블록 줄 수 | 21줄 | 더 짧게 |
| 모델이 답 쓰기 전에 내려야 하는 판단 | 1건 (어느 갈래인가) | 0건 |
| 부르지 않아도 되는 경우 | 갈래 하나 (C) | 명시된 예외 둘 |
| help 가 일반 응답으로 돌려보내는 갈래 | 1건 (초안에 있었음) | 0건 |

## 예외처리 (Edge cases)

- **이미 SCV 액션이 실린 턴** — 부르지 않는다. 부르면 자기 자신을 다시 부른다.
- **사람이 쓰지 않은 자동 알림** — 부르지 않는다. 사람의 요구가 없으므로 남길 논의도 없다.
- **인사·감사 같은 짧은 턴** — **부르고, 기록도 남는다.** 새 파일을 만들지 않고
  이 세션의 대화 파일에 이어 붙인다. 돌려보내지 않는다.
- **세션의 대화 파일이 아직 없는 짧은 턴** — 그때는 파일을 하나 연다. 그 뒤의 짧은
  턴은 전부 거기에 붙는다.
- **스위치가 꺼짐** — 아무 것도 주입하지 않는다. 기존 계약 그대로.
- **점검이 실패** — 지시만 나가고 진단은 없다. 종료 코드 0.

## Exit criteria

- TESTS.md 시나리오 전부 통과.
- 지시 블록에 갈래·분류·조건이 하나도 없다.
- 대체되는 계획의 성질 넷을 새 검사가 이어받는다.

## Suggested path

1. 지시 블록을 조건 없는 명령 한 문장으로 다시 쓴다. 예외 둘을 짧게 못 박고,
   이유 문장과 재조회 금지 문장은 남긴다.
2. help 프로토콜에서 돌려보내는 길을 없앤다 — 어떤 인자로 불려도 기록을 남긴다.
   짧은 턴은 세션의 대화 파일에 이어 붙이는 규칙을 명시한다.
3. 검사를 새로 쓴다. 반대가 된 성질(세 갈래 존재)을 걷어내고, 대체되는 계획에서
   이어받아야 할 성질 넷을 명시적으로 세운다.
4. 지문 재계산, 버전·변경기록 갱신.

## Risks / Open Questions

- 무조건 호출이고 돌려보내기도 없으므로, 짧은 턴에도 액션 호출과 기록이 붙는다.
  이번 변경이 의도적으로 치르는 값이다. 이어 붙이기가 파일 수 폭증만 막아 준다.
- 대화 파일 하나가 길어질 수 있다. 세션 단위로 끊기므로 무한히 자라지는 않는다.
- 대체되는 계획의 검사가 정확히 반대 성질을 검사한다. 이어받을 성질을 새 검사에
  옮기지 않으면 조용히 사라진다. TESTS 의 절반이 그 방어선이다.

# Test Plan — 분류를 걷어내고 무조건 부르게

## Overview

검사는 두 축이다. 하나는 **없어졌는가** — 갈래·분류·조건이 지시 블록에 남아 있지
않은가. 다른 하나는 **이어받았는가** — 대체되는 계획이 지키던 성질이 새 검사에
살아 있는가.

둘째 축이 더 위험하다. supersedes 를 선언하면 그 계획의 검사가 회귀에서 빠지므로,
거기 있던 성질을 여기서 다시 세우지 않으면 조용히 사라진다. T5~T8 이 그 방어선이다.

## Test scenarios

### T1. 지시 블록에 갈래가 없다

이 계획의 핵심이다. 갈래가 하나라도 남으면 원인이 그대로 남는다.

- **Setup**: scv 폴더가 있는 임시 프로젝트, 스위치 기본값.
- **Run**: 프롬프트 훅을 실행하고 지시 블록을 본다.
- **Expected**: A/B/C 같은 갈래 표시가 없고, "셋 중 하나를 고르라" 는 취지의 문장도
  없다.
- **Pass criterion**: 갈래 표지가 0건.

### T2. 명령이 하나이고 조건이 없다

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: "답을 쓰기 전에 이 메시지 전문을 인자로 help 를 지금 호출하라" 는
  취지의 명령이 있고, 그 명령에 조건절이 붙어 있지 않다.
- **Pass criterion**: 호출 명령이 확인되고, "…이면" 형태의 조건이 명령에 붙어 있지
  않다.

### T3. 부르지 않아도 되는 경우가 둘만 명시돼 있다

예외가 없으면 자기 자신을 다시 부르고, 예외가 많으면 다시 분류가 된다.

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: 이미 SCV 액션이 실린 턴, 그리고 사람이 쓰지 않은 자동 알림 —
  이 둘이 예외로 적혀 있다.
- **Pass criterion**: 두 예외가 모두 확인된다.

### T4. 왜 불러야 하는지의 이유가 남아 있다

볼륨 대신 이유를 준다는 것이 이 계열 계획의 설계 선택이다. 문구가 사라지면 선택도
사라진다.

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: 부르지 않으면 논의가 파일로 남지 않는다는 사실이 블록에 있다.
- **Pass criterion**: 그 취지의 문장이 확인된다.

### T5. 스위치를 끄면 아무 것도 주입하지 않는다

대체되는 계획에서 이어받는 성질 (1/4).

- **Setup**: 라우팅 스위치를 끈 프로젝트.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 지시도 진단도 나오지 않는다.
- **Pass criterion**: 지시 표지와 진단 표지가 모두 없다.

### T6. scv 폴더가 없으면 출력이 없다

이어받는 성질 (2/4).

- **Setup**: scv 를 채택하지 않은 빈 임시 디렉터리.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 출력 없음, 종료 코드 0.
- **Pass criterion**: 표준출력이 비어 있다.

### T7. 훅은 어떤 경우에도 막지 않는다

이어받는 성질 (3/4).

- **Setup**: 점검 스크립트가 비정상 종료하도록 만든 상황.
- **Run**: 프롬프트 훅을 실행하고 종료 코드를 본다.
- **Expected**: 종료 코드 0, 지시 블록은 그대로 나온다.
- **Pass criterion**: 종료 코드가 0 이고 지시 표지가 확인된다.

### T8. 같은 요구를 하는 블록이 하나뿐이다

이어받는 성질 (4/4). 무시되는 지시가 둘이면 서로를 약화시킨다.

- **Setup**: T1 과 같다.
- **Run**: 훅 출력 전체를 본다.
- **Expected**: help 호출을 요구하는 블록이 하나다.
- **Pass criterion**: 호출을 요구하는 표지가 1건.

### T9. 쉬운말 블록은 라우팅과 무관하다

- **Setup**: 라우팅 스위치를 끈 프로젝트.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 쉬운말 안내는 그대로 나온다.
- **Pass criterion**: 쉬운말 표지가 확인된다.

### T10. 지시 블록이 전보다 짧다

분류를 걷어낸 만큼 줄어야 한다. 늘어났다면 갈래를 말로 바꿔 남긴 것이다.

- **Setup**: 없음 — 지시 블록을 직접 만들어 본다.
- **Run**: 블록의 줄 수를 센다.
- **Expected**: 21줄보다 적다.
- **Pass criterion**: 줄 수 < 21.

### T11. help 에 돌려보내는 갈래가 없다

초안의 실수를 막는 검사다. 출구를 지침에서 액션으로 옮기기만 하면 같은 구멍이
자리만 바꾼다.

- **Setup**: 없음.
- **Run**: help 프로토콜 문서를 읽는다.
- **Expected**: "남길 논의가 없으니 아무것도 쓰지 않고 끝낸다" 는 취지의 갈래가
  없다.
- **Pass criterion**: 그런 갈래가 0건.

### T12. 짧은 턴은 세션의 대화 파일에 이어 붙는다

돌려보내지 않으므로 반드시 기록이 남되, 파일이 폭증하지 않아야 한다.

- **Setup**: 없음.
- **Run**: help 프로토콜 문서를 읽는다.
- **Expected**: 짧은 턴을 새 파일이 아니라 세션의 대화 파일에 이어 붙인다는 규칙이
  있고, 세션 파일이 아직 없으면 하나를 연다는 것도 적혀 있다.
- **Pass criterion**: 두 문장이 모두 확인된다.

# 분류를 걷어내고 무조건 부르게 — 판단은 help 가 한다

## Summary

0.41.0 이 지시를 맨 앞으로 옮기고 조건문을 명령으로 바꿨는데도 호출이 여전히 안 된다.
남아 있던 원인은 **세 갈래 자체**다. 블록이 행동을 시키기 전에 **판단을 시키고**,
그 판단에 "부르지 않아도 된다" 는 정당한 출구가 있다. 애매한 턴은 전부 그쪽으로 샌다.
분류를 지침에서 걷어내고 help 안으로 옮긴다.

## Goals / Non-Goals

- **Goals**
  - 지시 블록에서 갈래·분류·조건을 없앤다. 남는 것은 명령 하나다.
  - 부르지 않아도 되는 경우를 둘로 못 박는다 — 그 외에는 예외가 없다.
  - help 는 **항상 자기 일을 한다.** 일반 응답으로 돌려보내는 갈래를 두지 않는다.
- **Non-Goals**
  - 스위치를 없애지 않는다. 끄면 여전히 아무 것도 주입하지 않는다.
  - 훅의 비차단 보장을 건드리지 않는다.
  - help 의 기존 세 모드(진단·대화·기록 검색)를 바꾸지 않는다.

## Approach Overview

지금 블록은 이렇게 말한다: "셋 중 하나를 고르고, 고른 것을 실행하라." 고르는 일이
행동보다 앞에 있다. 그리고 셋째 갈래는 "아무 것도 부르지 말라" 다 — 즉 **아무 것도
하지 않는 것이 정답인 경우가 명시돼 있다.** 애매한 입력 앞에서 두 갈래(호출)와 한
갈래(침묵) 중 침묵이 언제나 더 싸다. 볼륨을 아무리 올려도 이 비대칭은 남는다.

그래서 판단을 옮긴다. 지침은 조건 없는 한 문장이 된다 — "답을 쓰기 전에 이 메시지
전문을 인자로 help 를 지금 호출하라. 판단하지 말고 부르라." 모델에게 남는 선택지가
없어지므로 샐 곳도 없다.

여기서 한 번 더 걸러야 할 것이 있다. 처음 안은 help 안에 "남길 논의 없음 → 아무
것도 쓰지 않고 끝" 이라는 갈래를 새로 두는 것이었는데, 그것은 **출구를 지침에서
액션으로 옮겼을 뿐 출구 자체는 살려 둔 것**이다. 같은 구멍이 자리만 바꾼다. 그래서
그 갈래를 두지 않는다 — **help 는 돌려보내지 않고 항상 기록한다.**

대신 기록의 **모양**을 정한다. 짧은 턴마다 새 대화 파일을 만들면 하루면 폴더가
잡음으로 찬다. 그래서 짧은 턴은 이 세션이 이미 쓰고 있는 대화 파일에 **이어
붙인다.** 돌려보내는 일이 없으므로 요구는 그대로 만족되고, 기록은 쓸모를 잃지
않는다.

무조건에서 빼야 하는 경우는 둘뿐이고, 둘 다 빼지 않으면 동작이 깨진다. 이미 SCV
액션이 도는 턴에서 다시 부르면 자기 자신을 부른다. 사람이 쓰지 않은 자동 알림에는
남길 논의가 없다. 이 둘은 분류가 아니라 **정의상 해당 없음**이므로 블록에 짧게
못 박는다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  readSwitches,      // 설정 파일 → 스위치 값                    ← 부수효과 (입구)
  renderDirective,   // 스위치    → 지시 블록 문자열              ← 이번에 짧아진다
  probeProject,      // 프로젝트  → 진단                          ← 부수효과
  emitBlock,         // 조각들    → 훅 출력                       ← 부수효과 (출구)
)

// help 액션 안 — 분류가 옮겨 가는 자리
flow(
  classifyArgument,  // 인자 → 진단 | 대화 | 기록 검색 | 남길 것 없음   ← 순수
)
```

| # | 단계 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|
| 1 | readSwitches | 설정 파일 → 스위치 값 | 부수효과 (입구) |
| 2 | renderDirective | 스위치 → 조건 없는 명령 블록 | 순수 |
| 3 | probeProject | 프로젝트 경로 → 진단 | 부수효과 |
| 4 | emitBlock | 명령 + 진단 → 훅 출력 | 부수효과 (출구) |
| 5 | classifyArgument | 인자 → 네 갈래 중 하나 | 순수 (help 안) |

- 부수효과 위치: 1·3·4. 2 와 5 는 순수하다.
- 재사용: 1·3·4 는 그대로 둔다. 2 는 내용을 줄이고, 5 는 갈래를 하나 더한다.

## Guardrails

- 스위치를 끄면 아무 것도 주입하지 않는다 — 지시도 진단도.
- scv 폴더가 없으면 출력이 없다.
- 훅은 어떤 경우에도 세션을 막지 않는다.
- 같은 요구를 하는 블록을 다시 늘리지 않는다. 지시는 한 곳에서만 한다.
- help 의 기존 세 모드의 동작은 바꾸지 않는다.
- 쉬운말 블록은 라우팅 스위치와 무관하게 그대로 나온다.

## 성공지표 (Metrics)

| 지표 | 지금 (baseline) | 목표 (target) |
|---|---|---|
| 지시 블록의 갈래 수 | 3 | 0 |
| 지시 블록 줄 수 | 21줄 | 더 짧게 |
| 모델이 답 쓰기 전에 내려야 하는 판단 | 1건 (어느 갈래인가) | 0건 |
| 부르지 않아도 되는 경우 | 갈래 하나 (C) | 명시된 예외 둘 |
| help 가 일반 응답으로 돌려보내는 갈래 | 1건 (초안에 있었음) | 0건 |

## 예외처리 (Edge cases)

- **이미 SCV 액션이 실린 턴** — 부르지 않는다. 부르면 자기 자신을 다시 부른다.
- **사람이 쓰지 않은 자동 알림** — 부르지 않는다. 사람의 요구가 없으므로 남길 논의도 없다.
- **인사·감사 같은 짧은 턴** — **부르고, 기록도 남는다.** 새 파일을 만들지 않고
  이 세션의 대화 파일에 이어 붙인다. 돌려보내지 않는다.
- **세션의 대화 파일이 아직 없는 짧은 턴** — 그때는 파일을 하나 연다. 그 뒤의 짧은
  턴은 전부 거기에 붙는다.
- **스위치가 꺼짐** — 아무 것도 주입하지 않는다. 기존 계약 그대로.
- **점검이 실패** — 지시만 나가고 진단은 없다. 종료 코드 0.

## Exit criteria

- TESTS.md 시나리오 전부 통과.
- 지시 블록에 갈래·분류·조건이 하나도 없다.
- 대체되는 계획의 성질 넷을 새 검사가 이어받는다.

## Suggested path

1. 지시 블록을 조건 없는 명령 한 문장으로 다시 쓴다. 예외 둘을 짧게 못 박고,
   이유 문장과 재조회 금지 문장은 남긴다.
2. help 프로토콜에서 돌려보내는 길을 없앤다 — 어떤 인자로 불려도 기록을 남긴다.
   짧은 턴은 세션의 대화 파일에 이어 붙이는 규칙을 명시한다.
3. 검사를 새로 쓴다. 반대가 된 성질(세 갈래 존재)을 걷어내고, 대체되는 계획에서
   이어받아야 할 성질 넷을 명시적으로 세운다.
4. 지문 재계산, 버전·변경기록 갱신.

# Test Plan — 분류를 걷어내고 무조건 부르게

## Overview

검사는 두 축이다. 하나는 **없어졌는가** — 갈래·분류·조건이 지시 블록에 남아 있지
않은가. 다른 하나는 **이어받았는가** — 대체되는 계획이 지키던 성질이 새 검사에
살아 있는가.

둘째 축이 더 위험하다. supersedes 를 선언하면 그 계획의 검사가 회귀에서 빠지므로,
거기 있던 성질을 여기서 다시 세우지 않으면 조용히 사라진다. T5~T8 이 그 방어선이다.

## Test scenarios

### T1. 지시 블록에 갈래가 없다

이 계획의 핵심이다. 갈래가 하나라도 남으면 원인이 그대로 남는다.

- **Setup**: scv 폴더가 있는 임시 프로젝트, 스위치 기본값.
- **Run**: 프롬프트 훅을 실행하고 지시 블록을 본다.
- **Expected**: A/B/C 같은 갈래 표시가 없고, "셋 중 하나를 고르라" 는 취지의 문장도
  없다.
- **Pass criterion**: 갈래 표지가 0건.

### T2. 명령이 하나이고 조건이 없다

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: "답을 쓰기 전에 이 메시지 전문을 인자로 help 를 지금 호출하라" 는
  취지의 명령이 있고, 그 명령에 조건절이 붙어 있지 않다.
- **Pass criterion**: 호출 명령이 확인되고, "…이면" 형태의 조건이 명령에 붙어 있지
  않다.

### T3. 부르지 않아도 되는 경우가 둘만 명시돼 있다

예외가 없으면 자기 자신을 다시 부르고, 예외가 많으면 다시 분류가 된다.

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: 이미 SCV 액션이 실린 턴, 그리고 사람이 쓰지 않은 자동 알림 —
  이 둘이 예외로 적혀 있다.
- **Pass criterion**: 두 예외가 모두 확인된다.

### T4. 왜 불러야 하는지의 이유가 남아 있다

볼륨 대신 이유를 준다는 것이 이 계열 계획의 설계 선택이다. 문구가 사라지면 선택도
사라진다.

- **Setup**: T1 과 같다.
- **Run**: 지시 블록을 본다.
- **Expected**: 부르지 않으면 논의가 파일로 남지 않는다는 사실이 블록에 있다.
- **Pass criterion**: 그 취지의 문장이 확인된다.

### T5. 스위치를 끄면 아무 것도 주입하지 않는다

대체되는 계획에서 이어받는 성질 (1/4).

- **Setup**: 라우팅 스위치를 끈 프로젝트.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 지시도 진단도 나오지 않는다.
- **Pass criterion**: 지시 표지와 진단 표지가 모두 없다.

### T6. scv 폴더가 없으면 출력이 없다

이어받는 성질 (2/4).

- **Setup**: scv 를 채택하지 않은 빈 임시 디렉터리.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 출력 없음, 종료 코드 0.
- **Pass criterion**: 표준출력이 비어 있다.

### T7. 훅은 어떤 경우에도 막지 않는다

이어받는 성질 (3/4).

- **Setup**: 점검 스크립트가 비정상 종료하도록 만든 상황.
- **Run**: 프롬프트 훅을 실행하고 종료 코드를 본다.
- **Expected**: 종료 코드 0, 지시 블록은 그대로 나온다.
- **Pass criterion**: 종료 코드가 0 이고 지시 표지가 확인된다.

### T8. 같은 요구를 하는 블록이 하나뿐이다

이어받는 성질 (4/4). 무시되는 지시가 둘이면 서로를 약화시킨다.

- **Setup**: T1 과 같다.
- **Run**: 훅 출력 전체를 본다.
- **Expected**: help 호출을 요구하는 블록이 하나다.
- **Pass criterion**: 호출을 요구하는 표지가 1건.

### T9. 쉬운말 블록은 라우팅과 무관하다

- **Setup**: 라우팅 스위치를 끈 프로젝트.
- **Run**: 프롬프트 훅을 실행한다.
- **Expected**: 쉬운말 안내는 그대로 나온다.
- **Pass criterion**: 쉬운말 표지가 확인된다.

### T10. 지시 블록이 전보다 짧다

분류를 걷어낸 만큼 줄어야 한다. 늘어났다면 갈래를 말로 바꿔 남긴 것이다.

- **Setup**: 없음 — 지시 블록을 직접 만들어 본다.
- **Run**: 블록의 줄 수를 센다.
- **Expected**: 21줄보다 적다.
- **Pass criterion**: 줄 수 < 21.

### T11. help 에 돌려보내는 갈래가 없다

초안의 실수를 막는 검사다. 출구를 지침에서 액션으로 옮기기만 하면 같은 구멍이
자리만 바꾼다.

- **Setup**: 없음.
- **Run**: help 프로토콜 문서를 읽는다.
- **Expected**: "남길 논의가 없으니 아무것도 쓰지 않고 끝낸다" 는 취지의 갈래가
  없다.
- **Pass criterion**: 그런 갈래가 0건.

### T12. 짧은 턴은 세션의 대화 파일에 이어 붙는다

돌려보내지 않으므로 반드시 기록이 남되, 파일이 폭증하지 않아야 한다.

- **Setup**: 없음.
- **Run**: help 프로토콜 문서를 읽는다.
- **Expected**: 짧은 턴을 새 파일이 아니라 세션의 대화 파일에 이어 붙인다는 규칙이
  있고, 세션 파일이 아직 없으면 하나를 연다는 것도 적혀 있다.
- **Pass criterion**: 두 문장이 모두 확인된다.

bash core/tests/test-force-help.sh

- 대체되는 계획의 성질 넷(T5~T8)이 새 검사에 살아 있다.
