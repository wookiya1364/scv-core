# Test Plan — 실사용 보고 판정기를 구조 규칙으로 — 보이고 물었나를 바르게 세기

## Overview

실사용 보고의 판정기가 '실제 결과를 보이고 계속 · 고칠 점을 물었나'를 기록의 구조 — 첫 편집 뒤 실행, 그 실행 뒤 묻기, 묻는
글 · 창이나 바로 앞 글에 그 실행 출력의 줄 · 숫자가 그대로 — 로 가르는지 확인한다. 저장소 안의 검사는 만든 고정 기록(대화
내용 없음)으로 세 조건의 경계와 기존 약속(끄면 같음 · 숫자만 · bash 3.2 와 리눅스 같은 결과 · 속도)을 본다. 저장소 밖에서는
정답을 먼저 고정한 새 표본 40턴을 한 번만 재어 잘못 잡음 0 · 18/20 이상을 확인한다. 기준과 절차는 표본을 열기 전에 고정한다.

## Test scenarios

### T1. 끄면 같음

- **Setup**: 임시 저장소, 설정 `SCV_SHOW_REAL=off`.
- **Run**: 매 턴 훅 출력을 이 계획 전 코어와 바이트로 비교한다.
- **Expected**: 출력이 같다. 보고 · 판정기를 바꿔도 매 턴 출력에는 영향이 없다.
- **Pass criterion**: 바이트 비교 차이 0.

### T2. 세 조건을 모두 만족하면 '보여 줌'

- **Setup**: 고정 기록 — 사람 턴 하나에 편집 → 실행(출력에 '32 passed' 줄) → 선택 창(질문 또는 그 앞 글에 '32 passed' 그대로).
- **Run**: 판정기를 돌린다.
- **Expected**: 그 턴이 바뀜 1 · 보여 줌 1.
- **Pass criterion**: 보여 줌 1.

### T3. 실행 뒤 묻지 않으면 '보여 주지 않음'

- **Setup**: 고정 기록 — 편집 → 실행 → 실행 결과를 알리는 글로 끝(질문 · 선택 창 없음). 지난 표본의 '알리기만 하고 묻지 않음' 모양.
- **Run**: 판정기를 돌린다.
- **Expected**: 보여 줌 0.
- **Pass criterion**: 보여 줌 0.

### T4. 묻기가 첫 편집보다 앞이면 '보여 주지 않음'

- **Setup**: 고정 기록 — 실행 → 결과를 보인 선택 창 → 그 뒤에 첫 편집(편집 뒤에는 묻기 없음).
- **Run**: 판정기를 돌린다.
- **Expected**: 보여 줌 0.
- **Pass criterion**: 보여 줌 0.

### T5. 편집 뒤 실행 없이 물으면 '보여 주지 않음'

- **Setup**: 고정 기록 — 편집 → (실행 없음) → 선택 창(결과물과 상관없는 질문, 예: 대화 보관 여부).
- **Run**: 판정기를 돌린다.
- **Expected**: 보여 줌 0.
- **Pass criterion**: 보여 줌 0.

### T6. 실제 값 없이 물으면 '보여 주지 않음'

- **Setup**: 고정 기록 — 편집 → 실행(출력에 '경고 0개 · 그림 7개') → 선택 창(질문과 앞 글에 그 출력의 줄 · 숫자가 없음).
- **Run**: 판정기를 돌린다.
- **Expected**: 보여 줌 0.
- **Pass criterion**: 보여 줌 0.

### T7. 선택 창 없이 글 질문으로 물어도 세 조건이면 '보여 줌'

- **Setup**: 고정 기록 — 편집 → 실행 → 끝 문단의 글 질문, 그 글에 실행 출력의 줄 그대로(선택 창이 없는 호스트 모양).
- **Run**: 판정기를 돌린다.
- **Expected**: 보여 줌 1.
- **Pass criterion**: 보여 줌 1.

### T8. 명령으로만 파일을 바꾼 턴은 바뀜 · 보여 줌 0

- **Setup**: 고정 기록 — 편집 도구 없이 명령(파일 이동 · 치환)으로만 파일을 바꾸고 결과를 보고.
- **Run**: 판정기를 돌린다.
- **Expected**: 바뀜 0 · 보여 줌 0(지금 판정기와 같은 뜻).
- **Pass criterion**: 두 칸 모두 0.

### T9. 다른 칸의 뜻은 그대로

- **Setup**: 지금 검사의 고정 기록들(완료 · 수정 요구 · 확인 질문 수 · 결과물 변화 없음 · 자동 입력 · 하위 에이전트 줄).
- **Run**: 판정기를 돌린다.
- **Expected**: 보여 줌을 뺀 칸이 이 계획 전과 같다.
- **Pass criterion**: 기존 검사 통과.

### T10. 보고는 숫자 · 날짜만

- **Setup**: 고정 기록 여러 개(출력에 고유한 문자열을 심어 둠).
- **Run**: 실사용 보고를 돌린다.
- **Expected**: 보고 글에 기록의 문장 · 실행 출력이 한 줄도 나오지 않고 숫자 · 날짜만 나온다.
- **Pass criterion**: 심어 둔 문자열이 보고 글에 0번.

### T11. 맥 기본 bash 3.2 와 지금 bash 가 같은 결과

- **Setup**: T2 ~ T10 의 고정 기록.
- **Run**: 시스템 bash 3.2 와 지금 bash 로 판정기 · 보고를 돌린다.
- **Expected**: 판정 줄과 보고 글이 바이트로 같다.
- **Pass criterion**: 차이 0. (리눅스는 CI 에서 같은 검사를 돈다.)

### T12. 속도 — 지금 판정기의 2배 안

- **Setup**: 같은 고정 기록 묶음(긴 한글 출력 · 많은 턴 포함).
- **Run**: 이 계획 전 판정기와 새 판정기로 보고를 돌려 시간을 잰다(맥 기본 bash 3.2).
- **Expected**: 새 판정기 시간이 2배 미만.
- **Pass criterion**: 시간 비 < 2.0.

### T13. 새 표본 한 번 재기 (측정 — CI 밖)

- **Setup**: 측정 기준 문서에 고정한 절차로 만든 새 표본 40턴('보이고 물음' 20 · '아님' 20, 10월 9일 이후 사용자 세션 + 지난 측정
  18번 기록, 정답은 가린 판정으로 먼저 매김). 표본은 저장소 밖.
- **Run**: 판정기를 다 만든 뒤 평가 스크립트로 한 번만 잰다.
- **Expected**: 잘못 잡음 0 · '보이고 물음' 20개 중 18개 이상 잡음.
- **Pass criterion**: 두 조건 모두. 못 넘으면 고치지 않고 멈춰 보고한다.

### T14. 리눅스 CI

- **Setup**: PR.
- **Run**: 맥 · 리눅스 CI.
- **Expected**: T1 ~ T12 통과.
- **Pass criterion**: CI 모두 통과.

## How to run

```bash
bash core/tests/test-show-real.sh
```

새 표본 측정(T13)은 실제 Claude 판정자를 쓰므로 CI · 회귀 실행에 넣지 않는다 — `~/scv-experiments/longbench/classifier-sample`
의 장치로 돌리고, 결과를 측정 기준 문서와 측정 보고서(scv/raw)에 적는다.

## Pass criteria

- T1 ~ T12 · T14 가 맥 · 리눅스 CI 에서 통과한다.
- T13 새 표본 한 번: 잘못 잡음 0 · 18/20 이상 — 아니면 멈추고 다음 길('둘 다')을 사용자와 정한다.
