# 잘못된 거절 셋 고치기 — 기록 폴더가 연결돼 있을 때와 낱말 하나 겹침

## Summary

SCV 의 검사 셋이 막지 말아야 할 일을 막는다. 셋 다 2026-11-10 세션에서 실제로 겪었다.
기록 폴더(scv/raw · scv/journal 따위)를 다른 저장소로 연결해 둔 프로젝트에서 두 가지가, 진행 메모의 낱말 하나 겹침에서 한 가지가 생긴다.
막아야 할 일은 그대로 막으면서 이 셋만 통과시킨다.

## Goals / Non-Goals

- **Goals**
  - 기록 폴더가 다른 저장소로 연결돼 있어도, 그 안 파일만 바꾼 턴은 턴 끝 검사가 막지 않는다.
  - 진행 메모 · 덧붙이는 단계 글은 '하지 않음' 항목 낱말의 절반 이상이 들어 있을 때만 거절된다(사용자가 고른 기준).
  - 원자료 폴더 뿌리가 연결이어도 `readpath.sh consume` 이 옮기고, 쓰지 않은 원자료 목록에도 그 파일이 보인다.
- **Non-Goals**
  - 턴 끝 검사의 나머지 판정(영수증 · 단계 보고 · 되돌아가기)
  - 충돌의 '뜻' 판단 — 모델 몫 그대로
  - 원자료 수명 규칙(언제 낡았다고 보는가)
  - 래퍼 저장소의 훅 등록

## Approach Overview

1. **턴 끝 검사** — 거름망 `scv_tc_filter` 는 `scv/` 로 시작하는 경로만 '일이 아님'으로 뺀다. 기록 폴더가 연결이면 그 안 파일은 연결된 저장소의 경로로 세어질 수 있다(추정 — 1단계에서 재현으로 확정). 어댑터가 기록 폴더의 실제 경로를 읽어 거름망에 넘기고, 거름망은 받은 경로 아래를 뺀다. 거름망은 순수 함수로 남는다.
2. **낱말 겹침** — `scv_tc_nongoal_hits` 는 낱말 하나만 같아도 충돌로 본다. 겹친 수를 세는 순수 함수를 따로 두고, "겹친 수 × 2 ≥ 항목 낱말 수"일 때만 충돌로 낸다. 항목 낱말이 1개면 1개 겹침으로 충돌(문서의 예 그대로).
3. **원자료 옮기기** — `assert_no_symlink_components` 는 경로의 모든 마디를 본다. 원자료 폴더 뿌리(`RAW_DIR`)까지는 건너뛰고 그 아래 마디만 본다. 쓰지 않은 원자료 목록도 연결된 뿌리 안을 읽게 한다(2026-11-11 00:00 확인: 연결된 뿌리에서 목록이 빈 값으로 나옴).

세 고침은 서로 기대지 않는다. 하나가 막히면 그 하나만 빼고 나머지를 내보낼 수 있다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  record_roots,            // 저장소 뿌리 → 기록 폴더의 실제 경로 줄들        (부수효과: 연결 읽기)
  scv_tc_filter,           // 바뀐 경로 · 뺄 경로 → 일로 셀 경로
)
flow(
  scv_tc_words,            // 글 → 낱말들                                     (있는 것 그대로)
  scv_tc_overlap_count,    // 항목 낱말 · 메모 낱말 → "겹친 수 전체 수"
  scv_tc_nongoal_hits,     // 계획 글 · 메모 → 충돌 줄들 (절반 이상일 때만)
)
flow(
  below_raw_root,          // 경로 · 원자료 뿌리 → 뿌리 아래 마디들
  assert_no_symlink_components, // 마디들 → 통과 또는 거절                    (부수효과: 연결 검사)
)
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | `record_roots` | 기록 폴더가 연결이면 가리키는 실제 경로를 읽는다 | 저장소 뿌리 → 실제 경로 줄들 | 부수효과 (입구) |
| 2 | `scv_tc_filter` | 바뀐 경로에서 기록 폴더 안의 것을 뺀다 | 바뀐 경로 · 뺄 경로 → 일로 셀 경로 | 순수 |
| 3 | `scv_tc_overlap_count` | 항목 낱말 중 메모에 있는 것을 센다 | 항목 낱말 · 메모 낱말 → "겹친 수 전체 수" | 순수 |
| 4 | `scv_tc_nongoal_hits` | 절반 이상 겹친 '하지 않음' 항목만 충돌로 낸다 | 계획 글 · 메모 → 충돌 줄들 | 순수 |
| 5 | `below_raw_root` | 경로에서 원자료 뿌리까지를 떼어 낸다 | 경로 · 원자료 뿌리 → 뿌리 아래 마디들 | 순수 |
| 6 | `assert_no_symlink_components` | 뿌리 아래 마디에 연결이 있으면 거절한다 | 마디들 → 통과 또는 거절 | 부수효과 (출구) |

- 부수효과 위치: 1(연결 읽기) · 6(파일 시스템 검사) — 판정은 가운데 순수 함수가 한다.
- 재사용: `scv_tc_words` · `scv_plan_goal_items` · `scv_plan_norm_req` 는 그대로 쓴다.

## Guardrails

- 거름망을 넓히는 길은 "기록 폴더의 실제 경로" 하나뿐이다. 다른 저장소의 다른 폴더는 빼지 않는다.
- 낱말 기준은 사용자가 고른 "절반 이상" 그대로 — 다른 가중치나 낱말 목록 손질을 더하지 않는다.
- 원자료 뿌리 아래의 연결은 계속 거절한다(밖으로 빠지는 이동을 막는 뜻).
- 맥(BSD) · 리눅스(GNU) 둘 다, bash 3.2 에서 돈다 — `readlink -f` · `realpath` 없이 `cd … && pwd -P`.
- 1단계 재현이 추정한 원인과 다르면, 고치기 전에 원인을 계획의 변경 이력에 적는다.

## Suggested path

1. 연결된 기록 폴더에서 턴 끝 검사가 막히는 것을 임시 저장소로 재현하고 원인을 확정 — 재현 시험을 먼저 쓴다(빨강)
2. 기록 폴더의 실제 경로를 거름망에 넘김 — `record_roots`, `scv_tc_filter`
3. 겹친 수 세기와 절반 기준 — `scv_tc_overlap_count`, `scv_tc_nongoal_hits`
4. 원자료 뿌리 아래만 연결 검사, 쓰지 않은 원자료 목록이 연결된 뿌리를 읽음 — `below_raw_root`, `assert_no_symlink_components`
5. 순수 함수 목록 · 계약 문서 · CHANGELOG · VERSION 0.88.2 — 문서와 버전을 맞춘다
6. 전체 시험을 bash 3.2 · bash 5 로 돌림 — 새로 실패한 것이 없는지 본다

## Risks / Open Questions

- 턴 끝 검사 오탐의 원인은 추정이다. 재현이 다른 원인을 보이면 2단계의 길이 바뀐다.

# 잘못된 거절 셋 고치기 — 기록 폴더가 연결돼 있을 때와 낱말 하나 겹침

## Summary

SCV 의 검사 셋이 막지 말아야 할 일을 막는다. 셋 다 2026-11-10 세션에서 실제로 겪었다.
기록 폴더(scv/raw · scv/journal 따위)를 다른 저장소로 연결해 둔 프로젝트에서 두 가지가, 진행 메모의 낱말 하나 겹침에서 한 가지가 생긴다.
막아야 할 일은 그대로 막으면서 이 셋만 통과시킨다.

## Goals / Non-Goals

- **Goals**
  - 기록 폴더가 다른 저장소로 연결돼 있어도, 그 안 파일만 바꾼 턴은 턴 끝 검사가 막지 않는다.
  - 진행 메모 · 덧붙이는 단계 글은 '하지 않음' 항목 낱말의 절반 이상이 들어 있을 때만 거절된다(사용자가 고른 기준).
  - 원자료 폴더 뿌리가 연결이어도 `readpath.sh consume` 이 옮기고, 쓰지 않은 원자료 목록에도 그 파일이 보인다.
- **Non-Goals**
  - 턴 끝 검사의 나머지 판정(영수증 · 단계 보고 · 되돌아가기)
  - 충돌의 '뜻' 판단 — 모델 몫 그대로
  - 원자료 수명 규칙(언제 낡았다고 보는가)
  - 래퍼 저장소의 훅 등록

## Approach Overview

1. **턴 끝 검사** — 거름망 `scv_tc_filter` 는 `scv/` 로 시작하는 경로만 '일이 아님'으로 뺀다. 기록 폴더가 연결이면 그 안 파일은 연결된 저장소의 경로로 세어질 수 있다(추정 — 1단계에서 재현으로 확정). 어댑터가 기록 폴더의 실제 경로를 읽어 거름망에 넘기고, 거름망은 받은 경로 아래를 뺀다. 거름망은 순수 함수로 남는다.
2. **낱말 겹침** — `scv_tc_nongoal_hits` 는 낱말 하나만 같아도 충돌로 본다. 겹친 수를 세는 순수 함수를 따로 두고, "겹친 수 × 2 ≥ 항목 낱말 수"일 때만 충돌로 낸다. 항목 낱말이 1개면 1개 겹침으로 충돌(문서의 예 그대로).
3. **원자료 옮기기** — `assert_no_symlink_components` 는 경로의 모든 마디를 본다. 원자료 폴더 뿌리(`RAW_DIR`)까지는 건너뛰고 그 아래 마디만 본다. 쓰지 않은 원자료 목록도 연결된 뿌리 안을 읽게 한다(2026-11-11 00:00 확인: 연결된 뿌리에서 목록이 빈 값으로 나옴).

세 고침은 서로 기대지 않는다. 하나가 막히면 그 하나만 빼고 나머지를 내보낼 수 있다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  record_roots,            // 저장소 뿌리 → 기록 폴더의 실제 경로 줄들        (부수효과: 연결 읽기)
  scv_tc_filter,           // 바뀐 경로 · 뺄 경로 → 일로 셀 경로
)
flow(
  scv_tc_words,            // 글 → 낱말들                                     (있는 것 그대로)
  scv_tc_overlap_count,    // 항목 낱말 · 메모 낱말 → "겹친 수 전체 수"
  scv_tc_nongoal_hits,     // 계획 글 · 메모 → 충돌 줄들 (절반 이상일 때만)
)
flow(
  below_raw_root,          // 경로 · 원자료 뿌리 → 뿌리 아래 마디들
  assert_no_symlink_components, // 마디들 → 통과 또는 거절                    (부수효과: 연결 검사)
)
```

|---|---|---|---|---|
| 1 | `record_roots` | 기록 폴더가 연결이면 가리키는 실제 경로를 읽는다 | 저장소 뿌리 → 실제 경로 줄들 | 부수효과 (입구) |
| 2 | `scv_tc_filter` | 바뀐 경로에서 기록 폴더 안의 것을 뺀다 | 바뀐 경로 · 뺄 경로 → 일로 셀 경로 | 순수 |
| 3 | `scv_tc_overlap_count` | 항목 낱말 중 메모에 있는 것을 센다 | 항목 낱말 · 메모 낱말 → "겹친 수 전체 수" | 순수 |
| 4 | `scv_tc_nongoal_hits` | 절반 이상 겹친 '하지 않음' 항목만 충돌로 낸다 | 계획 글 · 메모 → 충돌 줄들 | 순수 |
