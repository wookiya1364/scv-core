# 주석 옮기기 안전 — 셸 따옴표를 바로 읽기 · 깨지는 파일은 건드리지 않기 · 실패하면 원래대로

## Summary

0.98.0 의 주석 옮기기(기본 켜짐)를 SCV 코어 사본에 돌려 보니(2026-11-22) 셸 스크립트 하나의 문법이 깨졌다. 큰따옴표 안 `$( )` 속 작은따옴표에 든 `"` 를 바깥 큰따옴표의 끝으로 읽어, 뒤쪽 문자열 안 `###` 를 주석으로 지웠다. 같은 날 실제 저장소에서는 사전 쓰기가 실패했는데도 지운 코드가 그대로 남았다. 둘 다 사용자 프로젝트에서도 일어날 수 있다. 이 계획은 셸 읽기를 고치고, 지운 뒤 문법을 검사해 깨지는 파일은 건드리지 않으며, 사전 쓰기가 실패하면 코드 파일을 원래대로 돌린다.

## Goals / Non-Goals

- **Goals**
  - 셸 읽기가 큰따옴표 · `$( )` · `${ }` · 역따옴표가 겹친 글을 bash 와 같이 따라간다.
  - 지운 글의 문법을 검사한다(sh: `bash -n`, py: 컴파일). 원래는 통과하는데 지운 뒤 깨지면 그 파일은 지우지 않고 보고한다.
  - 사전 쓰기가 실패하면 지운 파일을 옮기기 전 내용으로 복원하고 멈춘다.
- **Non-Goals**
  - SCV 코어 · 래퍼 자기 저장소에 켜기(시험 표시 · 사용법 머리글 · 사전 제목 중복은 그 계획에서).
  - js · rs · go 문법 검사(도구가 없을 수 있음) — 읽기 시험만.

## Approach Overview

셸 읽기를 '지금 어디 안에 있는가'(맨 바깥 · 큰따옴표 · `$( )` · `${ }`)를 따라가는 재귀 읽기로 바꾼다. 옮기기는 파일마다 지운 글을 문법 검사에 통과시킨 뒤에만 쓴다. 옮기기 스크립트는 쓰기 전에 대상 파일을 임시 폴더에 복사해 두고, 사전 쓰기가 실패하면 되돌린다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

| 단계 | 함수 | 순수 | 하는 일 |
|---|---|---|---|
| 읽기 | `_spans_sh` | 순수 | 셸 글에서 주석 구간을 찾음 — 겹친 따옴표 · 치환을 따라감 |
| 검사 | `syntax_ok` | 부수효과(bash 실행) | 글 하나가 그 언어 문법을 통과하는가 |
| 쓰기 | `main migrate` | 부수효과 | 검사를 통과한 파일만 씀, 건너뛴 파일 수를 보고 |
| 읽기 | `parse_markers` | 순수 | 표식은 줄 맨 앞에서만, 예: 뒤는 통째로 예시 |
| 복원 | `cm_run` | 부수효과 | 사전 쓰기 실패 시 복사본으로 되돌림 |

## Guardrails

- 시험 없이 고치지 않는다 — 재현 시험이 먼저 실패해야 한다.
- 사용자 저장소를 시험에 쓰지 않는다 — 사본만.
- 옮기기 보고 줄(`MIGRATE …`)의 이미 있는 이름은 바꾸지 않는다(덧붙이기만).

## Exit criteria

- 재현 예 3개(따옴표 겹침 · `${ }` 안 따옴표 · `$( )` 안 주석)가 바르게 처리됨.
- SCV 코어 사본 전체 옮기기 뒤 바뀐 sh 파일 `bash -n` 깨짐 0, py 컴파일 깨짐 0.
- 사전 쓰기를 일부러 실패시키면 코드 파일이 옮기기 전과 바이트까지 같음.
- 관련 시험(주석 옮기기 · 규칙 · 순수 · 사전 검사)이 mac · linux 에서 통과.

## Suggested path

1. 재현 시험 추가(먼저 실패 확인) — `읽기`
2. 셸 읽기 고침 — `읽기` `_spans_sh`
3. 지운 뒤 문법 검사 — 깨지면 그 파일 제외 · 보고 — `검사` `syntax_ok`
4. 사전 쓰기 실패 시 복원 — `복원` `cm_run`
5. 표식 읽기 · 잃는 항목 검사 — 예시 속 @pure · 종류: 는 글로, 옮기기 전 항목이 하나라도 빠지면 멈춤 — `읽기` `parse_markers`
6. 사본 전체 + 관련 시험, mac · linux — `쓰기`

## Risks / Open Questions

- 실제 저장소에서 사전 쓰기가 왜 실패했는지는 아직 모름(사본에서는 성공). 복원이 있으면 결과는 안전하다.
- `case` 패턴의 `)` 가 `$( )` 안에 있으면 괄호 수가 어긋날 수 있음 — 문법 검사가 막는다.
