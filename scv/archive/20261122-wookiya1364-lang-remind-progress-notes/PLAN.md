# 도구 뒤 언어 알림 중복 — 생각 항목에 남은 중간 보고도 보기

## Summary

0.99.0 의 도구 뒤 언어 알림이 한국어 중간 보고를 쓴 직후에도 붙었다(2026-11-22, 이 세션에서 여러 번). 훅에 임시 기록 줄을 넣어 재 보니 훅이 본 '마지막 글'은 한참 전 글이었다. 이 환경(Claude Opus 5.5)에서는 도구 사이 중간 보고가 기록 파일에 글(text)이 아니라 생각(thinking) 항목으로 남고, 훅은 글 항목만 읽었다. 알림 판정이 이번 도구 호출 직전에 쓴 글 · 생각 항목을 보게 고친다.

## Goals / Non-Goals

- **Goals**
  - 마지막으로 쓴 묶음(이어진 글 · 생각 항목)에 설정 언어로 쓴 것이 있으면 알림을 싣지 않는다.
- **Non-Goals**
  - 생각 항목의 다른 언어 줄을 교정 — 사용자에게 안 보이는 생각과 가를 수 없다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

| 단계 | 함수 | 순수 | 하는 일 |
|---|---|---|---|
| 읽기 | `_scv_turn_round_notes` | 부수효과(원본 읽기) | 이번 턴 마지막으로 쓴 글 · 생각 묶음 |
| 판정 | `scv_lang_round_ok` | 순수 | 묶음 중 설정 언어 글이 있는가 |
| 싣기 | `on-lang-check.sh` | 부수효과 | 알림 판정에 묶음을 씀 |

## Guardrails

- 재현 시험이 먼저 실패해야 한다.
- 교정 경로(글 항목)는 바꾸지 않는다 — 기존 시험 그대로 통과.

## Exit criteria

- 생각 항목에만 한국어 중간 보고가 있는 기록에서 알림 없음, 글 · 생각 모두 없거나 다른 언어면 알림.
- 이 세션 기록 재생: 알림이 붙는 도구 결과 수가 줄어듦(전후 수).
- 관련 시험 mac · linux 통과.

## Suggested path

1. 재현 시험(생각 항목 중간 보고) — `판정`
2. 묶음 읽기 · 판정 — `읽기` `_scv_turn_round_notes`
3. 훅이 묶음으로 판정 — `싣기` `on-lang-check.sh`
4. 재생 · 관련 시험 mac · linux — `판정`
