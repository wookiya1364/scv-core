# 마무리 보고 — 도구 뒤 언어 알림 중복 — 생각 항목에 남은 중간 보고도 보기

     고장을 고치는 계획이 아니면 2 ~ 5번은 묶음마다 "해당 없음 — 이유" 한 줄로 건너뛴다.

## 1. 문제

- 상황: 0.99.0 의 도구 뒤 언어 알림(설정 언어로 다음 글을 쓰라는 한 줄).
- 기대: 직전에 설정 언어로 중간 보고를 썼으면 알림이 붙지 않음.
- 실제: 한국어 중간 보고를 쓴 직후에도 알림이 붙음(2026-11-22 이 세션에서 여러 번).
- 재현 조건: 도구 사이 중간 보고를 쓰고 도구를 부름 — 동시 호출이 아니어도 일어남.

## 2. 관찰

- 기록 순서: 한국어 중간 보고는 도구 결과보다 먼저 기록 파일에 있었음 — 처음 추정(쓰기 시점 문제)은 틀림.
- 임시 기록 줄: 훅에 넣어 재 보니 훅이 본 '마지막 글'은 한참 전 글이었음.
- 항목 종류: 그 중간 보고는 기록 파일에 글(text)이 아니라 생각(thinking) 항목(요약)으로 남아 있었음.

## 3. 가설

- 가설 1: 기록 쓰기가 훅보다 늦음 — 틀림(순서 확인).
- 가설 2: 훅이 글 항목만 읽어 생각 항목으로 남은 중간 보고를 못 봄 — 맞음.

## 4. 실험

- 재현 시험 T15(생각 항목 중간 보고): 고치기 전 실패 → 고친 뒤 통과.
- 기록 재생(판정 규칙을 옮긴 어림): 묶음만으로 판정하면 알림 19% → 38%(묶음에 안 보이는 영어 생각이 섞임) — 버림. 두 판정을 합치면 이 세션 458 → 392, 다른 프로젝트 세션 555 → 521.
- 실제 확인: 설치본에 덮어쓴 뒤 이 세션에서 한국어 중간 보고 뒤 도구 호출 — 알림 없음(고치기 전에는 매번 붙음).

## 5. 원인

- 직접 원인: 도구 뒤 훅이 '이번 턴 마지막 글'을 글 항목에서만 찾았음.
- 근본 원인: 일부 모델 · 호스트는 도구 사이 중간 보고를 생각 항목으로 남기는데, 언어 판정이 그 저장 방식을 몰랐음.

## 6. 해결과 검증

- 해결책과 고른 이유: 이번 턴 마지막 글 항목이 설정 언어이거나, 마지막으로 쓴 묶음(이어진 글 · 생각 항목) 중 하나라도 설정 언어면 알림을 싣지 않음. 묶음만으로 판정하지 않는 까닭은 안 보이는 영어 생각 때문에 알림이 늘었기 때문. 교정(다른 언어 줄 잡기)은 그대로 글 항목만.
- 고치기 전후 값: 알림이 붙는 도구 결과 — 이 세션 458 → 392(중복 66 없어짐), 다른 프로젝트 세션 555 → 521(34 없어짐). 늘어나는 경우 0(합친 판정은 옛 판정의 부분 집합).
- 부작용과 회귀 시험: test-lang-enforce T15 추가, 기존 17개 그대로 통과. mac · linux 관련 시험 통과(linux test-slow-pure-functions 의 scv_tc_words 어긋남은 고치기 전 판에서도 같음 — 컨테이너 문자 설정).

## 7. 배운 것

- 다음에 같은 문제를 만나면 진단하는 법: 훅에 임시 기록 줄을 넣어 '훅이 실제로 본 값'을 남기고 기록 파일 항목 종류를 함께 봄 — 추정 대신 그 순간 값.
- 다른 곳에도 쓸 수 있는 것: 기록 파일의 글을 읽는 검사는 생각 항목에도 사용자에게 보인 글이 남을 수 있음을 알아야 함 — 다만 안 보이는 생각과 섞이므로 '줄이는 쪽' 판정에만 씀.
