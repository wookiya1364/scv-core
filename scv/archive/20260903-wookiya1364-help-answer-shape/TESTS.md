# Test Plan — help 의 답 모양 (질문이 부르는 자리만)

## Overview

바꾸는 것은 **규약 문구**다. 답은 모델이 쓰므로 출력 자체를 검사하지 않는다 — 그 길은
0.39.0 이 갔다가 걷어냈다. 대신 규약에 **필요한 문장이 다 있는가**를 잠근다. 문장이
없으면 다음 사람이 모르고 지우고, 지우면 답 모양이 조용히 무너진다.

## Test scenarios

### T1. 여섯 자리가 어휘로 있고, 상대 순서가 정해져 있다

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 결론 / 예상 밖 사실 / 항목표 / 상세 / 횡단 관심사 / 결정표 — 여섯
  자리가 골라 쓰는 어휘로 적혀 있고, 고른 자리가 놓이는 상대 순서가 이와 같다.
- **Pass criterion**: 여섯 자리 이름이 모두 있고, 규약 안에서의 등장 순서가 위와 같다.

### T2. 질문이 부르는 자리만 고르고, 자리를 더하지 않는다

이 계획의 핵심이다. 점검표가 아니라 어휘라는 것.

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 질문이 부르는 자리만 고른다는 문장, 결론 자리만 항상 있다는 문장,
  그리고 완성돼 보이려고 자리를 더하지 않는다는 문장이 있다.
- **Pass criterion**: 세 문장이 모두 확인되고, "여섯 자리를 모두 채우라" 로 읽히는
  문장이 없다.

### T3. 짧은 턴은 결론 문단만 남는다

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 짧은 맞장구는 결론 자리 하나만 부른다는 예가 있다.
- **Pass criterion**: 그 예가 확인된다.

### T4. 백지 아이디어는 "없음" 표다

"지금" 열이 전부 "없음" 인 표와 부르지 말아야 할 표를 구분해 두지 않으면, 백지
아이디어에서 표를 빼 버린다.

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 기존 코드가 없을 때 "지금" 열을 "없음" 으로 채운 표가 나온다는
  문장이 있다.
- **Pass criterion**: 그 문장이 확인된다.

### T5. 결정표는 추천이 필수이고 번호로 답하게 한다

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 결정표에 추천 열이 있어야 하고, 사용자가 번호로 답하게 한다는 규칙이
  있다.
- **Pass criterion**: 두 문장이 모두 확인된다.

### T6. 의존 질문은 하나씩, 독립 결정은 한 표

기존 "한 턴에 질문 하나" 와의 충돌을 푼 자리다.

- **Setup**: 없음.
- **Run**: help 규약의 대화 루프 절을 읽는다.
- **Expected**: 다음 질문이 앞 답에 의존하면 하나씩, 서로 독립이면 추천 붙여 한 표로
  묻는다는 구분이 있다.
- **Pass criterion**: 의존/독립 두 갈래가 모두 확인되고, 옛 문장("Don't dump all
  questions at once")이 조건 없이 남아 있지 않다.

### T7. 쉬운말은 결론 문단을, 이 절은 그 뒤를 다스린다

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 쉬운말 규칙이 결론 문단(첫 1–2문장)을 다스리고, 답 모양 절이 그 뒤
  본문을 다스린다는 역할 분담이 적혀 있다.
- **Pass criterion**: 그 문장이 확인되고, 쉬운말 절의 본문은 바뀌지 않았다.

### T8. 사실에는 "확인됨" 을 붙인다

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: 확인한 사실에 표시를 붙이고 추정과 섞지 않는다는 규칙이 있다.
- **Pass criterion**: 그 문장이 확인된다.

### T9. 되돌림을 만들지 않았다

- **Setup**: 없음.
- **Run**: 규약과 훅을 읽는다.
- **Expected**: 답 모양을 검사해 차단하거나 되돌리는 문장·코드가 없다.
- **Pass criterion**: 규약의 답 모양 절에 "block"·"retry"·"되돌" 이 없고, 종료 훅은
  바뀌지 않았다.

### T10. 사람의 말로 — 만든 이름을 사용자에게 내보내지 않는다

이 계획을 만드는 대화에서 실제로 일어난 일이다. 규약의 여섯 부분에 붙인 이름은
모델용이지 사람용이 아니다.

- **Setup**: 없음.
- **Run**: help 규약의 답 모양 절을 읽는다.
- **Expected**: 이 절의 이름들은 사용자에게 나가지 않는다는 문장, 사용자가 쓴 말을
  그대로 쓴다는 문장, 피할 수 없는 용어는 같은 문장에서 예와 함께 설명하고 그 뒤로는
  쓰지 않는다는 문장이 있다.
- **Pass criterion**: 세 문장이 모두 확인된다.

### T11. 옛 계약 문구가 살아 있다

대체하지 않은 옛 계획이 "one question per turn" 을 잠가 두었다. 새 규칙(의존 질문은
한 턴에 하나)과 모순되지 않으므로 문구를 유지한다.

- **Setup**: 없음.
- **Run**: help 규약을 읽는다.
- **Expected**: "one question per turn" 이 대화 루프 절에 있다.
- **Pass criterion**: 그 문구가 확인된다.

## How to run

```bash
bash core/tests/test-help-shape.sh
```

## Pass criteria

- T1~T11 모두 통과.
- 쉬운말 절 본문이 바이트 단위로 그대로다 (T7).
