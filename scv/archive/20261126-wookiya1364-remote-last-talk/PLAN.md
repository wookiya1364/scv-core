# 원격 화면에도 비우기 전 직전 대화가 보인다 — 저장되는 글에 줄인 직전 대화를 넣는다

## Summary

대시보드는 자동으로 비운 직후 자기 명령을 돌리고, 그 출력 줄에 비우기 전의 마지막 대화를 그린다. 그런데 대화에 저장되는 글은 한 줄 안내뿐이고, 직전 대화는 호스트 앱이 화면을 그릴 때만 끼워 넣는다. 그래서 저장된 대화를 그리는 원격 화면에는 한 줄 안내만 보인다(사용자가 2026-11-26 에 사진으로 알림).

이 계획은 저장되는 글을 줄인 직전 대화로 바꾼다. 직전 대화마다 앞 150자와 끝 150자를 남기고(300자 이하면 전체), 가운데는 줄임표로 줄인다. 사용자가 선택 창에서 고른 모양이다.

## Goals / Non-Goals

- **Goals**
  - 자동으로 비운 뒤 원격 화면에도 직전 대화 최대 3개가 보인다
  - 저장되는 글은 짧다 — 직전 대화마다 내 글과 답이 각각 300자를 넘지 않는다
- **Non-Goals**
  - 호스트 화면을 바꾸는 것(지금처럼 전체)
  - 직전 대화를 통째로 저장하는 것(Claude 가 긴 답을 다시 읽게 되어 버림)
  - 기억하는 대화 수를 바꾸는 것

## Approach Overview

저장되는 글을 바꾸는 자리는 이미 있다. 대시보드는 자기 명령의 출력 줄이 저장될 때 그 글을 한 줄 안내로 바꾼다. 이 자리에서 한 줄 안내 대신 줄인 직전 대화를 넣는다. 줄이는 일과 묶는 일은 순수 함수 둘로 만든다. 직전 대화가 없으면 지금의 한 줄 안내를 그대로 쓴다.

Claude 는 저장된 글을 읽는다. 그래서 줄인 글의 머리말에 "표시용이며 할 일이 아니다"를 남긴다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  trimTalk,        // 글 하나 → 앞 150자 + … + 끝 150자 (300자 이하면 그대로)
  storedTalkPage,  // 직전 대화들 → 저장할 글 하나
  swapOutput,      // 저장될 출력 줄 + 저장할 글 → 바뀐 출력 줄 (이미 있음)
)
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | trimTalk | 긴 글의 가운데를 줄인다 | 글, 남길 글자 수 → 줄인 글 | 순수 |
| 2 | storedTalkPage | 줄인 직전 대화를 한 글로 묶는다 | 직전 대화 목록 → 저장할 글 | 순수 |
| 3 | swapOutput | 출력 줄의 글을 바꾼다 | 출력 줄, 넣을 글 → 바뀐 출력 줄 | 순수 |
| 4 | 저장 글 바꾸기 | 저장되는 순간 글을 바꿔 넘긴다 | 저장될 줄 → 바뀐 줄 | 부수효과 (출구) |

- 부수효과 위치: 4단계만 — 기억해 둔 직전 대화를 읽고, 바뀐 줄을 다음으로 넘긴다
- 재사용: `swapOutput`, `isTalkOutput`, `isEchoOf`, 직전 대화를 기억하는 자리(`talks`)

## Guardrails

- 호스트 화면에 그리는 글(직전 대화 전체)은 바꾸지 않는다
- 저장 글에는 긴 답을 통째로 넣지 않는다 — 글 하나에 300자까지
- 다른 명령의 출력 줄은 건드리지 않는다
- 직전 대화가 없을 때의 한 줄 안내는 지금 그대로다

## Exit criteria

- All TESTS.md scenarios pass
- 모드 시험 전부 통과
- 실제 저장 글 하나를 만들어 보고에 그대로 남긴다
- 원격 화면에서 보이는 것은 릴리스 뒤 사용자가 직접 본다(이 계획 안에서는 확인하지 못한다)

## Suggested path

1. 긴 글의 가운데를 줄이는 함수를 만든다 — `trimTalk`
2. 줄인 직전 대화를 한 글로 묶는다 — `storedTalkPage`
3. 저장될 때 한 줄 안내 대신 그 글을 넣는다 — `swapOutput`, `저장 글 바꾸기`
4. 모드 시험을 돌리고 실제 저장 글을 만들어 본다 — 시험 통과와 저장 글 모양을 확인한다

## Risks / Open Questions

- 원격 화면이 저장된 글을 그대로 그린다는 것은 사진으로 본 것이다(한 줄 안내가 글자까지 같았다). 여러 줄 글도 줄바꿈까지 그대로 그리는지는 릴리스 뒤에 봐야 안다.
