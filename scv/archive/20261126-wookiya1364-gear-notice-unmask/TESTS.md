# Test Plan — 맞는 기어가 있어도 반복을 알린다

## Overview

기어가 맞는 턴에도 반복이 같은 줄에 실리는지, 그 줄이 한 줄인지, 반복이 실린 알림을 "만들지 않음"으로 적을 수 있는지, 반복 꼬리에 세 갈래(묻기 · 일이 아니면 적기 · 이유 알리기)가 있는지, 기어만 맞는 턴과 겹치지 않는 턴이 전과 같은지 확인한다. 시험은 `core/tests/test-gear-detect.sh` 에 더한다.

## Test scenarios

### T1. 기어가 맞고 비슷한 요청이 전에도 있었으면 한 줄에 함께 알린다

- **Setup**: 기어 하나(낱말 "목록 만들기 정리")가 있는 프로젝트, 같은 요청을 한 번 보낸 뒤
- **Run**: 같은 요청을 한 번 더 보낸다
- **Expected**: `[SCV 기어 알림]` 줄이 하나다. 그 줄에 기어 이름 · 돌리는 명령과, "그 기어가 하는 일과 다르면" 뒤로 지난 요청 · 기어로 만들지 묻는 말이 함께 있다
- **Pass criterion**: 알림 줄 1, 기어 이름 · `run <이름>` · 지난 요청 글 · "기어로 만들어 재사용" 포함

### T2. 기어만 맞고 반복이 없으면 전과 글자까지 같다

- **Setup**: 기어가 있는 프로젝트, 요청 기록 없음
- **Run**: 기어와 낱말이 겹치는 요청을 처음 보낸다
- **Expected**: 기어 알림 한 줄, 끝이 "다른 일이면 이 줄을 무시한다." — 만들기 권유 없음
- **Pass criterion**: `scv_gear_notice_line` 에 기어만 준 결과가 고치기 전의 글과 같다

### T3. 반복만 있으면 꼬리에 세 갈래가 있다

- **Setup**: 기어 없는 프로젝트, 같은 요청을 한 번 보낸 뒤
- **Run**: 같은 요청을 한 번 더 보낸다
- **Expected**: 알림 줄에 "선택 도구로" 묻는 말, "일을 시키는 글이 아니면" 적으라는 말과 `decline` 명령, "묻지 않았으면 … 이유를 한 줄" 이 있다
- **Pass criterion**: 세 문구 포함

### T4. 기어와 함께 실린 반복도 "만들지 않음"으로 적을 수 있다

- **Setup**: T1 의 두 번째 턴 뒤
- **Run**: `gear.sh decline` 을 돌리고 같은 요청을 한 번 더 보낸다
- **Expected**: 적었다는 답이 나온다. 다음 턴의 알림은 기어만 알리는 글(전과 같은 글)이고 반복 꼬리가 없다
- **Pass criterion**: decline 출력에 "적음", 다음 알림에 "기어로 만들어 재사용" 없음

### T5. 겹치는 것이 없는 턴과 첫 턴은 전과 같다

- **Setup**: 기존 시험 T3 · T4 의 프로젝트
- **Run**: 기존 시험 그대로
- **Expected**: 켠 훅과 끈 훅의 출력이 바이트까지 같다
- **Pass criterion**: 기존 T3 · T4 통과

### T6. 매 턴 시간은 그대로다

- **Setup**: 기어 스무 개 · 기록 200줄(기존 T11)
- **Run**: 켠 훅과 끈 훅을 다섯 번씩
- **Expected**: 켠 훅이 끈 훅의 1.5배 이내
- **Pass criterion**: 기존 T10 · T11 통과

### T7. 실제 요청을 다시 흘린 전후 값 (손으로 한 번)

- **Setup**: 두 프로젝트의 요청 기록 84줄(54 + 30)과 그 프로젝트의 기어 사전
- **Run**: 줄마다 고치기 전 판정과 고친 판정을 차례로 돌린다(적어 두기는 하지 않은 것으로 센다)
- **Expected**: 기어가 맞은 턴 가운데 반복이 함께 실리는 턴이 생긴다(전에는 0). 반복만 알린 턴 수와 기어만 알린 턴의 합은 전의 알림 수와 같다 — 알림이 실리는 턴은 늘지 않는다
- **Pass criterion**: 전후 표를 보고에 남긴다

### T8. 화면 없는 실행에서 모델이 알림대로 한다 (손으로 한 번)

- **Setup**: 고친 본체를 얹은 설치본 사본, 작은 프로젝트에 진행을 묻는 같은 글을 한 번 쌓아 둠
- **Run**: 같은 글을 한 번 더 보낸다
- **Expected**: 모델이 기어 질문을 하지 않고, `gear.sh decline` 을 돌리고, 답 끝에 이유를 한 줄로 적는다
- **Pass criterion**: 답과 기록 파일(`.gear-declined`)을 보고에 남긴다 — 그렇게 하지 않았으면 그대로 적는다

## How to run

```bash
bash core/tests/test-gear-detect.sh
```

## Pass criteria

- T1 ~ T6 이 시험 파일로 통과한다(맥 기본 셸 · 새 셸)
- T7 · T8 의 출력이 보고에 남는다
- 순수 함수 사전 검사 통과
