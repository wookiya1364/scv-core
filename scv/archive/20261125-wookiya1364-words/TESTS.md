# Test Plan — 낱말 사전

## Overview

사전에 넣은 피할 말이 (1) 대화 첫머리의 안내 묶음으로 한 번 실리는지, (2) 답에 나오면 다음 턴에 한 줄로 알려지는지, (3) 사전이 없는 프로젝트에서는 아무것도 달라지지 않는지를 본다. 사전 파일을 읽고 쓰는 명령의 출력 줄은 대시보드와 맞춘 약속이라 한 줄씩 그대로 견준다.

T1–T7 은 순수 함수를 직접 부르고, T8–T12 는 임시 폴더의 시험용 프로젝트에서 명령을 돌리고, T13–T15 는 같은 프로젝트에서 두 훅을 직접 부른다. 시험 자료의 사전은 `재다 → 측정하다` · `유저 → 사용자` · `utilize → use` 다.

## Test scenarios

### T1. 사전 파일 글을 항목으로 읽는다

- **Setup**: 주석 줄 · 빈 줄 · 칸이 둘뿐인 줄 · 같은 피할 말이 두 번 나오는 줄이 섞인 글.
- **Run**: `scv_words_parse` 에 그 글을 넣는다.
- **Expected**: 주석 줄과 빈 줄은 빠지고, 줄마다 네 칸이 되고, 같은 피할 말은 앞의 것만 남는다.
- **Pass criterion**: 출력이 기대 글과 글자까지 같다.

### T2. 넣기 — 같은 피할 말이면 갈아 끼우고, 꼴을 주지 않으면 있던 꼴을 지킨다

- **Setup**: `재다 → 측정하다`(꼴 여섯) 가 든 항목 줄들.
- **Run**: `scv_words_upsert` 로 같은 피할 말에 쓸 말만 바꿔 넣는다(꼴 없음). 그다음 꼴을 줘서 넣는다. 새 피할 말도 넣는다.
- **Expected**: 첫째는 쓸 말만 바뀌고 꼴은 그대로, 둘째는 꼴이 바뀌고, 셋째는 맨 뒤에 줄이 는다. 항목의 자리는 바뀌지 않는다.
- **Pass criterion**: 세 출력이 기대 글과 같다.

### T3. 빼기 — 있는 말은 빠지고, 없는 말은 실패한다

- **Run**: `scv_words_remove` 에 있는 피할 말과 없는 피할 말을 넣는다.
- **Pass criterion**: 있는 말은 그 줄만 빠지고 종료 코드 0, 없는 말은 종료 코드 1 이고 줄들이 그대로다.

### T4. 낱말 첫머리에서만 센다

- **Setup**: `재다`(꼴: 잰, 재서, 재 본, 재 봤, 쟀다, 재는).
- **Run**: `scv_words_hits` 에 "현재다" · "어잰" 이 든 글, "잰 값" · "(잰 값" · "값은 재 봤을 때" 가 든 글을 넣는다.
- **Expected**: 앞의 글은 찾은 것이 없고, 뒤의 글들은 찾은 꼴 한 줄이 나온다.
- **Pass criterion**: 앞 0줄, 뒤 각각 `잰 → 측정하다` · `잰 → 측정하다` · `재 봤 → 측정하다`.

### T5. 코드와 인용한 사용자 글은 건너뛴다

- **Run**: 피할 말이 울타리 코드 블록 안 · 백틱 안 · `>` 로 시작하는 줄에만 있는 글과, 그 밖의 줄에도 있는 글을 넣는다.
- **Pass criterion**: 앞은 0줄, 뒤는 1줄.

### T6. 꼴이 빈 항목 — 피할 말 그대로와 두 글자 이상의 어간만 찾는다

- **Setup**: `사용하다 → 쓰다`(꼴 없음), `재다 → 측정하다`(꼴 없음).
- **Run**: "사용하는 값" · "재는 값" · "재다" 가 든 글을 넣는다.
- **Expected**: "사용하는"은 어간 "사용하"로 찾고, "재는"은 찾지 않고(어간이 한 글자), "재다"는 찾는다.
- **Pass criterion**: 차례로 1줄 · 0줄 · 1줄.

### T7. 끄기 — 안내도 검사도 하지 않는다

- **Setup**: 사전이 있는 프로젝트, 설정 `SCV_WORDS=off`(설정 파일과 환경 변수 각각).
- **Run**: `words.sh text`, 피할 말이 든 답으로 `words.sh check`, `words.sh list`.
- **Pass criterion**: text 출력 0바이트, check 출력 0줄 · 종료 코드 0, list 는 항목이 그대로 나온다.

### T8. 명령 list

- **Run**: 사전이 없는 프로젝트와 항목 둘인 프로젝트에서 `words.sh list`.
- **Pass criterion**: 없으면 `WORDS: none` 한 줄 · 종료 코드 0. 있으면 저장된 줄 그대로(탭 네 칸) 두 줄.

### T9. 명령 add

- **Run**: `words.sh add --avoid 재다 --use 측정하다 --forms "잰, 재서"`, 같은 피할 말을 `--forms` 없이 다시, 빈 `--avoid`, 빈 `--use`, 두 말이 같은 경우, 칸 안에 탭 · 줄바꿈이 든 경우.
- **Expected**: `WORDS_SAVED: 재다 → 측정하다`. 다시 넣으면 꼴이 그대로다. 잘못된 셋은 `WORDS_ERROR:` 줄과 종료 코드 2 이고 파일이 바뀌지 않는다. 탭 · 줄바꿈은 빈칸이 된다.
- **Pass criterion**: 출력 줄 · 종료 코드 · 파일 내용이 기대와 같다.

### T10. 명령 remove

- **Run**: 있는 피할 말과 없는 피할 말로 `words.sh remove`.
- **Pass criterion**: `WORDS_REMOVED: <말>` · 종료 코드 0, 없는 말은 `WORDS_ERROR:` · 종료 코드 1.

### T11. 명령 check

- **Run**: 피할 말 둘이 든 답과 없는 답을 표준 입력으로 넣는다.
- **Pass criterion**: 앞은 `WORDS_HIT: <찾은 꼴> → <쓸 말>` 두 줄(항목마다 한 줄) · 종료 코드 1, 뒤는 출력 없음 · 종료 코드 0.

### T12. 명령 text

- **Run**: 설정 언어가 한국어인 프로젝트와 아닌 프로젝트에서 `words.sh text`, 항목이 없는 프로젝트에서도.
- **Expected**: 머리 한 줄 + 항목마다 한 줄. 머리에 "적힌 꼴은 예일 뿐"과 "코드 · 파일 이름 · 인용한 사용자 글 · 명령에는 적용하지 않는다"는 뜻이 있다. 한국어가 아니면 영어 글이다. 항목이 없으면 출력이 없다.
- **Pass criterion**: 줄 수 = 항목 수 + 1, 표식 글 있음, 항목 없음일 때 0바이트.

### T13. 매 턴 훅 — 맥락마다 한 번, 요약 뒤 다시, 사전이 바뀌면 다시

- **Setup**: 사전이 있는 프로젝트.
- **Run**: 같은 세션으로 훅을 두 번 부른다. 초기화(요약 · 비움 · 재개 때 도는 명령)를 돌리고 한 번 더 부른다. 사전에 항목을 더하고 한 번 더 부른다. 자동 알림 턴으로도 부른다.
- **Pass criterion**: 안내 묶음 머리 줄 수가 차례로 1 · 0 · 1 · 1, 자동 알림 턴 0.

### T14. 사전이 없는 프로젝트의 훅 출력은 지금과 바이트까지 같다

- **Setup**: 사전이 없는 프로젝트. 낱말 구간을 지운 훅 사본.
- **Run**: 같은 입력으로 두 훅을 부른다(첫 턴과 둘째 턴). 주석 줄만 있는 사전 파일로도 부른다.
- **Pass criterion**: `cmp` 종료 코드 0 (세 번 모두).

### T15. 턴 끝 훅 — 다음 턴 한 줄, 막지 않는다

- **Setup**: 사전이 있는 프로젝트, 대화 기록 파일.
- **Run**: 피할 말이 든 답으로 턴 끝 훅을 부른다. 다음 사람 턴의 매 턴 훅을 부른다. 피할 말이 없는 답 · 자동 알림으로 열린 턴 · 끈 설정으로도 부른다.
- **Expected**: 턴 끝 훅은 막는 출력이 없다. 다음 턴 안내에 `[SCV 낱말] 직전 답에 피할 말이 있었다: 잰 → 측정하다 …(직전 답은 다시 쓰지 않는다).` 한 줄이 실리고 그다음 턴에는 없다. 나머지 셋은 줄이 없다.
- **Pass criterion**: 그 줄 수가 1 · 다음 턴 0, 나머지 0. 턴 끝 훅 출력에 `"decision"` 없음.

### T16. 두 셸에서 같은 결과

- **Run**: 순수 함수 묶음(T1–T6 의 입력)을 맥 기본 셸(3.2)과 새 셸로 각각 돌린다. 글자 설정을 C 로 바꿔서도 돌린다.
- **Pass criterion**: 세 출력의 지문이 같다. 기본 셸이 없는 기계에서는 그 부분을 건너뛴다고 한 줄로 밝힌다.

### T17. 액션 목록과 순수성

- **Run**: 액션 목록에서 words 를 읽고, 순수성 검사를 새 파일에 돌린다.
- **Pass criterion**: 액션이 23개이고 words 의 규약 · 입구가 맞다. 순수성 검사 종료 코드 0.

## How to run

```bash
bash core/tests/test-words.sh
```

## Pass criteria

- T1–T17 이 모두 `ok` 로 찍히고 종료 코드 0 — 맥 기본 셸과 새 셸 둘 다.
- 순수 함수 사전 검사(`bash core/scripts/pure-catalog.sh check`)와 액션 목록 시험(`bash tests/test-actions.sh`) 통과.
