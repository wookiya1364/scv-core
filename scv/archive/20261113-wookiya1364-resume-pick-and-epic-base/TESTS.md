# Test Plan — 복원 요약이 끝난 대화를 싣던 것 · PR 도구가 묶음 계획 가지를 늘 main 에서 만들던 것

## Overview

두 가지를 본다. 첫째, 세션을 비우거나 다시 연 뒤의 복원 요약이 구현 중인 계획에 이어진 대화를 먼저 싣고, 오래 손대지 않은 대화는 전문 대신 경로만 알린다. 둘째, PR 도구가 묶음 계획의 가지를 PR 대상과 같은 순서의 출발점에서 만들고, 출발점이 없으면 커밋하기 전에 멈춘다. 시험은 임시 폴더에 가짜 프로젝트 · 가짜 대화 · 가짜 원격을 만들어 실제 훅과 명령을 돌린다.

## Test scenarios

### T1. 구현 중인 계획에 이어진 대화를 먼저 싣는다

- **Setup**: 대화 셋 — (가) "진행 중" 표시, 어제 손댐 (나) "계획으로 넘김" 표시, 이틀 전 손댐, 구현 중인 계획의 원자료 목록에 적힘 (다) "진행 중" 표시, 10일 전 손댐
- **Run**: 세션 시작 훅(비우기 뒤)
- **Expected**: (나)의 전문이 실린다. (가)는 경로만, (다)는 "오래 손대지 않음" 묶음에 경로만
- **Pass criterion**: 출력에 (나)의 본문 있음 · (가) · (다)의 본문 없음 · (가)의 경로 1번 · (다)의 경로 1번

### T2. 계획에 이어진 대화가 없으면 최근에 손댄 진행 중 대화를 싣는다

- **Setup**: 대화 둘 — (가) "진행 중", 어제 손댐 (다) "진행 중", 10일 전 손댐. 구현 중인 계획 없음
- **Run**: 세션 시작 훅
- **Expected**: (가)의 전문. (다)는 오래된 묶음에 경로만
- **Pass criterion**: (가)의 본문 1번 · (다)의 본문 0번

### T3. 모두 오래됐으면 전문을 싣지 않는다

- **Setup**: "진행 중" 대화 둘, 5일 전 · 10일 전에 손댐. 구현 중인 계획 없음
- **Run**: 세션 시작 훅
- **Expected**: 대화 전문 없음. 두 경로가 "오래 손대지 않음"으로 나온다. 계획 요약 등 다른 묶음은 지금과 같다
- **Pass criterion**: 본문 0개 · 경로 2개 · 종료 코드 0 · 표준 오류 0줄

### T4. 기준은 3일이다

- **Setup**: "진행 중" 대화 둘 — 하나는 2일 23시간 전, 하나는 3일 1시간 전에 손댐
- **Run**: 고르는 함수에 지금 시각과 기준 초를 줘서 부른다
- **Expected**: 앞의 것은 고르고, 뒤의 것은 오래된 것으로 낸다
- **Pass criterion**: 고른 경로 1개(앞의 것) · 오래된 경로 1개(뒤의 것)

### T5. 계획의 목록에 적힌 대화가 없는 파일이면 다음 후보로 간다

- **Setup**: 구현 중인 계획의 원자료 목록에 없는 대화 경로. "진행 중" 대화 하나(어제)
- **Run**: 세션 시작 훅
- **Expected**: 어제의 대화가 실린다. 오류 없음
- **Pass criterion**: 그 본문 있음 · 종료 코드 0 · 표준 오류 0줄

### T6. 끝난 계획 · 세우기만 한 계획의 대화는 우선하지 않는다

- **Setup**: 표시가 "세움" · "끝남"인 계획의 목록에 적힌 "계획으로 넘김" 대화 둘
- **Run**: 세션 시작 훅
- **Expected**: 둘 다 실리지 않는다 — 구현 중(진행 중 · 시험 중)인 계획만 본다
- **Pass criterion**: 두 본문 0개

### T7. 지금의 안전장치는 그대로다

- **Setup**: 지금의 세션 복원 시험 전체(연결 파일 · 이름에 탭 · 줄바꿈 · 폴더 없음 · 가림 필터 · 크기 상한)
- **Run**: 그 시험 파일
- **Expected**: 고치기 전에 통과하던 줄이 모두 통과한다
- **Pass criterion**: 실패 0

### T8. 세션 시작 훅이 느려지지 않는다

- **Setup**: 대화 300개 · 계획 20개인 가짜 프로젝트
- **Run**: 세션 시작 훅을 고치기 전 · 뒤 코드로 세 번씩
- **Expected**: 가장 빠른 값끼리 견줘 고친 쪽이 1.5배를 넘지 않는다
- **Pass criterion**: 뒤 ≤ 앞 × 1.5 + 0.1초

### T9. 묶음 계획의 가지를 설정한 대상에서 만든다

- **Setup**: 가짜 원격 — 가지는 develop 과 main(내용이 다름). 설정한 PR 대상은 develop. 묶음 계획의 가지는 원격에 없음
- **Run**: PR 도구
- **Expected**: 원격에 묶음 계획의 가지가 생기고, 그 끝이 develop 의 끝과 같다(main 이 아님). PR 대상은 그 가지
- **Pass criterion**: 새 가지의 커밋 = develop 의 커밋 · 종료 코드 0

### T10. 설정이 없으면 원격의 기본 가지에서, 그것도 없으면 main 에서 만든다

- **Setup**: (가) 설정 없음 · 원격의 기본 가지가 trunk (나) 설정 없음 · 기본 가지 정보 없음 · main 있음
- **Run**: PR 도구
- **Expected**: (가) trunk 의 끝에서, (나) main 의 끝에서 만든다
- **Pass criterion**: 출발점의 커밋과 다른 경우 0개 — (가) trunk · (나) main 의 커밋과 같음

### T11. 출발점이 원격에 없으면 커밋하기 전에 멈춘다

- **Setup**: 설정 없음 · 원격에 main 없음(가지는 trunk 뿐, 기본 가지 정보 없음). 묶음 계획의 가지도 없음
- **Run**: PR 도구
- **Expected**: 종료 코드 1. 출발점의 이름과 고치는 길(설정)을 대는 글. 로컬에 새 커밋 0개, 원격에 새 가지 0개, PR 만들기 호출 0번
- **Pass criterion**: 종료 코드 1 · 새 커밋 0 · 새 가지 0 · PR 호출 0 (고치기 전: 커밋 1개가 생긴 뒤 실패)

### T12. 묶음 계획의 가지가 이미 있으면 그대로 쓴다 · 묶음 계획이 아니면 달라지지 않는다

- **Setup**: (가) 원격에 묶음 계획의 가지가 이미 있음 (나) 묶음 계획이 아닌 보통 계획
- **Run**: PR 도구
- **Expected**: (가) 그 가지를 건드리지 않고 PR 을 연다 (나) 지금의 PR 대상 시험이 모두 통과한다
- **Pass criterion**: (가) 그 가지의 커밋 그대로 · (나) 기존 시험 실패 0

## How to run

```bash
bash core/tests/test-session-resume.sh && bash core/tests/test-pr-base.sh && bash core/scripts/check-purity.sh && LC_ALL=C bash core/scripts/pure-catalog.sh check
```

## Pass criteria

- T1 ~ T12 가 맥의 옛 셸(bash 3.2)과 새 셸(bash 5)에서 통과한다 — 시간을 보는 T8 은 다른 시험과 겹치지 않게 혼자 돌려 판정한다
- 순수 검사 · 함수 사전 검사 종료 코드 0 (C 언어 설정에서도 위반 0건)
- PR 을 올리기 전 전체 시험 한 번에서 실패 0, PR 의 검사(리눅스 · 맥) 전부 성공
