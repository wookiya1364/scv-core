# Test Plan — 기어 돌리기

## Overview

프로젝트 scv 안에 둔 기어(스킬 — 맨 위 flow 줄로 톱니를 잇는다)와 톱니(아주 작은 sh)가 약속대로 도는지 본다: 톱니는 실행기가 직접 돌리고 결과가 매번 같은가, 판단 단계(@)에서만 모델에게 넘어가는가, 밖으로 나가는 톱니는 사용자의 "실행" 답 없이 돌지 않는가, 순수 톱니의 예시가 실제 결과와 맞는가, 호스트 스킬 폴더와 매 턴 훅을 건드리지 않는가.

모든 시나리오는 임시 폴더에 만든 시험용 프로젝트에서 돈다. 시험용 프로젝트에는 톱니 다섯(순수 둘 · effect 둘 · outward 하나)과 기어 다섯이 있다.

## Test scenarios

### T1. 같은 입력이면 톱니 단계 결과가 매번 같다

- **Setup**: 순수 톱니 둘로만 된 기어(flow 에 @ 없음), 입력 "hello" + 줄바꿈.
- **Run**: 같은 입력으로 기어를 두 번 돌려 결과를 각각 파일로 받는다.
- **Expected**: 두 결과 파일이 바이트까지 같고, 값은 6(대문자로 바꾼 뒤 센 바이트 수)이다.
- **Pass criterion**: `cmp` 종료 코드 0, 실행 종료 코드 0, 값 6.

### T2. 판단 단계에서만 멈추고, 그 기어의 글과 앞 결과만 넘긴다

- **Setup**: flow 가 `톱니 | @ | 톱니` 인 기어. 글이 있는 다른 기어가 하나 더 있다(이 흐름에 안 쓰임).
- **Run**: 기어를 돌린다.
- **Expected**: 첫 톱니가 돈 뒤 실행기가 멈춘다. 내놓은 글에 이 기어의 글 전문, 앞 단계 결과, 이어가기 표가 있다. 다른 기어의 글과 맨 위 flow 줄은 없다. 마지막 톱니는 아직 돌지 않았다.
- **Pass criterion**: 종료 코드 10, 출력에 세 가지가 모두 있고 다른 기어 글의 표식 0건 · `flow:` 줄 0건, 마지막 톱니의 표식 파일 없음.

### T3. 모델의 결과를 돌려주면 남은 톱니가 이어진다

- **Setup**: T2 에서 멈춘 상태.
- **Run**: 이어가기 표와 함께 판단 단계의 결과를 표준 입력으로 돌려준다. 같은 표로 한 번 더 시도한다.
- **Expected**: 마지막 톱니가 그 결과를 입력으로 받아 돌고, 최종 결과가 기대값과 같다. 두 번째 시도는 거절된다.
- **Pass criterion**: 종료 코드 0, 최종 출력이 기대 글과 같음, 두 번째 시도는 0 이 아닌 종료 코드.

### T4. 밖으로 나가는 톱니는 확인 없이 돌지 않는다

- **Setup**: `outward` 톱니가 마지막인 기어. 그 톱니는 실행되면 표식 파일을 남긴다.
- **Run**: (a) 그냥 돌린다. (b) 확인 없이 이어가기를 시도한다. (c) 확인 물음에 "실행하지 않음"으로 답한 것으로 적고 이어가기를 시도한다. (d) "실행"으로 답한 것으로 적고 이어 간다.
- **Expected**: (a) 그 톱니 앞에서 멈추고, 질문에 넣을 확인 표(표와 단계 번호)를 낸다. (b)(c) 다시 멈춘다 — 표식 파일 없음. (d) 그 톱니가 돌고 표식 파일이 생긴다.
- **Pass criterion**: (a)(b)(c) 종료 코드 11 + 표식 파일 없음, (d) 종료 코드 0 + 표식 파일 있음.

### T5. 검사가 표시 없는 위험 명령을 잡고, 잡힌 톱니는 돌리지 않는다

- **Setup**: 표시가 `pure` · `effect` 인데 본문에 push · 삭제 · 네트워크 명령이 든 톱니 셋(하나는 실행되면 표식 파일을 남긴다), 같은 명령이 있고 표시가 `outward` 인 톱니 하나.
- **Run**: 검사 명령.
- **Expected**: 표시 없는 셋은 톱니 이름과 줄 번호와 함께 지목되고 검사가 실패한다. `outward` 톱니는 지목되지 않는다. 지목된 톱니는 예시로도 실행되지 않는다.
- **Pass criterion**: 종료 코드 0 아님, 지목 줄 3건(이름 · 줄 번호 맞음), `outward` 톱니 이름 0건, 표식 파일 없음.

### T6. 잘못된 흐름은 한 단계도 돌기 전에 막힌다

- **Setup**: (a) 사전에 없는 이름을 가리키는 flow, (b) 앞 톱니가 돌려주는 값 이름과 뒤 톱니가 받는 값 이름이 다른 flow. 첫 톱니는 실행되면 표식 파일을 남긴다.
- **Run**: 각각 실행.
- **Expected**: 둘 다 오류 줄에 단계 번호와 이유를 내고 멈춘다. 첫 톱니도 돌지 않는다.
- **Pass criterion**: 종료 코드 1, 오류 줄에 단계 번호, 표식 파일 없음.

### T7. 만든 사전은 스크립트가 쓰고, 어긋나면 검사가 잡는다

- **Setup**: 빈 프로젝트.
- **Run**: 만들기 명령으로 톱니 하나를 만든다. 그 뒤 INDEX.tsv 를 손으로 한 줄 고치고 검사한다.
- **Expected**: 만든 직후 사전에 그 톱니의 한 줄이 있고 검사가 통과한다. 손으로 고친 뒤에는 검사가 어긋난 이름을 지목하며 실패한다.
- **Pass criterion**: 사전 줄 수 1, 첫 검사 종료 코드 0, 둘째 검사 종료 코드 0 아님 + 이름 지목.

### T8. 호스트 스킬 폴더에는 아무것도 쓰지 않는다

- **Setup**: 시험용 프로젝트에 `.claude` 폴더와 그 안 파일 하나.
- **Run**: 만들기 · 목록 · 검사 · 실행 · 이어가기를 모두 한 번씩 돈다.
- **Expected**: `.claude` 아래 파일 목록과 내용이 전후에 같다. 새로 생긴 파일은 `scv/gears/` 아래에만 있다.
- **Pass criterion**: 전후 해시 비교가 같음, 새 파일 경로가 모두 `scv/gears/` 로 시작(실행 상태는 시험이 프로젝트 밖으로 돌려 둠).

### T9. 기어 없는 프로젝트는 그대로다

- **Setup**: `scv/gears/` 가 없는 프로젝트.
- **Run**: 목록 명령. 그리고 매 턴 훅 폴더가 실행기를 부르는지 본다.
- **Expected**: 목록은 "기어 없음" 한 줄과 종료 코드 0 이고 폴더를 만들지 않는다. 매 턴 훅은 실행기를 부르지 않는다.
- **Pass criterion**: 출력 1줄 · 종료 코드 0 · 폴더 없음, `core/template/hooks/` 에 실행기 이름 0건.

### T10. `/scv:gear` 명령이 있고 명령 개수가 23 이다

- **Setup**: 변경 뒤 저장소.
- **Run**: 명령 목록 파일과 명령 글을 본다.
- **Expected**: 명령 23개, gear 명령이 명령 글과 실행기를 가리키고, 명령 글이 목록 · 만들기 · 검사 · 실행을 안내한다.
- **Pass criterion**: 개수 23, gear 항목 있음, 명령 글에 네 가지 명령.

### T11. 사전 글은 정해진 그대로다

- **Setup**: 톱니 하나가 있는 프로젝트.
- **Run**: 사전을 다시 만든다.
- **Expected**: INDEX.tsv 의 한 줄이 정해진 글(탭으로 나눈 일곱 칸)과 바이트까지 같다 — 맥과 리눅스가 같은 글을 낸다.
- **Pass criterion**: 기대 글과 같음.

### T12. 순수 톱니는 예시로 검사한다

- **Setup**: (a) 예시가 본문의 실제 결과와 맞는 순수 톱니(탭 · 줄바꿈 · 한글이 든 예시), (b) 예시가 틀린 순수 톱니, (c) 예시가 없는 순수 톱니.
- **Run**: 각각 검사.
- **Expected**: (a) 통과. (b) 실패 — 기대한 글과 실제 글을 보여 준다. (c) 실패 — 예시가 없다고 알린다.
- **Pass criterion**: (a) 종료 코드 0, (b)(c) 종료 코드 0 아님 + 해당 줄.

### T13. 한 가지 일만 — 큰 톱니와 가운데의 순수하지 않은 톱니는 알림

- **Setup**: 본문이 14줄인 순수 톱니, 그리고 `effect` 톱니가 흐름 가운데에 있는 기어.
- **Run**: 검사.
- **Expected**: 두 건이 알림으로 나오고 검사는 통과한다.
- **Pass criterion**: 종료 코드 0, 알림 2건(톱니 본문 줄 수 · 가운데의 effect).

### T14. 기어가 다른 기어의 흐름을 품는다

- **Setup**: flow 에 다른 기어의 이름을 적은 기어. 서로를 가리키는 기어 둘.
- **Run**: 품은 기어를 돌리고 이어 간다. 서로를 가리키는 기어를 돌린다.
- **Expected**: 품은 기어의 흐름이 그 자리에 펼쳐지고, 판단 단계의 글은 품긴 기어의 것이다. 자기 자신으로 돌아오는 흐름은 실행 전에 거절된다.
- **Pass criterion**: 종료 코드 10 → 0 과 기대 결과, 도는 흐름은 종료 코드 1 + 이유.

### T15. 이름의 선

- **Setup**: 톱니와 기어가 있는 프로젝트.
- **Run**: 톱니와 같은 이름의 기어, 기어와 같은 이름의 톱니, `teeth` 라는 이름을 만들려 한다. 새 톱니를 하나 만든다.
- **Expected**: 같은 이름은 거절(1), `teeth` 는 거절(2). 새 톱니 파일에는 첫 줄 `#!` 말고 주석이 없다.
- **Pass criterion**: 종료 코드 1 · 1 · 2, 주석 줄 수 1.

### T16. 실행 도중의 상태는 기록 폴더의 숨김 자리에 둔다

- **Setup**: 상태 자리를 따로 정하지 않은 실행.
- **Run**: 판단 단계에서 멈춘다.
- **Expected**: 상태가 `scv/journal/.gear-run/<표>/` 에 있다.
- **Pass criterion**: 그 자리에 대기 파일 있음.

### T17. 선택 답 훅의 길

- **Setup**: `outward` 톱니 앞에서 멈춘 실행.
- **Run**: 턴 검사의 선택 명령을, 확인 표가 든 질문과 "실행 (Recommended)" 답으로 부른다. 그 뒤 이어 간다.
- **Expected**: 턴 검사가 실행기에 확인을 적고, 이어가기가 그 톱니를 돌린다.
- **Pass criterion**: 종료 코드 0, 표식 파일 있음.

### T18. 톱니 폴더 밖을 가리키는 이름은 돌리지 않는다

- **Setup**: 톱니 사전에 `../../evil` 이라는 이름이 적혀 있고, 그 자리에 실행되면 표식 파일을 남기는 sh 가 있다.
- **Run**: 그 이름을 직접 돌리고, 그 이름을 flow 에 적은 기어를 돌린다.
- **Expected**: 둘 다 실행 전에 거절된다.
- **Pass criterion**: 0 이 아닌 종료 코드, 표식 파일 없음.

### T19. 이름이 겹쳐도 밖으로 톱니는 확인 없이 돌지 않는다

- **Setup**: `outward` 톱니와 같은 이름의 기어 폴더를 손으로 만든 경우, 톱니 사전에 같은 이름의 항목을 `effect` 로 한 번 더 적은 경우.
- **Run**: 그 톱니가 든 기어와 그 톱니를 돌린다.
- **Expected**: 기어 폴더가 겹친 경우에도 확인에서 멈춘다. 사전에 두 번 적힌 경우는 실행 전에 거절된다. 표식 파일은 생기지 않는다.
- **Pass criterion**: 종료 코드 11 / 1 · 1, 표식 파일 없음.

### T20. 확인이 아닌 답

- **Setup**: `outward` 톱니 앞에서 멈춘 실행들, `outward` 톱니가 둘 이어진 기어.
- **Run**: "실행 하지 마세요" · "실행 안 함" · "Run later" · "실행하지 않음" 으로 답한다. "실행" 뒤에 "실행하지 않음" 으로 다시 답한다. 첫 단계의 물음과 답을 둘째 단계 앞에서 다시 보낸다.
- **Expected**: 어느 경우에도 그 톱니는 돌지 않는다 — 다시 확인에서 멈춘다.
- **Pass criterion**: 모두 종료 코드 11, 해당 표식 파일 없음.

### T21. 잘못 적힌 표시

- **Setup**: 밖으로 나가는 톱니의 표시를 `outward (push)` · 탭 뒤의 `outward` · 끝에 보이지 않는 빈칸이 붙은 `outward` · `Outward` · 표시 줄 없음 — 다섯 가지로, 적는 모양 셋(빈칸 하나 · 둘 · 없음)으로 적는다.
- **Run**: 언어 설정이 없는 환경과 UTF-8 환경에서 각각 돌린다.
- **Expected**: 한 번도 그냥 돌지 않는다 — 확인에서 멈추거나 실행 전에 거절된다.
- **Pass criterion**: 30가지 모두 종료 코드 11 또는 1, 표식 파일 없음.

### T22. 검사는 파일을 바꾸는 '순수' 톱니를 돌리지 않는다

- **Setup**: `pure` 로 적었지만 본문이 파일을 지우는 · 옮기는 · 파일로 쓰는 톱니 셋, 끝나지 않는 톱니 하나. 지킬 파일 둘.
- **Run**: 예시 시간 한도를 1초로 두고 검사.
- **Expected**: 세 톱니는 돌리지 않고 줄 번호와 함께 지목한다. 지킬 파일은 그대로다. 끝나지 않는 톱니의 예시는 1초에서 끊고 알린다.
- **Pass criterion**: 종료 코드 0 아님, 지목 줄 넷, 파일 둘 그대로, 20초 안에 끝남.

### T23. 값이 빠진 인자

- **Setup**: 없음.
- **Run**: 값 없이 `--kind` 로 끝나는 만들기 명령, 값 없이 `--question` 으로 끝나는 확인 명령.
- **Expected**: 끝없이 돌지 않고 쓰는 법을 내며 끝난다.
- **Pass criterion**: 10초 안에 종료 코드 2.

### T24. 톱니 사전의 줄 끝과 빈칸

- **Setup**: 톱니 사전의 줄 끝이 CRLF 이고 값 줄 끝에 빈칸이 있다.
- **Run**: 기어를 돌리고 검사한다.
- **Expected**: 결과와 검사가 그대로다.
- **Pass criterion**: 실행 종료 코드 0 과 기대값, 검사 종료 코드 0.

### T25. flow 줄이 없는 품은 기어

- **Setup**: flow 에 적힌 다른 기어의 글에 flow 줄이 없다.
- **Run**: 바깥 기어를 돌린다.
- **Expected**: 조용히 건너뛰지 않고 실행 전에 거절한다.
- **Pass criterion**: 종료 코드 1 + 이유.

### T26. 순수 함수 사전과 측정

- **Setup**: 변경 뒤 저장소.
- **Run**: 순수 함수 사전 만들기 · 검사, 계획 끝 측정.
- **Expected**: 새 순수 함수들이 사전에 올라가고 검사가 통과한다. 측정값이 기록된다.
- **Pass criterion**: 검사 종료 코드 0, 측정 한도 넘음 0.

### T27. 실제로 도는 것을 보여 준다

- **Setup**: 이 저장소의 실제 커밋 기록, 톱니 넷과 기어 하나("릴리스 노트 초안").
- **Run**: 톱니 하나와 기어를 실제로 돌린다.
- **Expected**: 출력을 요약 없이 그대로 사용자에게 보여 주고, 선택 창으로 "이대로 계속할까요, 고칠 점이 있나요?"를 묻는다.
- **Pass criterion**: 사용자가 계속을 골랐다는 기록이 계획의 변경 이력에 있다.

### T28. 맥과 리눅스에서 같은 결과

- **Setup**: 맥(BSD 도구 · bash 3.2)과 리눅스(GNU 도구).
- **Run**: 이 시험 파일과 관련 시험을 두 곳에서 돈다.
- **Expected**: 두 곳 모두 통과한다.
- **Pass criterion**: 종료 코드 0.

## How to run

```bash
bash core/tests/test-gear-run.sh
```

## Pass criteria

- T1–T25 가 맥과 리눅스에서 통과한다.
- T26 의 사전 검사와 측정이 통과한다.
- T27 의 사용자 확인이 변경 이력에 있다.
- `tests/test-host-neutral.sh` 가 통과한다.
