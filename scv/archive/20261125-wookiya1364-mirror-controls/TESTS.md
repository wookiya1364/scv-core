# Test Plan — 거울 창에서도 누른다 · 낱말 카드

## Overview

거울(다른 세션의 SCV 창을 그리는 세션)에서 누른 것이 일하는 세션에 가서 그 세션이 하는지, 그리고 낱말 카드가 사전 파일을 그대로 읽고 쓰는지를 본다. 모드 시험은 대시보드 모드의 시험 틀에서 돌고, 실제 창의 장면은 사진으로 남긴다.

## Test scenarios

### T1. 누름이 정해진 꼴의 글이 되고, 그 글이 같은 할 일로 읽힌다

- **Setup**: 누름 다섯 가지(묻기 모드 · 자동 요약 · 기준 표시 · 기어 실행 · 브랜치)와 낱말 편집 셋(넣기 · 바꾸기 · 빼기).
- **Run**: 누름을 보낼 글로 바꾸고, 그 글을 다시 할 일로 읽는다.
- **Expected**: 읽은 할 일이 누른 것과 같다. 정해진 꼴이 아닌 글은 "모름"이다.
- **Pass criterion**: 여덟 가지 모두 왕복이 같고, 다른 글 세 가지는 모름.

### T2. 거울에서 묻기 모드 · 자동 요약을 누르면 일하는 세션의 값이 바뀐다

- **Setup**: 일하는 세션과 그 거울.
- **Run**: 거울에서 묻기 모드 스위치, 자동 요약 스위치, 기준 표시의 ◀ 와 ▶ 를 차례로 누른다.
- **Expected**: 누를 때마다 일하는 세션이 글 하나를 받고 그 값을 바꾼다. 두 창의 스위치와 기준 표시가 같은 값을 보인다.
- **Pass criterion**: 보낸 글 4개, 일하는 세션의 값 4번 바뀜, 두 창의 값이 같음.

### T3. 거울에서 기어를 돌린다 — 값 넣는 칸 · 확인 · 멈춤

- **Setup**: 값이 하나 필요한 기어와 밖으로 나가는 단계가 있는 기어.
- **Run**: 거울에서 첫 기어의 값을 채워 돌린다. 둘째 기어를 돌려 확인에서 "실행하지 않음"을, 다시 돌려 "실행"을 고른다. 도는 중에 멈춤을 누른다.
- **Expected**: 값이 일하는 세션의 실행에 그대로 들어간다. "실행하지 않음"이면 그 단계가 돌지 않는다. "실행"이면 돈다. 멈춤을 누르면 실행이 멈춘다.
- **Pass criterion**: 네 경우의 결과가 기대와 같고, 확인 없이 밖으로 나가는 단계가 돈 적이 0번.

### T4. 거울에서 브랜치를 바꾼다

- **Run**: 일하는 세션이 쉬는 동안과 턴이 도는 동안 각각 거울에서 브랜치를 고른다.
- **Expected**: 쉬는 동안에는 바뀌고 두 창의 브랜치 줄이 새 이름을 보인다. 도는 동안에는 바뀌지 않고 그렇다고 알린다.
- **Pass criterion**: 바뀜 1번 · 바뀌지 않음 1번, 알림 글 있음.

### T5. 낱말 카드 — 늘 보이고, 넣고 · 바꾸고 · 뺀다

- **Setup**: 사전이 없는 프로젝트와 항목 둘인 프로젝트.
- **Run**: 카드를 연다. 항목을 넣고, 쓸 말을 바꾸고, 하나를 뺀다. 칸에 탭이 든 글도 넣어 본다.
- **Expected**: 사전이 없으면 빈 카드와 넣는 칸이 보인다. 편집 뒤 사전 파일은 탭으로 나눈 네 칸 그대로이고, 같은 피할 말은 한 줄뿐이며, 바꿀 때 있던 꼴이 남는다. 꼴이 빈 항목은 "꼴 없음"으로 보인다. 탭은 빈칸이 된다.
- **Pass criterion**: 편집 뒤 파일의 줄이 기대 줄과 글자까지 같다. 본체의 `words.sh list` 가 같은 줄을 낸다.

### T6. 보내지 못하면 상태를 바꾸지 않는다

- **Run**: 일하는 세션이 없는 거울에서 누른다.
- **Expected**: 거울에 "보내지 못함"이 보이고 스위치가 눌리기 전 값으로 남는다.
- **Pass criterion**: 값이 바뀌지 않음, 알림 글 있음.

### T7. 누를 때마다 "메시지 받음" 줄이 하나 생긴다는 것을 알린다

- **Run**: 거울에서 누를 수 있는 것 위에 마우스를 올리거나 처음 누른다.
- **Expected**: 일하는 세션에 줄이 하나 생긴다는 안내가 보인다.
- **Pass criterion**: 안내 글 있음. 실제 창 사진에서 일하는 세션의 줄 수가 누른 횟수와 같음.

## How to run

```bash
cd ../scv-mods && claude plugin test marketplace/mods/scv-dashboard
```

## Pass criteria

- 모드 시험이 모두 통과한다.
- T2–T5 · T7 의 실제 창 장면을 사진으로 남겨 사용자가 본다.
