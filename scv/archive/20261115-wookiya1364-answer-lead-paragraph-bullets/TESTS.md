# Test Plan — 답 모양 바꾸기: 결론은 불릿 없는 한두 문장, 이어지는 생각은 문단 불릿

## Overview

답 골격 검사가 새 모양을 통과시키고 어긋난 곳만 다음 턴 경고로 내는지, 그리고 옛 모양을 말하는 문구가 어디에도 남지 않았는지 본다.
답은 모델이 쓰므로 실제 답이 새 모양으로 나오는지는 마지막 시나리오(T14)에서 사람이 본다.

## Test scenarios

### T1. 새 모양의 답은 위반이 없다

- **Setup**: 굵은 주제 → 불릿 없는 결론 줄 2문장(개조식) → 3문장짜리 문단 불릿('~함'으로 끝남) 둘
- **Run**: 그 본문을 답 골격 검사에 넣는다(줄글 상한 2)
- **Expected**: 위반 줄이 하나도 없다
- **Pass criterion**: 검사 출력 0줄(`""`)

### T2. 결론 줄이 3문장이면 지금처럼 알린다

- **Setup**: T1 의 결론 줄을 3문장으로 늘린 본문
- **Run**: 답 골격 검사(줄글 상한 2)
- **Expected**: 줄글 문단이 길다는 표시가 나온다
- **Pass criterion**: 출력에 `prose-long=3>2`

### T3. 불릿 아래로 들여 이어 쓴 줄은 그 불릿의 것으로 센다

- **Setup**: 불릿 한 줄 뒤에 들여 쓴 줄 둘(합쳐 4문장)이 이어지는 본문
- **Run**: 답 골격 검사(줄글 상한 2)
- **Expected**: 이어 쓴 줄이 줄글 문단으로 세지지 않는다
- **Pass criterion**: 출력에 `prose-long` 없음 — 고치기 전에는 `prose-long` 이 나오는 것을 먼저 본다

### T4. 6문장을 넘는 불릿만 알린다

- **Setup**: 7문장짜리 불릿 하나가 든 본문, 6문장짜리 불릿 하나가 든 본문
- **Run**: 두 본문을 각각 답 골격 검사에 넣는다
- **Expected**: 7문장은 긴 불릿 표시가 나오고 6문장은 나오지 않는다
- **Pass criterion**: 첫 출력에 `bullet-long=7>6`, 둘째 출력에 `bullet-long` 없음

### T5. 결론 줄이 '~습니다'로 끝나면 알린다

- **Setup**: 결론 줄이 "통과했습니다."인 본문, "이대로 쓸까요?"인 본문
- **Run**: 두 본문을 각각 답 골격 검사에 넣는다
- **Expected**: 존댓말 결론 줄은 표시가 나오고 물음은 나오지 않는다
- **Pass criterion**: 첫 출력에 `lead-polite=1`, 둘째 출력에 `lead-polite` 없음

### T6. 문단 불릿의 끝말 검사는 지금과 같다

- **Setup**: '~습니다'로 끝나는 문단 불릿 하나, '~함'으로 끝나는 문단 불릿 하나가 든 본문
- **Run**: 답 골격 검사
- **Expected**: 존댓말로 끝난 불릿만 센다
- **Pass criterion**: 출력에 `bullet-polite=1`

### T7. 따로인 항목만 나열한 주제는 결론 줄이 없어도 위반이 없다

- **Setup**: 굵은 주제 "확인 범위" 바로 아래 짧은 개조식 불릿 셋만 있는 본문, 그리고 지금 모양의 답(굵은 주제 + 짧은 불릿만)
- **Run**: 두 본문을 각각 답 골격 검사에 넣는다
- **Expected**: 둘 다 위반이 없다
- **Pass criterion**: 두 출력 모두 0줄(`""`)

### T8. 옛 모양을 말하는 문구가 남지 않았고 새 문구가 제자리에 있다

- **Setup**: 고친 코어 문서들
- **Run**: 문구 검사 — 옛 문구 다섯 가지(`first bullet states the result` · `bullets with the result first` · `its first bullet` · `첫 불릿에 결과` · `then short bullets`)를 규칙 · 규약 · 훅 틀 · 프로젝트 틀에서 찾고, 새 모양 문구를 규칙 본문 · 매 턴 안내 · 14개 규약 · 프로젝트 틀에서 찾는다
- **Expected**: 옛 문구는 없고 새 문구는 모든 자리에 있다
- **Pass criterion**: 옛 문구 0곳, 새 문구가 빠진 자리 0곳, 14개 규약의 글 모양 절이 서로 글자까지 같음(해시 1종)

### T9. 잠긴 '답 모양' 절은 결론 자리 두 줄만 바뀌었다

- **Setup**: 고친 도움말 규약
- **Run**: 잠금 시험
- **Expected**: 여섯 자리와 순서가 그대로이고, 결론 자리가 "굵은 주제와 그 아래 결론 줄"로 적혀 있다
- **Pass criterion**: 잠금 시험 끝 코드 0, 고치기 전과의 차이가 그 두 줄뿐

### T10. 불릿 기준 숫자는 한 곳에만 있다

- **Setup**: 고친 코어
- **Run**: 규칙 본문 · 매 턴 안내 · 14개 규약에서 불릿 문장 수 상한을 말하는 숫자를 찾는다
- **Expected**: 숫자는 기준 함수 한 곳에만 있고 문구에는 이유 문장("휴대폰 … 한 화면")이 있다
- **Pass criterion**: 문구 쪽 숫자 0곳, 기준 함수 출력 `6`, 규칙 본문과 매 턴 안내에 이유 문장 있음

### T11. 도움말 크기 한도 안이다

- **Setup**: 고친 도움말 규약과 훅 틀
- **Run**: 크기 한도 시험
- **Expected**: 본문 · 매 턴 · 합계가 모두 지금 한도 안이다
- **Pass criterion**: 끝 코드 0 — 한도 값(8,000 · 12,000 · 33,200)은 고치지 않음

### T12. 끄는 설정과 문장 상한 설정은 지금처럼 듣는다

- **Setup**: 글 모양 안내를 끈 프로젝트, 줄글 상한을 3으로 둔 프로젝트
- **Run**: 매 턴 훅을 돌리고, T2 의 본문을 상한 3으로 검사한다
- **Expected**: 끈 프로젝트에는 안내가 실리지 않고, 상한 3에서는 3문장 결론 줄을 알리지 않는다
- **Pass criterion**: 훅 출력에 `[SCV plain language]` 없음, 검사 출력에 `prose-long` 없음

### T13. 새 표시는 다음 턴 경고에 사람이 읽을 말로 실린다

- **Setup**: 긴 불릿 표시와 존댓말 결론 줄 표시가 든 위반 줄들
- **Run**: 위반 줄들을 경고 문구로 바꾸는 판정에 넣는다
- **Expected**: 두 표시 모두 무엇을 고칠지 말하는 한 줄이 된다(표시 이름 그대로가 아니다)
- **Pass criterion**: 경고 줄에 "불릿" · "결론" 이라는 말이 각각 있고, 다시 싣기 값이 1

### T14. 새 안내로 뽑은 실제 답을 사용자가 확인한다

- **Setup**: 고친 훅 틀을 쓰는 시험 프로젝트, 설명형 질문 3개(이유가 이어져야 답이 되는 질문)
- **Run**: 사람 없는 실행으로 질문마다 답을 하나씩 뽑아 그대로 사용자에게 보인다
- **Expected**: 답마다 결론 줄이 불릿 없이 먼저 오고, 이유가 이어지는 문단 불릿이 있다
- **Pass criterion**: 답 3개 모두 결론 줄 2문장 이하 · 문단 불릿(2문장 이상) 1개 이상 · 답 골격 검사 출력 빈 문자열, 그리고 사용자가 휴대폰에서 읽고 선택 창에서 "이대로"를 고름

### T15. 고친 검사가 눈에 띄게 느려지지 않는다

- **Setup**: 고치기 전 · 뒤의 답 골격 검사
- **Run**: 순수 함수 속도 견주기
- **Expected**: 고친 함수가 고치기 전의 1.2배 안이다
- **Pass criterion**: 속도 견주기 끝 코드 0(배수 1.2 이하)

## How to run

```bash
bash core/tests/test-answer-bullets.sh && bash core/tests/test-answer-lint-source.sh && bash core/tests/test-help-shape.sh && bash core/tests/test-instruction-conflicts.sh && bash core/tests/test-help-budget.sh
```

## Pass criteria

- T1–T13 · T15 가 맥 bash 3.2 와 리눅스 bash 5 에서 모두 통과(끝 코드 0)
- T14 에서 사용자가 "이대로"를 고름
- 순수성 검사와 순수 함수 목록 검사 끝 코드 0
