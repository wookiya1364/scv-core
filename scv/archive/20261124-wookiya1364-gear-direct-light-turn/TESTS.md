# Test Plan — 기어는 모델 없이 바로 돌고, 대화 턴은 가볍게 — 어긋나는 지시 정리

## Overview

세 가지를 확인한다. (1) 기어 요청인 턴이 가벼운 길로 가고, 보통 턴은 그대로인지. (2) 창이 값을 버튼 · 입력 칸으로 정해 기어를 모델 없이 돌리고, 밖으로 나가는 기어는 확인을 거치는지. (3) 어긋나는 지시 표의 항목이 모두 정리됐는지. 본체는 `core/tests/` 의 셸 시험, 대시보드는 모드의 시험 도구로 돈다. 모델 호출 수는 새 세션에서 손으로 한 번 잰다.

## Test scenarios

### T1. 기어 요청을 가린다

- **Setup**: 요청 글 다섯 — 기어 액션 꼴, 창이 붙인 기어 줄이 있는 글, 보통 글, 기어라는 낱말만 든 글, 기어 줄 꼴을 흉내 낸 틀린 이름
- **Run**: `scv_gear_turn`
- **Expected**: 앞의 둘만 기어 이름을 돌려주고, 나머지는 없음
- **Pass criterion**: 다섯 결과가 기대와 같음

### T2. 기어 턴에는 짧은 안내가 실린다

- **Setup**: 기어가 있는 프로젝트, 기어 요청 글
- **Run**: 매 턴 훅
- **Expected**: 세 줄 안팎의 기어 안내만 실리고, 도움말 먼저 · 등록 · 답 모양 긴 글은 실리지 않는다. 턴 상태에 액션 턴 표시가 남는다
- **Pass criterion**: 출력 크기가 보통 턴의 절반 이하, 표시 파일 있음

### T3. 보통 턴은 그대로다

- **Setup**: 같은 프로젝트, 보통 요청 글
- **Run**: 매 턴 훅
- **Expected**: 0.102.0 과 같은 글
- **Pass criterion**: 출력이 바꾸기 전과 바이트까지 같음(지시 정리로 합의해 바꾼 줄은 그 줄만 다름)

### T4. 기어 턴은 도움말 · 등록 없이 기어 실행기를 부를 수 있다

- **Setup**: 기어 턴으로 시작한 세션
- **Run**: 가드(모든 도구 방식)에 기어 실행 명령을 넣는다
- **Expected**: 거절되지 않는다
- **Pass criterion**: 거절 0번

### T5. 기어 턴에서도 파일 쓰기는 지금처럼 본다

- **Setup**: 기어 턴, 등록 없음
- **Run**: 가드(쓰기 방식)에 프로젝트 파일 쓰기를 넣는다
- **Expected**: 지금 규칙대로 거절된다(가벼운 길이 쓰기 검사를 풀지 않음)
- **Pass criterion**: 거절 1번

### T6. 기어 턴의 턴 끝 검사

- **Setup**: 기어 턴, 끝 답이 결과 두 줄(인용 · 세 줄 끝 보고 없음)
- **Run**: 종료 훅
- **Expected**: 막지 않고 알림도 남기지 않는다. 저널에 기어 이름 · 인자 · 종료 코드가 든 한 줄이 남는다
- **Pass criterion**: 알림 0줄, 저널 줄 1개

### T7. 설명에서 버튼 보기를 뽑는다

- **Setup**: 인자 설명 넷 — `돌릴 곳: mac · linux`(기본값 mac), `저장소: core · claude · codex · selftest`(기본값 core), `한 번에 겹쳐 돌릴 시험 수`(기본값 4), 보기에 기본값이 없는 설명
- **Run**: `argChoices`
- **Expected**: 앞의 둘은 버튼 보기(기본값이 골라짐), 뒤의 둘은 입력 칸
- **Pass criterion**: 네 결과가 기대와 같음

### T8. 누른 뒤 할 일을 정한다

- **Setup**: 기어 다섯 — 값 없는 pure, 값 없는 effect, 고를 값이 있는 effect, outward, judge. 입력 칸이 있는 화면과 없는 화면
- **Run**: `runPlan`
- **Expected**: 차례로 바로 실행 · 바로 실행 · 값 칸 · 확인 · 대화로. 입력 칸이 없는 화면에서 적어야 하는 값이 있으면 대화로
- **Pass criterion**: 결과가 기대와 같음

### T9. 값이 없는 기어는 누르는 즉시 창이 돌린다

- **Setup**: 표시가 effect 이고 인자가 없는 기어, 본체 설치 기록 있음
- **Run**: 기어 칸의 실행 버튼을 누른다
- **Expected**: 본체 기어 실행기가 한 번 불리고, 입력창에는 아무것도 들어가지 않고, 보내지는 글도 없다
- **Pass criterion**: 실행 1번, 입력창 채움 0번, 보냄 0번

### T10. 고를 값은 버튼으로 정하고 실행한다

- **Setup**: 인자 `os=mac`(돌릴 곳: mac · linux)인 기어
- **Run**: 실행을 누르고, linux 버튼을 누르고, [이 값으로 실행]을 누른다
- **Expected**: 실행 인자 배열 끝에 `os=linux` 낱말 하나가 붙는다
- **Pass criterion**: 불린 명령의 인자가 기대와 같음

### T11. 적어야 하는 값과 넣을 자료

- **Setup**: 인자 `count=4`(설명에 보기 없음)이고 받는 값이 있는 기어, 입력 칸이 있는 화면
- **Run**: 값 칸에 `7` 과 자료 두 줄을 적고 실행한다. 값에 공백 · 따옴표 · `;` 를 넣은 경우도 한 번
- **Expected**: `count=7` 이 낱말 하나로, 자료는 표준 입력으로 간다. 이상한 글자가 든 값도 낱말 하나의 값으로만 간다
- **Pass criterion**: 인자 배열과 표준 입력이 기대와 같음

### T12. 밖으로 나가는 기어는 확인을 거친다

- **Setup**: outward 톱니가 든 기어
- **Run**: 실행을 누른다. [취소]를 누른 경우와 [실행]을 누른 경우
- **Expected**: 누르면 확인 글(무엇이 밖으로 나가는지)이 먼저 보인다. 취소면 실행 0번, 실행이면 본체의 확인 절차를 거쳐 돈다
- **Pass criterion**: 취소 때 실행 0번, 실행 때 확인 기록 뒤 실행 1번

### T13. 판단 단계가 든 기어는 대화로 간다

- **Setup**: 표시가 judge 인 기어
- **Run**: 실행을 누른다
- **Expected**: 창이 돌리지 않고 입력창에 기어 명령을 넣는다
- **Pass criterion**: 실행 0번, 입력창 채움 1번

### T14. 오래 도는 실행

- **Setup**: 30초 안에 끝나지 않는 실행(시험에서는 끝나지 않는 것으로 흉내)
- **Run**: 실행을 누르고 시간을 흘린다. 그다음 끝난 것으로 바꾼다. 멈춤을 누르는 경우도 한 번
- **Expected**: 도는 동안 기어 칸에 끝 줄과 걸린 시간이 보이고, 끝나면 결과 줄과 알림. 멈추면 멈췄다고 보인다
- **Pass criterion**: 도는 중 줄 · 결과 줄 · 알림 1번 · 멈춤 줄

### T15. 사용함은 창이 돌릴 수 있으면 창이 돌린다

- **Setup**: 입력창 위 줄이 뜬 상태. 값 없는 effect 기어인 경우와 judge 기어인 경우
- **Run**: [사용함]을 누른다
- **Expected**: 앞은 창이 바로 돌리고 보내지는 글이 없다. 뒤는 0.3.2 처럼 글이 한 줄과 함께 간다
- **Pass criterion**: 앞 — 실행 1번 · 보냄 0번, 뒤 — 실행 0번 · 보냄 1번

### T16. 결과를 대화에 붙이기는 누를 때만

- **Setup**: 창에서 돌린 결과가 있는 기어
- **Run**: 아무것도 누르지 않은 경우와 [결과를 대화에 붙이기]를 누른 경우
- **Expected**: 누르지 않으면 입력창이 그대로, 누르면 결과 줄이 입력창에 들어간다(보내지는 않음)
- **Pass criterion**: 채움 0번 → 1번, 보냄 0번

### T17. 어긋나는 지시 표의 항목이 모두 끝났다

- **Setup**: 계획 폴더의 표 문서
- **Run**: 표의 줄을 읽는다
- **Expected**: 모든 줄의 처리 칸이 없앰 · 다듬음 · 이기는 쪽을 적음 중 하나이고, 근거 칸(고친 파일과 줄)이 차 있다
- **Pass criterion**: 처리 칸이 빈 줄 0

### T18. 정리한 지시가 글에 실제로 반영됐다

- **Setup**: 표에서 '없앰' · '다듬음'인 항목
- **Run**: 매 턴 훅과 규약 글에서 옛 문장을 찾는다
- **Expected**: 옛 문장이 없고 새 문장이 있다
- **Pass criterion**: 옛 문장 0번, 새 문장 1번씩

### T19. 모델 호출 수 재기 (손으로 한 번, 새 세션)

- **Setup**: 새 세션 둘 — 바꾸기 전 설치본과 바꾼 뒤의 것. 값이 다 있는 같은 기어 요청
- **Run**: 대화로 기어를 시키고 세션 기록에서 그 턴의 모델 호출 수 · 쓴 토큰 · 걸린 시간을 센다. 창에서 같은 기어를 돌린 경우도 센다
- **Expected**: 대화 — 호출 수가 줄어 3 이하. 창 — 호출 0
- **Pass criterion**: 세 숫자를 마무리 보고에 전 · 후로 적음

### T20. 기존 시험이 그대로 통과한다

- **Setup**: 없음
- **Run**: 본체의 관련 시험과 대시보드 시험 전체
- **Expected**: 모두 통과(지시 정리로 글이 바뀐 시험은 그 글만 고침)
- **Pass criterion**: 실패 0

## How to run

```bash
bash core/tests/test-gear-turn.sh && bash core/tests/test-gear-run.sh && bash core/tests/test-help-first.sh && bash core/tests/test-guard.sh && bash core/tests/test-instruction-diet.sh && bash core/tests/test-instruction-conflicts.sh && (cd ../scv-mods/marketplace/mods/scv-dashboard && claude plugin test .)
```

## Pass criteria

- 위 명령이 종료 코드 0 으로 끝난다(`core/tests/test-gear-turn.sh` 는 이 계획이 새로 만든다).
- T19 의 숫자를 마무리 보고에 적었다: 대화 호출 3 이하, 창 호출 0.
- 어긋나는 지시 표를 사용자에게 보였고 남은 항목이 없다.
- 순수 함수 사전 · 순도 · 호스트 중립 검사 통과, 대시보드 형 검사 오류 수 9 이하.
