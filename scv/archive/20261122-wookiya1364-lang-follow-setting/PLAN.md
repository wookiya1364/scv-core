# 답 · 중간 보고를 설정 언어로 — 한 줄 규칙 턴에도 언어 줄 · 쓰기 전 알림 · 여러 언어 검사

## Summary

다른 프로젝트의 긴 세션(2026-11-22, 사람 턴 107)에서 도구 사이 중간 보고가 약 37% 영어였고 끝 답도 3번 영어였다(설정 언어 korean). '방금 쓴 글이 한국어가 아니다' 경고는 약 99번 나갔지만 쓴 뒤에 고치는 방식이라 다음 글에서 다시 영어가 나왔다. 규칙이 한 줄로만 실리는 턴(0.96.0+)에는 언어 줄 자체가 없었고, 검사는 설정 언어가 korean 일 때만 돈다. 이 계획은 사용자가 SCV 에서 정한 언어로 답 · 중간 보고가 나오게 한다.

## Goals / Non-Goals

- **Goals**
  - 한 줄 규칙 턴에도 설정 언어 줄을 싣는다.
  - 쓰기 전에 막기: 도구 결과 뒤에 짧은 설정 언어 알림을 싣는다 — 이번 턴의 직전 글이 이미 설정 언어면 싣지 않는다.
  - 검사(다른 언어 줄 세기 · 교정 문구)를 korean 밖으로 넓힌다 — 글자로 구별되는 언어(일본어 · 중국어).
- **Non-Goals**
  - 글자로 구별되지 않는 언어끼리(예: 스페인어 설정에 영어 줄) 판정 — 규칙 줄만 싣는다.
  - 끝 답 막기(종료 훅) 규칙 바꾸기.
  - english 설정 — 모델 기본 언어라 지금처럼 아무것도 싣지 않는다(기존 약속: english 면 훅 출력이 그대로).

## Approach Overview

언어 판정 함수가 설정 언어에 따라 '맞는 글자'와 '다른 글자' 바이트 범위를 고른다(한국어 한글, 일본어 가나 · 한자, 중국어 한자). 사람 턴 훅은 규칙이 한 줄인 턴에도 언어 줄을 싣는다. 도구 뒤 훅은 이번 턴 마지막 글이 설정 언어로 판정되지 않으면 짧은 알림을 싣는다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

| 단계 | 함수 | 순수 | 하는 일 |
|---|---|---|---|
| 글자 | `scv_lang_script` | 순수 | 설정 언어 → 맞는 글자 · 다른 글자 바이트 범위 |
| 판정 | `scv_lint_lang_turn` | 순수 | 다른 언어 줄 수 — 설정 언어별 글자로 |
| 판정 | `scv_lang_text_ok` | 순수 | 글이 설정 언어로 쓰였다고 판정되는가 |
| 문구 | `scv_lang_remind_line` | 순수 | 도구 뒤 짧은 알림 한 줄 |
| 문구 | `scv_lang_fix_note` | 순수 | 교정 문구 — 한국어 밖은 영어 문장에 언어 이름 |
| 싣기 | `on-lang-check.sh` | 부수효과 | 도구 뒤 알림 · 교정 |
| 싣기 | `on-user-prompt.sh` | 부수효과 | 한 줄 턴에도 언어 줄 |

## Guardrails

- 설정 언어가 없거나 사용자가 이 턴에 다른 언어를 썼으면 알림을 싣지 않는다.
- 매 턴 글 예산(codex 사본 포함)을 넘지 않는다 — 넘으면 멈추고 묻는다.
- 시험 없이 고치지 않는다 — 재현 시험이 먼저 실패해야 한다.

## Exit criteria

- 한 줄 규칙 턴에 설정 언어 줄이 있음(korean · japanese), 설정이 없으면 없음.
- 도구 뒤 알림: 이번 턴에 글이 없거나 마지막 글이 다른 언어면 한 줄, 마지막 글이 설정 언어면 없음.
- japanese 설정에서 영어 중간 보고 줄을 잡음. korean 판정은 지금과 같음(기존 시험 통과). english 설정은 출력 그대로.
- 그 세션 기록 재생: 알림이 실릴 도구 결과 수와 늘어나는 글 바이트를 잼.
